# Skill：CSV 文本编辑规范（换行 / 变量替换）

## 适用范围

适用于所有**含文本字段**的 CSV：tooltip、描述、状态文本等（不限于武器）。

目标：

- 文本可读、支持多行、变量替换稳定
- 避免 `%` 触发底层格式化导致崩溃
- 避免 CSV 字段内的引号/逗号/换行导致列错位

## 规范 1：换行机制（单元格内真实换行）

当你希望 UI/Tooltip 真正换行时，**不要**在 CSV 里写字面量 `\n` 期待游戏解析。

正确做法：

- 让字段内容直接包含真实换行符（LF/CRLF）
- 含换行的字段**必须**用双引号包裹（CSV 标准）
- 字段内双引号必须双写：`""`

提示：

- 使用 `ss-csv` 生成时，含换行字段会自动加引号，减少手工错误。

## 规范 2：变量替换机制（`{%s}` + 管道列表）

推荐结构（适用于 tooltip/描述文本的“高亮替换”路径）：

- 在模板字段中使用 `{%s}` 作为占位符（可出现多次）
- 在替换字段中提供替换列表，并用 `|` 分隔，按顺序依次填充

示例：

- 模板字段：`系统联动武器：随『{%s}』启用。\n光束 DPS = 容量 × {%s}。`
- 替换字段：`恒星喷射 | 15%`

注意：

- 替换列表里写“最终展示文本”，不是格式化指令
- 占位符数量与替换段数应一致，否则会出现“部分不高亮/错位替换”

## 规范 3：百分号 `%` 的安全写法

风险背景：某些 UI 文本路径会执行 `String.format` / `Formatter`。

规范建议：

- **优先**把带 `%` 的动态数值放进替换字段，通过 `{%s}` 填充
- 若确认会走 `String.format`：用 `%%` 表示字面 `%`
- 若不确定：避免在模板里直接写 `15%`，改用替换字段

本项目推荐：

- 模板字段只放 `{%s}`
- 替换字段里可以安全使用 ASCII `%`

## 常见坑位清单

- 不换行：写的是字面量 `\n`，而不是字段内真实换行
- `%` 崩溃：模板进入 `String.format` 路径且包含未转义 `%`
- 替换失效：`{%s}` 与 `|` 段数不匹配
- CSV 读坏：字段含逗号/引号/换行但未正确加引号或引号未双写
