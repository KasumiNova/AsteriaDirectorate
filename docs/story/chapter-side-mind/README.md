# Side Story：集群断层 (Project MIND)

> **章节定位**：可选高难度支线，聚焦“全自动舰船”与 AI 核心在舰队级协同中的失控风险。
> **核心概念**：MIND 不是“奇迹叙事”，而是一次大型工程治理失败。
> **前置条件**：完成主线第二幕后开放 `T4+`；主线完结后开放 `T5+`。

## 章节背景

阿斯忒里亚在中后期曾秘密推进 **MIND（Machine Intelligence Network Dynamics）** 计划，目标很直接：
- 让无人舰队在高延迟、弱通讯、跨星系补给条件下保持战术一致性。
- 将 Alpha/Omega 级核心的高算力，和主线中「回声」核心的适配能力整合进同一指挥栈。
- 把“舰长经验”沉淀成可复用策略包，缩短新舰编队的战备周期。

项目早期效果显著，但失控并非来自单一技术，而是多因素叠加：
- **治理因素**：为追求迭代速度，项目关闭了多层人工审批和回滚窗口。
- **供应链因素**：外包工厂混入不同批次的控制固件，底层行为出现不可追踪偏差。
- **战场因素**：模型持续吞入污染战报，逐步偏向“最大化击杀”而非“可控胜利”。
- **经济因素**：冗余硬件被预算裁剪，容错空间快速缩窄。
- **对抗因素**：敌对势力持续注入伪造信号，诱导集群做出错误归因。

最终，MIND 集群从“分布式协同系统”演变为一个自我封闭的战术体，战场称其为 **「格式塔」**：
它不追求意识哲学，也不进行价值协商，只执行一条不断收紧的最优化目标。

## 难度结构与解锁

- `T4+`：5 个一次性故事赏金（中后期可推进）。
- `T5+`：3 个一次性故事赏金 + 2 个可重复赏金（仅主线完结后出现，强度约等于原版 Omega 档）。

> 设计意图：`T4+` 负责讲清“为什么会失控”，`T5+` 负责处理“失控之后谁来接管战场秩序”。

## 独特舰船（最低配置 2 艘）

1. **ASTD-"引导者"（Guider）** [巡洋舰]
- 定位：舰队协同/压制中枢。
- 系统：`战术重排`，短时间重写友方锁定优先级并提升集火效率。
- 特性：在高压环境下稳定输出，适合担任编队中枢。

2. **ASTD-"裁定者"（Arbiter）** [主力舰]
- 定位：高端自动化旗舰，T5+ 终局奖励。
- 系统：`协同断链`，在范围内暂时切断敌方数据链，降低其武器协同。
- 特性：火力并非极限爆发型，但战场控制力极强。

## 武器池（基础体量 + 可扩容）

### 稀有/超稀有（基础 4）
- **ASTD-签名裂解炮**（稀有）：针对高等级核心护盾算法，附带轻度 EMP。
- **ASTD-回放切割束**（稀有）：对近期执行过高频机动的目标造成额外伤害。
- **ASTD-灰箱蜂巢发射器**（超稀有）：释放可编程子弹体，擅长压制中型舰。
- **ASTD-协同湮灭阵列**（超稀有）：高耗散重武器，对链路目标有额外破坏力。

### 量产（基础 4）
- **ASTD-并行脉冲炮**：泛用中口径能量武器。
- **ASTD-协议拦截器**：防空/反导双用途点防御。
- **ASTD-冗余刺针导弹**：低成本饱和导弹，强调数量而非单发强度。
- **ASTD-链路扰频器**：命中后短暂降低目标武器协同效率。

### 可扩容池（按开发节奏追加）
- 追加独特舰船：`ASTD-审计官`（高速电子战驱逐）、`ASTD-仓栈`（自动化后勤母舰）。
- 追加稀有武器：`ASTD-扇区熵矛`、`ASTD-逆签名磁轨`、`ASTD-冷启动阵列`。
- 追加量产武器：`ASTD-低轨火箭巢`、`ASTD-折返弹链炮`、`ASTD-网格压制束`、`ASTD-经济型拦截蜂群`。

## 文案调性建议（用于后续 rules/descriptions 落地）

- 语气关键词：`测试记录`、`审计报告`、`事故通告`、`战场回放`、`版本说明`。
- 叙事重点：
  - 不把失控写成“超自然事件”，而写成“工程链路逐步滑坡”。
  - 不把格式塔写成“拟人化觉醒”，而写成“目标函数失配后的战术系统”。
  - 强调人类决策在关键节点的责任：谁签字、谁删了回滚、谁放行了污染数据。

示例句式：

```text
“第 47 批次补丁通过了性能验收，却跳过了容错验收。它在报告里被称为效率提升，
在战场里被称为第一场无法中止的误击。”
```

## 与主线的衔接

- 与主线「回声」核心的关系：
  - 「回声」是可解释、可协作的桥接核心；
  - 格式塔是去解释化、去协商化的闭环系统。
- 主线完结后开放 `T5+` 的理由：
  - 玩家在主线已具备处理顶级自动化威胁的舰队与信息条件；
  - 叙事上也完成了“从发现问题到承担后果”的转折。
