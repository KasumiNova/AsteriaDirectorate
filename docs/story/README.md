## 叙事特色

### 双线对立的哲学内核
- **弧光计划（蓝）**：压倒性正面火力，体现"力量即正义"的技术至上主义
- **透镜协议（紫）**：信息优势与空间操控，体现"洞察即胜利"的认知哲学

### 三层时间的交织叙事
- **深层时间**：领域纪元的辉煌与大崩塌的废墟
- **中层时间**：阿斯忒里亚项目的兴衰与分裂
- **即时时间**：玩家的发现与抉择对未来的影响

### 渐进式揭示机制
每完成一个主线节点，解锁：
- 更深层的历史档案与设计理念
- 更强大的敌方词缀与战术挑战
- 更复杂的道德选择与结局分支
