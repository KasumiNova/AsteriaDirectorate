# 组织命名与设定基调

> 本文档是设定推翻重做后的第一份文档，记录模组命名体系与叙事基调的定案。
> 后续所有设定文档、游戏内文案以此为准。

## 命名层级

```
菀星设计总局（Asteria Directorate）—— 模组对外名 / 势力名
├── 星坠理事会（ARC）—— 武备端：弹道、能量弧、打击系统
└── 紫菀理事会（LENS）—— 观测端：传感、制导、火控透镜
```

### 菀星设计总局（Asteria Directorate）

模组对外宣传名。"菀星"取紫菀（aster）与星的双关，与英文名 Asteria 同源：

- **Asteria**：希腊神话中流星与夜间神谕的泰坦女神。词根 *aster* = 星，亦是紫菀属花名。
- **Directorate**：总署/理事会，行政与裁决机构——不是军队、不是王朝、不是公司。

命名基调是纯中式的"衙门感"，不掺西方词根（弃用"司星总署"等候选即出于此）。

### 星坠理事会（ARC）

武备设计局。意象来源：流星 = 划过天际的弹道/投射物。"我们制造坠落的星"。

### 紫菀理事会（LENS）

观测设计局。意象来源：紫菀花瓣呈放射状排列，形态即一枚光圈叶片/虹膜——"透镜"的植物学隐喻。

两家是互相依赖的军工组织，核心叙事一句话：

> ARC 负责让星星坠落，LENS 负责让它落在该落的地方。

ARC 的投射平台离了 LENS 的火控就是瞎炮；LENS 的透镜系统离了 ARC 的平台就是没有牙的眼睛。
这同时解释了模组内装备分 ARC / LENS 两个系列的由来。

## ARC / LENS 展开词：多版本并存制

缩写展开词**不设唯一官方答案**。大崩塌烧掉了档案，两百年后没人确定当年全称是什么——
总署从不纠正任何说法。以下均为"考据出的版本"，玩家觉得是什么就是什么。

### ARC 的流传版本

| 版本 | 直译 | 气质 / 叙事钩子 |
|---|---|---|
| Asteroid Redirect Commission | 小行星变轨委员会 | 人之领时代的行星工程机构前身：拖曳小行星、坠落采矿。"星坠"之名的历史由来——他们以前真的让星星坠落，崩塌后同一套变轨数学被用来计算弹道。 |
| Armament Research Combine | 武备研究联合体 | 直白现名，对外注册口径，只讲业务不讲故事。 |
| Applied Resonance Concern | 应用共振企业 | 能量弧武器路线的指向。 |

### LENS 的流传版本

| 版本 | 直译 | 气质 / 叙事钩子 |
|---|---|---|
| Long-range Engagement & Navigation Systems | 远程交战与导航系统 | 功能描述型，最像真实军工公司命名（BAE Systems 一挂）。交战 + 导航精确覆盖火控 + 制导。 |
| Luminous Evaluation & Nullification Systems | 光度评估与压制系统 | "评估与压制"带裁决味，呼应总署的赏金签发/核销气质；Luminous 扣紫菀的光学意象。 |
| Low-observability Engagement Network Systems | 低可观测交战网络系统 | 传感网络 / 反隐身对抗路线，为日后电子战、侦察类装备留位。 |

命名风格本身暗示分工：ARC 各版本均为 Commission / Combine / Concern（重工联合体质感），
LENS 各版本均为 Systems（精密系统公司质感）。

## 游戏内 design type 字段

舰船/武器数据的 design type（法典与装配界面的"设计流派"栏）使用：

| 系列 | design type | 显示颜色 |
|---|---|---|
| ARC | `菀星设计局-星坠` | 淡蓝色 |
| LENS | `菀星设计局-紫菀` | 淡紫色 |

- 使用连字符 `-`，与多数第三方模组的习惯保持一致。
- 此处用"菀星设计局"（而非对外名"总局"）作为归属前缀：字段内强调"这是菀星旗下某个分局的设计"，
  分局名"星坠/紫菀"置于连字符后。

## 文案使用规则

- **剧情叙述、势力描述、物品 flavor 文本**：使用寓意中文名——"星坠""紫菀""菀星""总局"，
  用寓意名强调设计，不用缩写讲设定。
- **型号/装备命名**：ARC、LENS 作为系列代号前缀使用（如装备 ID、型号编号）。
- **展开词**：任何官方文案不得钦定唯一展开；如引用，以"据说""考据认为"等不确定口径出现。

## 叙事基调

- **不走"人之领继承者"路线**。总局不宣称复兴任何人，Asteria 是"坠落的那一位"——
  承认坠落，但不怀旧。
- 总局的自我定位是**签发、裁决与记录**的行政机构（赏金签发、核销、审计），
  英仙座无政府环境里的中立第三方，而非又一个大军阀。
- 多模组联动时，总局在其他势力剧情中扮演**第三方/背景板**，不当主角。
