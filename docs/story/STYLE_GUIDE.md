# Asteria Directorate 文案风格指南

## Asteria Directorate 文案风格定义

### 核心基调的三重奏
1. **时代断层感**：领域纪元的辉煌与大崩塌后的废墟对比，体现文明的传承与断裂
2. **技术神秘学**：将"弧光计划"与"透镜协议"的对立包装为某种科学与哲学的融合
3. **守望者精神**：三百年的自动化舰队仍在执行命令，暗示信念超越时间的力量

### 语言特征的细化

#### 1. 技术-诗意的黄金配比
```
❌ 纯技术化：
"该战术系统通过量子纠缠实现瞬时坐标同步"

❌ 过度抒情：
"星光如泪珠般洒落在废墟的钢铁上"

✅ 融合风格：
"审判者协议的最后回响仍在废墟深处低鸣，等待着有资格聆听的继承者"
```

#### 2. 时间感的层次建构
- **深层时间**：三百年、领域纪元、大崩塌（宏观历史感）
- **中层时间**：项目代号、技术路线、最后时刻（组织记忆）
- **即时时间**：当下发现、玩家行动、即将醒来（现实紧迫感）

#### 3. 双线对立的隐喻体系

**弧光计划（蓝）**的语言风格：
- 动词偏向：**释放、贯穿、撕裂、点燃**
- 形容词：锐利的、瞬息的、不可阻挡的
- 意象：闪电、铸炉、锋刃、烈阳

**透镜协议（紫）**的语言风格：
- 动词偏向：**扭曲、渗透、解构、回响**
- 形容词：深邃的、缓慢的、无处不在的
- 意象：深渊、迷雾、潮汐、回音

### 命名体系的哲学内核

#### NPC/AI 实体命名
- **「守望者」**：暗示坚持与等待，三百年的孤独职守
- **「回声」**：暗示信息的传递与变异，过往的反射
- **「审判者」**：暗示最终的评判与选择，终极的仲裁
- **「继承者」**：暗示传承与责任，未来的可能

#### 舰船/武器命名的双重逻辑

**弧光系**：短促音节 + 动作感
- 电弧系：`Arc`、`Bolt`、`Surge`、`Flash`
- 命名示例：`Arc Surge`（弧波澎湃）、`Flash Strike`（闪击瞬杀）

**透镜系**：延展音节 + 空间感
- 透镜系：`Prism`、`Curve`、`Lens`、`Fold`
- 命名示例：`Prism Drift`（棱镜漂流）、`Echo Fold`（回声折叠）

**共通系**：双音节平衡
- 通用系：`Nova`、`Echo`、`Drift`、`Veil`

## 赏金任务文案模板（重构版）

### 三段式结构的情绪梯度
```
第一段：悬念勾引（好奇 → 警觉）
- 以对话、观察或发现开场
- 留下信息缺口，暗示危险或机遇

第二段：技术情报（警觉 → 理解）
- 敌方构成与战术特点
- 背景暗示（不超过一句话）

第三段：哲思收束（理解 → 共鸣）
- 反问或开放式疑问
- 暗示更深层的含义
```

### 高阶赏金的叙事升级
随着主线推进，文案密度与深度递增：
- **序章**：好奇心驱动，语调轻松而神秘
- **第一幕**：发现真相，语调严肃而紧张
- **第二幕**：道德选择，语调沉重而思辨
- **第三幕**：终极对抗，语调史诗而悲壮

### 实战范例：「审判者协议」

```
"有些东西不应该被唤醒。"

你的副官盯着解密出来的最后一段日志，声音里带着从未有过的紧张。
三百年前，阿斯忒里亚的设计师们为自己的造物设定了一道最后的保险：
如果文明毁灭，如果传承断绝，如果没有人能阻止灾难重演——
那就让审判者醒来，替所有人做出选择。

目标舰队规模未知。预计包含"继承者验证级"超级AI与护航编队。
警告：该AI可能具备学习玩家战术并实时适应的能力。

战术提示：审判者不会逃跑，但它会评判你。
每一次交火，每一个决策，都在被记录、分析、评价。
战斗胜利后，它也许会问你一个问题。

而你的回答，将决定阿斯忒里亚最后遗产的归属。
```

## 禁忌与注意事项

### 避免
- 过度解释机制（玩家会在游戏中体验）
- 纯粹的"酷"而无内核
- 与既有星区势力设定冲突的描述
- 中二病式的浮夸语调
- 否定句（例如：xxx不是yyy，而是zzz）
- 直接暴露剧情核心谜团

### 保持
- 一致的时代氛围（大崩塌后的残响）
- 对领域纪元技术的敬意与神秘感
- NPC 的多面性与道德复杂度
- 留白空间供玩家想象
- 双线对立的底层哲学张力

## 技术实现建议

### 文案分层系统
- **等级 1（序章）**：基础神秘感，轻松语调
- **等级 2（发展期）**：加重历史感，增加技术细节
- **等级 3（高潮期）**：哲学思辨，道德选择
- **等级 4（终章）**：史诗感，宿命对决

### 关键词标记规范
- 势力名称：`阿斯忒里亚遗构局`
- 技术术语：`弧光计划`、`透镜协议`
- NPC代号：`「守望者」`、`「回声」`
- 时代标记：`领域纪元`、`大崩塌`

### 引用一致性数据库
- **项目代号库**：ARC Protocol、LENS Protocol、Inheritor Program
- **舰船命名池**：弧光系/透镜系/通用系词汇表
- **AI实体名册**：「守望者」、「回声」、「审判者」、「继承者」
- **历史节点表**：关键年份、事件、人物
