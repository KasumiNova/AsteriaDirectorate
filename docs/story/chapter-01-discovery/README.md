# 第一幕：暗流涌动

> **章节定位**：主线展开，玩家开始深入阿斯忒里亚遗迹，发现两条技术路线的竞争仍在以某种形式延续。
> **情绪弧线**：追踪 → 发现 → 选择倾向
> **主要内容**：8 个主线赏金 + 「守望者」NPC 首次出场 + 弧光/透镜路线初步分化

---

## 章节简介

序章的坐标将玩家引向一座废弃的阿斯忒里亚造船厂。但抵达时，玩家发现这里并不像想象中那样沉寂——有人比你先到一步，而且留下了痕迹。

追踪这些痕迹，玩家将逐渐揭开弧光计划与透镜协议在大崩塌后的不同命运：
- 弧光遗产被速子科技的猎手觊觎
- 透镜遗产被霸主的回收舰队瓜分

在这场三百年前就埋下伏笔的技术争夺中，一个神秘的人物——「守望者」——开始向玩家传递信息。

| 类型 | 舰队歼灭（混合编队） |
| 奖励 | 积分 + 双线数据碎片 |

### 任务文案（job_description）

```
「守望者」没有寒暄。
他把一段战术回放丢给你，只说了一句：

"看清楚。弧光和透镜的对立，到了最后是怎么变成同一把刀的。"

回放里是一场短促的遭遇战。
一支看似杂牌的舰队，却像训练有素的合唱团：
前排用弧光火力强行逼迫过载，后排用透镜干扰切断撤退路线。

"这绝非巧合，"守望者说，"有人在把两条路线的残件拼起来。

目标：歼灭混合编队，并回收其旗舰的数据核心。
预计敌方包含：
- 弧光系重火力平台（高输出窗口）
- 透镜系干扰与假目标平台（锁定欺骗）

战术提示：
1) 这支编队会故意“引诱你追错目标”。请看向你的目视窗口，而非雷达。
2) 当弧光火力进入过驱窗口时，不要硬吃；切断其支援更有效。

守望者最后补了一句：

"这算是一次测试。属于我个人的测试。"
"我想看看，你会不会为了赢，去做和他们一样的事。"
弧光与透镜的融合本应是文明的巅峰，如今却成了掠夺者的工具。这本身就是一种评判。
```

### 任务完成后文案（job_success_text）

```
混合编队被击溃后，你从旗舰残骸里拆出了一枚数据核心。

你的技术员皱眉：
"这些算法在互相‘否定’。弧光那套在追求最短时间内的压倒性输出，

「守望者」沉默了很久，才低声说：
"双重校验……"
"他们已经开始了。"

[获取：双线数据碎片]

### 任务文案（job_description）

```
会师坐标把你带到一处不起眼的引力异常点。
从外观上看，它只是一座废弃的中继平台。

但当你的舰队靠近时，平台的灯光一盏盏亮起。
像一座死去的城市突然想起了呼吸。

「守望者」低声说：
"这里是两条路线最后一次试图‘握手’的地方。"

平台广播出一段简短的系统提示：

"Access requires dual validation."（访问需要双重校验。）

然后，守卫舰队从阴影里出现。
比起余晖，它们更像阿斯忒里亚的旧式自动化保全——
动作克制、攻击精准，坚守防线，拒绝任何靠近。

目标：清理守卫，靠近平台核心，夺取外围访问权限。

战术提示：
- 它们会主动“保护平台”，你可以利用这一点拉扯阵型。
- 观察其协同节奏：这会是你在第二幕活下来的预习。

你突然明白：
所谓“访问权限”更像是一次裁决。
它在审视你是否值得被允许继续往里走——弧光与透镜共同认可的继承者。
```

### 任务完成后文案（job_success_text）

```
平台核心的加密并没有完全解开。
你只能拿到一份“外围访问权限”与一段提示。

提示是一行字：

"Bring the marks, not the key."（带上印记，而不是钥匙。）

你的副官看了你一眼：
"他们是在吐槽谁吗？"

「守望者」却像被这句话击中了。
他缓慢地说：

## NPC 档案：「守望者」

### 基本信息
- **称谓**：守望者（The Watcher）
- **真名**：未知
- **背景**：自称是阿斯忒里亚遗构局最后一代工程师的后裔
- **所在**：位置不固定，通过加密通讯与玩家联络

### 初次见面对话（通讯界面）

```
屏幕上没有图像——只有一个古老的阿斯忒里亚徽标在缓慢旋转。
声音经过处理，听起来不男不女，不老不少。

"我观察你很久了，陌生人。"

"有人踏入阿斯忒里亚的遗迹，只是为了拾荒——把一切能卖钱的东西拆下来，销往黑市。
有人踏入这里，是受雇于那些想要'垄断'这些技术的势力。"

"但你……看起来有些不同。"

"我不会问你的动机。每个人都有自己的理由。"
"但如果你愿意，我可以告诉你更多关于阿斯忒里亚的事——"
"关于弧光，关于透镜，关于那场三百年前的分裂。"

"也许到最后，你会明白这些遗产真正的价值。"
"比起火力或数据——它们的价值在于代表的选择。"

[对话选项]
A. "你是谁？为什么要帮我？"

```

### 选项回应

声音沉默了片刻。

"弧光的工程师们常说：'真正的高手不会开过量的火。'"
"你的战斗风格很干净。这在当今星区是稀缺品。"
```

**选项 B 回应**：
```
"继承者？"声音里有一丝苦涩。

"弧光计划的残骸大部分落入了霸主手中。他们不理解其中的精髓，只会蛮力复刻。
透镜协议……速子科技一直在觊觎这条线。他们的电子战技术有一半是从透镜偷来的。"

"要看你怎么定义。如果是指血脉，那条线早就断了。"

"你可以选择一条先做。"

"毕竟——弧光和透镜，曾经是一体的。"
