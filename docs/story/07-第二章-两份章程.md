# 第二章细化：两份章程

> 定稿日期：2026-09-05（初稿 2026-09-04）。上位文档：`02-赏金主线构思.md`；
> 前章：`05-第一章-积压工单.md`。
> 本章职责：双线赏金（星坠/紫菀封存类目），把赏金从"空间站接单"扩展到"遗址星系实地交互"，
> 并用档案室第二层揭出两院的分工真相与**行政核心**的存在。
> 两线档案合读，指向大崩塌前一场**没有会议纪要的投票**。

## 章节结构：双线并行

第一章章末解锁的两份封存工单类目即本章入口。两线**并行开放、互不卡进度，由玩家自行选择
先做哪一单**；但**单条线路内部仍为线性**（单 1 → 2 → 3），两线全部结清后进入章末。

- **FP 预设（单线三单递进）**：**400 / 600 / 800**——从本章开始对赏金难度正式施压
  （全局算法见 02 文档）；
- **词缀数量（单线三单递进）**：**3 / 5 / 7**——词缀系统的完整设定见
  `docs/design/bounty/affixes.md`；
- 报酬：单票 **400,000 ~ 2,000,000** 随难度系数缩放；每线结清奖金 **1,000,000**（最高 5×）。

### 星坠线「武器试验场遗留工单」

**工单性质**：注销/回收试验场中的"未交付资产"。

- 玩法：工单坐标指向**星坠遗址星系**（规格见下节）——武器试验场的
  **总局旧式自动防御系统仍在值班**（模组自动化舰船编成）。
  玩家须击毁/瘫痪防御，随后打捞未交付的设计原型；
- 三单递进：外围警戒平台 → 内环防御群 → 试验场核心库（线末单，高压组合）；
- 档案揭示：星坠理事会的军事遗产规模——**封存舰队清单（存目）**与**未交付设计目录**；
- 基调：兵工厂的两百年静默。武器架上的一切都保养良好，领取窗口积灰两米。

### 紫菀线「科研遗址遗留工单」

**工单性质**：回收科研数据核心。

- 玩法：坐标指向**紫菀遗址星系**（规格见下节）。遗址防御不是炮，是**力场实验产物**——
  偏机制战的遭遇（具体机制随战斗设计另定，原则：紫菀的防御"不接舷"）；
- 三单递进：遗址外缘观测站 → 实验环带 → 核心数据舱（线末单）；
- 档案揭示：**行政核心**的存在与权限——紫菀建造的大型行政 AI，统管签发、审计、
  **清算**权限，是总局"活着的章程"；
- 基调：实验室日志的最后一页都写完了，没人写"停笔"。

### 任务物品锁定规则

设计原型与数据核心为**锁死交互**的任务物品：**不可存放、不可交易、不可丢弃，
只可交付任务**。

## 遗址星系规格

两星系在星图上**距剧情主星系约 30 光年**，随机选取落位，但**固定位于边缘星区**。

### 星坠遗址星系

- **主星**：蓝超巨星。
- **空间站 ×3**：
  1. **星坠设计局主空间站**；
  2. **星坠动力船坞**；
  3. 预留单位（后续内容扩展）。
- **丛林行星 ×1**（固定，名称待定——候选见末节）：
  宜居、污染、大量矿物、大量稀有矿物、炎热、大型废墟、
  **（特殊）星坠工程部遗址**——效果随难度系数缩放：
  - 流通性 +5% ~ +25%
  - 重工业产量 +2 ~ +6
  - 舰队规模 +50% ~ +200%
  - 地面防御 +200% ~ +800%
  - 最大工业设施数量 +1 ~ +3
- **荒芜星球 ×1~3**：随机星球特征。
- **气态巨行星 ×1~2**：随机星球特征。
- **小行星带 ×1**。
- **稳定点 ×4**：通讯中继站、传感器阵列、导航浮标、星门各一。
- **IndEvo 联动**：
  - 丛林行星增设一座**轨道炮台**（磁轨炮类型），星球附加 IndEvo 要求的轨道炮特性；
    炮台对玩家**敌对、主动开火**（注意：与剧情主星系的中立炮台相反——
    这里的防御系统还在执行两百年前的工作），允许玩家主动摧毁/殖民等交互；
  - 星系额外增设 4 个稳定点，均放置**观锚站**。

### 紫菀遗址星系

- **主星**：黑洞。
- **空间站 ×5**：
  1. **紫菀设计局主空间站**；
  2. **紫菀引力船坞**；
  3. **奇点跃迁器**（占位，后续内容扩展）；
  4. 预留位（占位，力场防御系统使用）；
  5. **轨道生活空间站**（固定，名称待定——候选见末节）：宜居、
     **（特殊）视界动力**、**（特殊）紫菀科研部遗址**。
- **视界动力**——效果随难度系数缩放：
  - 最大工业设施数量 +2 ~ +4
  - 所有建筑维护费 -15% ~ -75%
  - 危险度 -10% ~ -50%
  - 令空间站约 **1500 码**范围内的全部舰队**免疫黑洞环境导致的事件视界效果**。
  - 设定：紫菀设计局打造的实验性空间站动力系统，能直接从黑洞周围汲取近乎无限的能量。
- **紫菀科研部遗址**——效果随难度系数缩放：
  - 流通性 +10% ~ +50%
  - 舰队规模 +25% ~ +100%
  - 人口增长 +5 ~ +20
- **荒芜星球 ×1~2**：随机星球特征。
- **冰封星球 ×2~4**：固定**极度寒冷 + 黑暗**特性 + 随机星球特征。
- **气态巨行星 ×2~4**：固定**黑暗**特性 + 随机星球特征。
- **小行星带 ×2**。
- **稳定点 ×4**：通讯中继站、传感器阵列、导航浮标、星门各一。
- **模组联动**：暂无。

## 档案室：第二层

两线推进交替解锁，共 6 份，定题与概要：

| # | 档案 | 内容概要 | 解锁线 |
|---|---|---|---|
| 1 | 《未交付设计目录（星坠理事会 · 存目）》 | 未交付设计 117 项，全部标注"待验收"。验收方一栏：人之领。 | 星坠 |
| 2 | 《封存舰队清单（存目）》 | 只有总数与封存等级，没有舷号。封存等级全部为最高级："非清算令不得启用"。 | 星坠 |
| 3 | 《试验场防御系统值班日志（末页）》 | 最后一行是例行格式："本日无异常。"日期之后，空白延续至今。 | 星坠 |
| 4 | 《行政核心权限白皮书（紫菀理事会）》 | 签发、审计、清算三权集中于一枚核心；附两院联署的授权记录。 | 紫菀 |
| 5 | 《力场实验伦理审查纪要（节选）》 | 紫菀的"守门"气质来源：多段"建议中止"的批注，落款全是紫菀自己。 | 紫菀 |
| 6 | 《两院联合备忘录（残页）》 | 只剩半页：「……表决结果：通过。会议纪要：依动议方要求，不留存。」 | 双线结清 |

叙事功能：#1~#3 立星坠的"遗产规模"；#4~#5 立紫菀的"守门与授权"；
**#6 是本章真正的交付物**——玩家第一次看见那场投票存在过的痕迹。

## 章末钩子

双线结清后，终端打印一张总结算回执，末尾多出两行：

> 「清算序列进度：97.3%。」
> 「提示：核销单 XW-c206-0447／核销-03 的目标识别码与本周期新登记目标重复。
> 按章：重复目标重新挂出。已挂出。」

——序章那艘"违约资产"的识别码，出现在一份**新**工单上。系统不做解释。
（→ 第三章「核销」，中点转折正式开场。）

## 机制对接清单

| 机制 | 本章内的用法 |
|---|---|
| 双线类目 | 星坠/紫菀并行开放、玩家自选接单顺序；单线内线性递进 |
| 遗址星系 | 两个新增特殊星系（规格见上节），距主星系约 30 光年、固定位于边缘星区 |
| 生涯单位交互 | 工单目标须实地前往遗址星系、打捞交割；任务物品锁死交互（仅可交付） |
| 词缀系统 | 单线 3 / 5 / 7 递进；完整设定见 `docs/design/bounty/affixes.md` |
| 舰队规模 | FP 预设 400 / 600 / 800（单线递进），走 02 全局算法 |
| 星币报酬 | 单票 400,000 ~ 2,000,000；每线结清奖金 1,000,000（最高 5×） |
| 承包商等级 | 双线结清后 二级 → 三级 |
| 新增 condition | 星坠工程部遗址 / 视界动力 / 紫菀科研部遗址，数值随难度系数缩放；视界动力含黑洞事件视界免疫光环（约 1500 码） |
| 档案室 | 第二层 6 份，随两线进度交替解锁，残页（#6）须双线结清 |

## 基调守则（本章专用）

- 两条线的遗址文本各带一种静默：试验场是**保养良好的静默**，科研遗址是**写到一半的静默**；
- 行政核心不作人格化描写——白皮书写权限，不写性格；它的"性格"留给清算令原件（第三章）；
- #6 残页全章唯一一次"不平静"的档案，其余档案保持公文体，靠内容而非语气制造不安。
