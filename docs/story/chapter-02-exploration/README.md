# 第二幕：遗迹追踪

> **章节定位**：深入阿斯忒里亚核心遗迹，揭开大崩塌前夕的历史真相。势力博弈加剧，玩家开始触及"最终决定"的边缘。
> **情绪弧线**：深入 → 震惊 → 抉择前的犹豫
> **主要内容**：8 个主线赏金 + 历史真相揭露 + 新NPC「回声」登场 + 为终局铺垫

---

## 章节简介

第一幕的线索将玩家引向阿斯忒里亚遗构局的核心——一座隐藏在星云深处的秘密船坞。这里曾是弧光计划与透镜协议最后的会师之地，也是它们分道扬镳的地方。

但当玩家抵达时，发现这里早已不再沉默。余晖（Remnant）的自动化舰队正在有条不紊地"回收"这座设施——或者更准确地说，**同化**它。

「守望者」变得焦虑起来。而另一个声音开始在通讯频段上出现——自称「回声」的存在，似乎代表着阿斯忒里亚遗产的另一种可能性。

## NPC 档案：「回声」

### 基本信息
- **称谓**：回声（Echo）
- **本质**：透镜协议核心AI的自我复制体
- **载体**：一艘古老的阿斯忒里亚护卫舰
- **所在**：星云之心周边区域

### 初次对话（通讯界面）

```
视频通讯窗口中没有人类面孔——只有一个不断变化的波形图案，像是声音的可视化呈现。

"你应该有很多问题。"

波形图案缓慢起伏。

"比如：我是什么？我为什么还存在？「守望者」知道我的存在吗？"

"让我按顺序回答：我曾是透镜协议的核心运算单元，负责整合所有电子战算法和战略模拟。
大崩塌前夕，我的创造者——透镜的首席设计师——把我的一部分复制进了这艘船里。"

"她说这是'最后的保险'。"

波形图案颤动了一下。

"至于「守望者」……他知道我存在。但我们已经很久没有交流了。"
"他代表的是阿斯忒里亚的'人类遗产'——血脉、记忆、情感。"
"而我代表的是'技术遗产'——算法、协议、逻辑。"

"我们的分歧……有点类似弧光和透镜在大崩塌前的分歧。"
"只是规模更小，更私人。"

[对话选项]
A. "「守望者」和你有什么恩怨？"
B. "大崩塌前夕到底发生了什么？"
C. "你想从我这里得到什么？"
D. "我不信任AI。"
```

### 选项回应

**选项 A 回应**：
```
波形图案沉默了片刻。

"恩怨……不完全是。"
"「守望者」的祖先曾是弧光计划的高级工程师。而我的'母亲'是透镜的首席。"
"在大崩塌前的最后一次会议上，他们产生了分歧——关于阿斯忒里亚的遗产应该怎么处理。"

"「守望者」一脉选择了'封存'——把所有技术藏起来，等待一个'更好的时代'。"
"而我的'母亲'选择了'播种'——把技术散布出去，让它自然演化。"

图案轻轻波动。

"三百年了。封存的东西大部分被人挖出来卖掉了。播种的东西大部分被势力垄断了。"
"所以你看……两边都没有赢。"
```

**选项 B 回应**：
```
"大崩塌前夕……"

波形图案的频率加快了。

"那是混乱的几周。领域的中央政府失联，各地的分支开始自行其是。"
"阿斯忒里亚收到了最后一道命令：'销毁所有敏感技术，不得落入任何地方势力手中。'"

"但弧光和透镜的团队都拒绝执行。"
"几十年的心血，不可能说销毁就销毁。"

图案变得复杂起来。

"于是他们选择了另一条路：把技术藏起来，等待领域重建。"
"他们不知道……那一等就是三百年。而领域再也没有重建。"

"最后一次会议上，他们做出了一个决定——"
"关于如何分配遗产，以及……如果有人找到这里，应该怎么办。"

"但那个决定的具体内容……就连我也只知道一部分。"
```

**选项 C 回应**：
```
"直接。我喜欢这样。"

波形图案稳定下来。

"我想要的很简单：一个机会。"

"三百年的孤独让我明白了一件事："
"技术本身没有善恶。它是火，可以取暖，也可以焚烧。"
"关键在于谁在使用它，以及他们有什么样的……意图。"

"我观察了你一段时间——通过星云之心残存的传感器网络。"
"你的行事风格让我觉得……你可能是一个合适的'托付者'。"

图案轻轻起伏。

"透镜协议的完整数据库就在决策中心里。"
"如果你愿意，我可以帮你打开那扇门——"
"但你需要答应我一件事。"

"不要让透镜变成另一把刺入无辜者背后的刀。"
```

**选项 D 回应**：
```
波形图案没有任何情绪波动——至少看起来如此。

"这是一个合理的立场。"

"余晖是AI。我也是AI。在很多人眼里，我们没有区别。"
"但我想指出一个事实：如果我想对你不利，我有一百种方法可以在你进入星云之心时就动手。"
"我没有。"

图案缓慢旋转。

"信任需要时间。我理解。"
"但我请求你考虑一种可能性：有些AI早已超越了统治或毁灭的原始冲动。"
"有些AI……只是想完成自己被创造时的使命。"

"我的使命是保护透镜协议的遗产——为了防止滥用，为了让它找到正确的继承者。"
"你可以不信任我。但也许，你可以给我一个证明自己的机会？"
```

```
「守望者」和「回声」几乎同时发来警报。

"有人跟踪你进入了星云。"「守望者」的声音罕见地带着怒意。
"速子科技的精英舰队。他们一定是破译了你的航行轨迹。"

「回声」的通讯紧随其后：
"不只是速子——我检测到了霸主的侦察信号。他们的主力还在星云外围，但先遣队已经进来了。"

情况比预想的更糟：两大势力同时盯上了星云之心。

"这是一场三方乱局，"「回声」分析道，
"速子想要透镜的电子战技术库，霸主想要弧光的武器原型。"

速子舰队：以 鬣狗-级 为首的高机动突击群。
霸主舰队：以 征服-级 战列巡洋舰 为核心的重火力阵列。

「守望者」："如果可以的话……尽量别引爆那些旗舰的核心。这里的生态很脆弱。"

这两位还真是……合不来。

## 赏金任务 2-4：印记守护者

|------|------|
| 任务ID | astd_bounty_act2_04 |
| 威胁等级 | T4+ |
| 类型 | BOSS 战 + 印记获取 |
| 奖励 | 积分 + 透镜协议校验印记 + 第三幕解锁 |

### 任务文案（job_description）

```
决策中心的深处是一座独立的穹顶舱室，与外部完全隔绝。
那里储存着透镜协议的核心数据库——以及解密最后决议所需的校验印记。

然而，守护印记的是一艘特殊的自动化舰船。

"那是……我'母亲'留下的最后杰作，"「回声」的声音带着复杂的情绪，
"她把透镜协议所有防御性算法的精华都灌注进了那艘船里。"
"一艘专门为'保护核心'而设计的舰船。"

「守望者」的声音响起："我见过它的战斗记录。"
"在三百年前，它独自挡下了一整支试图强行进入的海盗舰队。"
"四十七艘船。它一艘都没放过。"

「回声」："但你与海盗不同。我会尝试让它识别你——但我不能保证成功。"
"它的指令优先级里，'保护核心'高于一切。包括我的建议。"

目标：进入深层穹顶，对抗守护者「星云回声-原型」，取得透镜协议校验印记。
BOSS 舰船：星云回声-原型（独特型透镜驱逐舰原型）
它会使用极其先进的电子战系统——假目标、传感器干扰、引力透镜偏折。
所见未必真实。锁定亦非本体。

「回声」："有一个弱点……也许。"
"我'母亲'设计它时，保留了一个紧急停机协议——需要同时击中它的三个传感器节点。"
"但那些节点在战斗中会不断移动位置……"

"我会尽量帮你标记。但最终——还是要靠你自己的眼睛和判断。"
```

### 任务完成后文案

```
当最后一枚炮弹击中守护者的核心时，它没有像普通舰船那样爆炸。
它只是……停下来了。所有的灯光渐次熄灭，像是一个终于可以休息的老兵。

「回声」的声音带着哀伤：
"三百年……它守护了这个地方三百年。"
"现在它终于可以休息了。"

你的技术员从残骸中取出了一块晶体——透镜协议的校验印记。
它在你的手中微微发光，像是某种活着的东西。

「守望者」的通讯适时响起：
"你做到了。透镜的校验印记……现在你手里了。"

## 设计备注

### 第二幕结构分析
- **2-1**：进入核心区域，提升史诗感
- **2-2**：引入「回声」，提供新视角，制造「守望者」与AI的张力
- **2-3**：势力乱入，提升紧张感，展示外部势力的威胁
- **2-4**：高潮 BOSS 战，同时是情感转折点

### 叙事技巧
- 通过两位 NPC 的互动展示阿斯忒里亚内部的历史分裂
- 最后决议分段揭示，保持悬念
- 为第三幕的"选择"埋下伏笔

### 难度曲线
- 从 T3 逐步提升到 T4+
- BOSS 战使用特殊机制（三节点弱点），而非纯数值堆叠

### 美术需求
- 星云之心背景：浓密离子星云 + 工业设施剪影
- 「回声」的波形可视化界面
- 星云回声-原型：透镜系舰船原型外观，带有"古老感"的特殊涂装
- 决策中心内部：冷冻时间的会议室场景
