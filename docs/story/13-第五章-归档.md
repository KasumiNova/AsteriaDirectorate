# 第五章细化：归档（结局章）

> 定稿日期：2026-09-05。上位文档：`02-赏金主线构思.md`（第五章节）；
> 前章：`11-第四章-最后一份文书.md`。
> 本章职责：**结局章，无战斗**。承接第四章末的「档案处置申请」，
> 玩家完成归档三选，终端认证"无限期承包商"，解锁随机无限赏金；
> 各势力按选择以不同方式获得总局技术索引碎片（对接势力变强机制）。

## 交互流程

1. 第四章末单结清后，回执提示：「档案处置申请已受理，待经办人到场签署。
   请前往分局空间站终端办理。」——终局不主动追击玩家，它等玩家来签字；
2. 玩家抵达分局空间站，终端进入**归档流程**：归档对象的正式档案名为
   **《菀星设计总局清算序列全宗》**（终端文书口径，下文简称"档案"）；
   终端出示三份拟制文书，分别对应三种归档方式，玩家择一签署（不可多选、不可反悔——
   签署前可退出终端再考虑，文书保持待签状态）；
3. 签署后依次结算：归档回执 → 势力变强机制生效 → 《无限期承包合同》→
   **「执行官」签发** → 最终回执。

## 三选分支

### 选择一：公开（抄送全星区）

> 《档案公开抄送函》：档案全文上传公开网络。抄送栏列着星区所有主要势力的
> 通讯地址，按字母序排列——**包括已灭失的那些**（地址失效不影响抄送流程，
> 依章办理）。

- 机制后果（提案数值）：**全体**势力强度提升幅度最大（+25%）、**立即生效**；
  技术索引碎片人人有份，无差别。
- 附带责任 / 信息代价：抄送函经办人栏署玩家名——**"是谁公开的"随档案一起公开**，
  全星区可查；玩家不保留任何信息优势。

### 选择二：封存（再度封存）

> 《档案封存回执》：档案重新封存，玩家登记为唯一经办人/保管责任人。
> 封存期限栏：「永久（可复查）」。备注栏：上一次封存的经办人签名栏，
> 是空白的。

- 机制后果（提案数值）：势力提升幅度**减半**（+12%）、**延迟若干周期**生效——
  口径：封存阻止不了"见过档案的人"凭记忆复述，碎片经玩家手中的印象缓慢渗漏；
- 玩家保留档案室全部访问权（其余两选下档案室转入"已归档"只读状态）。
- 附带责任 / 信息代价：玩家登记为唯一经办人 / 保管责任人，**保管责任无限期、
  不可转让**；作为见过全卷的人，玩家本人成为唯一的信息节点。

### 选择三：交易（定向移交）

> 《档案定向移交协议》：档案副本出售给选定势力。协议乙方栏由玩家填写——
> 终端提供候选列表，并附各候选方的**报价函**（报价函的落款日期全是两百年前，
> 系统按章保留了当年的询价记录）。

- 机制后果（提案数值）：对象势力提升最大（+50%），其余势力小幅度（+10%）；
  玩家获得一次性巨额报酬（5,000,000 ~ 25,000,000 随难度系数缩放）；
  与对象势力关系显著提升，其余势力微降；
- 附带责任 / 信息代价：协议副本依章留底——**交易行为本身成为可流通的情报**，
  其余势力可经碎片流向比对推断交易方。
- 候选对象列表：星区主要势力（霸主/辛达强权/速子科技/卢德教会等，
  余晖除外——**不向非在编自动智能出售**，这是章程条款，不是价值判断）。

## 无限期承包商认证

签署完成后，终端打印《无限期承包合同》：

> 「合同期限：无限期。续约条款：自动。解约条款：无。
> 欢迎继续合作。」

- **无限赏金解锁**：随机赏金持续生成，词缀全谱系（含 R 型）按难度系数抽取；
- **设定口径**：清算序列完成后，核销系统依章程转入**常设职能**
  （辖区安全维护条款——章程里本来就有的常规条款）。系统没有"下班"这个概念。

## 「执行官」签发（主线奖励）

归档流程完成后，终端签发本局**最后一枚核心「执行官」**（近 O 级——近 O 不等于 O，
口径见 `docs/design/85-AI核心分级设定.md`）：

- 特化**二选一**：战斗特化 / 行政特化，签发时选定、不可更改
  （公文口径：「一经签发，不予退换」）；
- 签发栏只有一行：「依承包商履约记录，特批。」——档案里没有它的编目号，
  它是行政核心为玩家现造的；
- 完整设定（获取口径、统一规则、内幕）见 85 文档 §4.6，本文档不重复数值。

## 势力变强机制

三选影响的是碎片流出的**方式、幅度与节奏**，不影响"是否流出"（02 定案）：

| 选择 | 幅度 | 节奏 | 备注 |
|---|---|---|---|
| 公开 | 全体 +25% | 立即 | 无差别扩散 |
| 封存 | 全体 +12% | 延迟数周期 | 玩家保留档案室访问权 |
| 交易 | 对象 +50%，其余 +10% | 对象立即，其余延迟 | 附巨额报酬与关系变动 |

实现路径（待细化）：舰队质量参数 / 赏金池构成 / 市场装备池的周期性调整事件。

## 结局文本（最终回执）

> 「归档完成。经办人签名已登记。
> 本分局将继续正常运作。
> ——第 205 期年检筹备中。」

（沿用年检序号意象：第一章档案室《分局资产年检报告（连续第 203 期）》、行政核心 204 份年报——
主线通关后，年检进入第 205 期筹备。机构的时间从未停摆。）

## 机制对接清单

| 机制 | 本章内的用法 |
|---|---|
| 归档三选 | 终局唯一决策点；不可反悔（签署前可退出考虑） |
| 势力变强 | 三选控制幅度/节奏/对象；实现路径待细化 |
| 无限赏金 | 结局后解锁；词缀全谱系含 R 型；难度系数照常驱动 |
| 特殊核心「执行官」 | 归档流程完成后由终端签发；战斗/行政特化二选一，选定不可更改（设定见 `docs/design/85-AI核心分级设定.md` §4.6） |
| 档案室 | 封存选保留完整访问权；其余两选转入"已归档"只读 |
| 关系系统 | 交易选：对象势力关系↑、其余微降（数值待定） |

## 基调守则（本章专用）

- 结局没有谢幕：系统不庆祝、不感谢、不道别——它给玩家打印了一份新合同；
- 三选的重量放在**文书措辞**上，不放在动画与音乐上；
- 最终回执与序章的注册确认函使用**同一格式模板**，首尾闭环——
  玩家走完整个主线，在系统眼里只是完成了一次手续。

## 待定项

- 势力变强的具体实现路径与数值（提案幅度 25%/12%/50%/10% 待平衡）；
- 交易选的候选势力完整列表、关系变动数值与报酬区间；
- 无限赏金的生成频率与目标池构成（是否复用主线目标池 + 常规势力目标）；
- 「档案处置申请」签署界面的 UI 呈现（模组总 UI 终端流程）。
