- **封存类目立码**：两份封存工单类目以理事会代号立码——**XC=星坠线**、**ZW=紫菀线**。
  （第一章类目码：YJ=积压、JJ=加急；序章：XW=外勤。）

  签发的最后一批公文。大崩塌发生于 **c+209**，清算程序随之启动（全模组统一口径，见 02）。
- **追加条款栏**：条款 = 改装件编目（affixes.md v3 口径：条款编号 = 改装件编目号，
  S-01~S-08 / M-09~M-14 / R-15~R-17，与词缀清单序号一一对应）。
  本章词缀数按难度系数动态搭配（S 2~4 + M 1~2，无 R），文书内条款为**示例口径**，
  实装时由 UI 按实际抽取结果动态开列。

## 写作口径备忘

- **签发日期 c+208**：封存件是大崩塌前夜签发的最后一批公文——比第一章积压件
  （c+206/207）更晚。积压件是"没来得及派"，封存件是"锁起来之前最后锁的一道门"。
- **编目号映射**：追加条款示例中的 S-01/S-02/S-05 等编号 = affixes.md v3 词缀清单
  序号（S 型 1~8 → S-01~S-08，M 型 9~14 → M-09~M-14，R 型 15~17 → R-15~R-17）；
  引力节点效果无对应词缀，写作"编目外条目"——遗址设施不在改装件标准里，
  这是紫菀"前沿科学"气质的文书表达。
- **紫菀单把执行顺序写进委托事项**："先解除，后回收，顺序不可变更"与游戏内的
  「有一股无形力量排斥」提示互为表里——公文的先见之明，两百年后仍然有效。
- **73,000 日**：两百年按 365 日/年计。总局的计数器精确到日，且仍在走字。
- **回执批注的两线气质**：星坠线批注围着"登记簿/存目/窗口"（武备库的账），
  紫菀线批注围着"报告/收件地址"（实验室的信）——账房先生与实验室助理是同一枚核心。
