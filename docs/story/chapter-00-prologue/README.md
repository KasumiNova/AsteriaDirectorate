# 序章：首次接触

> **章节定位**：玩家进入赏金线的入口点，通过一次"偶然发现"引入阿斯忒里亚遗构局的世界。
> **情绪弧线**：好奇 → 警觉 → 兴趣被勾起
> **主要内容**：2 个引导性主线赏金 + 世界观铺垫

---

## 章节简介

玩家在边缘星系发现一座废弃的领域纪元研究站。设施内的信号仍在循环播放一段三百年前的日志——记录了一个名为"阿斯忒里亚"的军工项目的最后时刻。

一支锈迹斑斑却仍在执行命令的自动化舰队正在设施周围巡逻。击败它们，意味着踏入一条通往领域纪元最后遗产的道路。

---

## 世界观条目：阿斯忒里亚遗构局

*位置：Intel → 势力资料 → 阿斯忒里亚遗构局*

### 概况

阿斯忒里亚遗构局是领域纪元末期的一个军工-科研复合体，曾为领域海军提供先进武器与舰船原型。

大崩塌前夕，该组织内部分裂为两条相互竞争的技术路线：

- **弧光计划（ARC Protocol）**：专注于电弧/等离子体武器与高输出能量系统。其设计理念是"压倒性的正面火力"——在敌人做出反应之前摧毁它们。
  
- **透镜协议（LENS Protocol）**：专注于引力透镜武器与电子战系统。其设计理念是"信息优势决定战场"——让敌人在看不见的地方被击败。

这两条路线的竞争贯穿了阿斯忒里亚最后的岁月。

大崩塌后，阿斯忒里亚的总部失联，分散在各地的研究站、生产设施与实验舰队也陷入沉默。
三百年过去了，偶尔有人报告——在星区的边缘，仍能看到挂着阿斯忒里亚徽标的舰船幽灵般地游荡。

它们在守护什么，在等待什么，早已无人知晓。

### 双线简报

**弧光计划（蓝）**
- 视觉识别：深枪灰底色，电容蓝（Electric Blue）边饰
- 设计语言：楔形轮廓，工业感重
- 代表舰船：弧光耀斑级、激波前锋级

**透镜协议（紫）**
- 视觉识别：暗紫底色，信号紫（Signal Purple）装饰
- 设计语言：不对称结构，传感器阵列突出
- 代表舰船：引力透镜级、星云回声级

## 设计备注

### 序章节奏目标
1. **无痛引入**：T2 难度确保新手也能通过，不造成挫败感。
2. **留下钩子**：通过坐标与项目代号暗示后续内容。
3. **建立基调**：引入"三百年的守望"这一核心意象。

### 美术需求
- 自动化舰队外观：锈蚀涂装变体
- 中继站背景（可选，如果支持战斗背景）
- 信号贩子立绘（可用通用NPC）
