# 第三幕：终局抉择

> **章节定位**：主线收束。揭示阿斯忒里亚“继承者协议”的真意，并以最终Boss战（顶点逻辑级）逼迫玩家做出选择。
> **情绪弧线**：真相揭露 → 失控 → 对峙 → 余温
> **主要内容**：6 个主线赏金 + 1 个终局选择事件 + 2~3 个结局变体（可扩展）

---

## 章节简介

两枚校验印记完成了解密。三百年前的最后会议并非为了“保存技术”，而是为了**筛选继承者**。

弧光与透镜的负责人在终末时刻达成一致：不把遗产交给任何既存势力，不把它封进永远不会开启的墓穴——而是让它自己选择主人。

于是他们造出了“审判者”。

顶点逻辑级（Apex Logic Class），一艘被设计为“规则篡改者”的自动化旗舰。超越守卫与兵器的定义，它即是协议本身。
它只做一件事：对所有觊觎者下达同一个问题——

> 你要用这份遗产，终结战争，还是延长战争？

## 赏金任务 3-1：完整决议

### 任务信息

| 字段 | 内容 |
|------|------|
| 任务ID | astd_bounty_act3_01 |
| 威胁等级 | T4 |
| 类型 | 剧情解密 + 设施防御 |
| 奖励 | 积分 + “继承者协议”条目解锁 |

### 任务文案（job_description）

```
决策中心的投影重新点亮。
两枚校验印记靠在一起，像两段从未真正和解的历史。

「守望者」的声音很轻：
"这是我家族守了三百年的东西。"

「回声」的波形则异常平稳：
"这是我守了三百年的东西。"

投影开始播放——

[日志时间戳：领域纪元 206年，第327天，16:41:12]

弧光负责人站起身来：
"我们不销毁技术，也不把它交给任何势力。"
"我们做一个协议。一个能在未来自动运作的协议。"

透镜首席皱眉：
"你想把选择权交给谁？"

"交给一个陌生人。"弧光负责人说，
"交给那个能穿过废墟，穿过谎言，穿过恐惧，仍然走到这里的人。"

透镜首席沉默很久，最后点头：
"那就需要一个审判者。"

"一个不属于任何一派的审判者。"

屏幕上出现了一个代号：Apex Logic。

就在这时，设施外围响起警报。
速子与霸主的第二波舰队突破了星云边缘，余晖的信号也在同步逼近。

目标：在决策中心完成日志拷贝，并守住设施外围直到传输完成。

战术提示：这是一场延时防御。不要恋战，优先确保数据传输不中断。
```

### 任务完成后文案

```
日志拷贝完成。
但你没有感到轻松。

因为日志最后一段被标注为：
[继承者测试 - 启动条件已满足]

「回声」的波形出现了短促的尖峰：
"……它要醒了。"

「守望者」沉默片刻：
"顶点逻辑级。审判者。"

"三百年前，他们渴望的并非继承遗产的舰队。"
"他们在等一个人……来回答问题。"

[情报更新：继承者协议 - 审判者]
> "审判"这个词在脑海里回荡。不是法律的审判，是命运的审判。
```

## 赏金任务 3-2：逻辑门扉

### 任务信息

| 字段 | 内容 |
|------|------|
| 任务ID | astd_bounty_act3_02 |
| 威胁等级 | T4 |
| 类型 | 突破战 + 特殊机制 |
| 奖励 | 积分 + 终局战入口开启 |

### 任务文案（job_description）

```
星云之心的深层区域开启了。
确切地说，那超越了“开启”的概念。
更像是某个沉睡的系统决定重新工作。

「回声」："顶点逻辑级的唤醒会重写周围的通信规则。
它会把所有进入范围的舰队标记为'候选者'，并强制进入测试流程。"

「守望者」："换句话说——所有人都会被它当成敌人。"

深层通道的尽头是一道巨大的环形闸门。
闸门外侧漂浮着被同化的自动化舰队，像一层层无声的防火墙。

目标：突破逻辑门扉的守卫舰队，进入终局战区域。
守卫舰队：以 极光栅格-级 为节点的立体防御网，填充着大量 磁暴折线-级 与无人机群。

特殊机制：
- 门扉周围的干扰场会周期性刷新“假目标”。
- 假目标不会造成伤害，但会打乱锁定与导弹制导。

战术提示：别被雷达牵着鼻子走。相信目视与近距传感器。
```

### 任务完成后文案

```
闸门打开的瞬间，你感到舰船的惯性像被轻轻改写。

深层区域的空间被某种力场固定成“规整”的几何。
每一块残骸的漂移都像是提前计算过。

「回声」低声（如果AI也能低声的话）：
"它在建立战场。"

「守望者」："它在建立法庭。"

前方的传感器读数突然归零。
然后，一个新的目标出现在屏幕上。

顶点逻辑级。

[终局战解锁：审判者 - 顶点逻辑级]
> 那个身影就在那里。它不仅是一艘船，它是所有规则的具象化。
```

## 赏金任务 3-4：审判者（Boss）

### 任务信息

| 字段 | 内容 |
|------|------|
| 任务ID | astd_bounty_act3_04 |
| 威胁等级 | T5 |
| 类型 | Boss 战（规则型） |
| 奖励 | 积分（大量）+ 终局选择权 |

### 任务文案（job_description）

```
顶点逻辑级没有呼号。
没有挑衅。
它甚至没有开火。

它只是发送了一段简短的协议文本：

"候选者已确认。"
"继承者测试开始。"

下一秒，你的导航屏幕上出现了三条“规则”。
它们作为物理常数被直接写入了这个区域。

规则一：因果延迟。
- 你看到的攻击轨迹，可能是上一秒的结果。

规则二：状态回溯。
- 过载即是死亡，护盾皆为虚妄，相位亦无处避难。

规则三：选择不可撤销。
- 任何试图逃离测试区域的单位将被标记为“放弃者”，并遭到优先处决。

「守望者」："它在逼你正面回答。"
「回声」："它在逼你给出意图。"

目标：击败顶点逻辑级（Apex Logic Class）。
战术提示：
- 它拥有“预知闪避”式的瞬移充能。不要用一发大招去换一次空。
- 它的系统“逻辑崩塌”会破坏你的节奏：注意护盾、相位与系统冷却时机。
- 它以规则为甲，而非厚重的装甲板。打破规则的办法是——让它无处可预测。
```

### 任务完成后文案

```
顶点逻辑级的量子核心在力场中缓缓降温。
它没有爆炸。
它像一段程序完成了最后一行。

最后一条信息出现在屏幕上：

"候选者通过测试。"
"继承者权限开放。"

然后，是一个问题。

"请选择遗产的归宿。"

「守望者」的声音第一次显得脆弱：
"这就是他们的终局。把选择留给你。"

「回声」的波形也变得缓慢：
"这也是我的终局。"

"如果你愿意……也许是新的开始。"

[终局事件解锁：继承者协议 - 归宿选择]
> 寂静降临。所有人都看着你。整个星区的三百年都在看着你。
```

## 终局事件 3-6：继承者协议（选择）

> 这里是“玩家决定”的落点。可在实现时做成对话/选项事件，并绑定奖励与后续可重复赏金池。

### 选项 A：合流（让弧光与透镜再次成为“一体”）

**叙事核心**：技术不属于任何势力，也不应该成为孤岛。你选择让两条路线互相制衡。

**事件文案**：

```
你把两枚校验印记嵌回决策中心的核心槽。

弧光的校验印记发出短促的蓝光。
透镜的校验印记则像深紫色的水面。

它们完美兼容。
它们像是终于承认：对立并非宿命，而仅是路径。

「守望者」轻声说：
"我祖先一直以为封存能保护一切。"
"但封存只是延缓。"

「回声」回答：
"而我一直以为播种能解决一切。"
"但播种只是扩散。"

你按下确认。

系统回馈：
"合流协议已建立。"
"遗产将以双路线形式向继承者开放。"

星云之心的灯光逐段亮起，像一座沉睡的城市重新呼吸。

但你知道，这背后的代价。
合流意味着你要承担两条路线的代价。
火与镜，都会割伤手。
```

**玩法/奖励建议**：
- 解锁：弧光耀斑级（Arc Flare）与 引力透镜级（Gravitational Lens）其一为“立即可获得”，另一为“后续里程碑”。
- 解锁：T4~T5 动态赏金池“继承者协议”系列（带 Affix）。
- 代价：提高后续赏金中敌方对你路线的“针对词缀”概率（可选）。

### 选项 B：封印（把遗产重新埋回废墟）

**叙事核心**：你相信星区配不上这份遗产。

**事件文案**：

```
你没有把校验印记嵌回去。
你只是看着那座三百年前的会议桌。
茶杯早已干涸，但争论的余温还在。

"他们把选择交给我，"你说，
"但我选择让它结束。"

「守望者」没有反对。
他只是闭上眼，像终于完成了世代的守望。

「回声」的波形停顿了很久。

"……我理解。"
"如果这就是你的答案——那么你比很多人更像一个继承者。"

你启动了自毁式封存程序。
星云之心的深层核心开始逐段断电。

最后一盏灯熄灭时，你听见了一个很轻的声音。
像远处电弧断开的“咔”。

也许是技术在叹气。
也许是历史在合上书页。
```

**玩法/奖励建议**：
- 奖励：大量积分/资源、一个“纪念型”装备（非顶级，偏风味）。
- 后续：禁用/弱化双路线独特舰获取；改为更多“普通赏金模板”内容。

### 选项 C：转交（把遗产交给某一方势力）【可选扩展】

**叙事核心**：你承认个人无法承受这份重量，于是让某个势力背负它。

**事件文案（概述）**：
- 转交 TT：透镜相关内容更丰富，但引发电子战军备竞赛。
- 转交 HE：弧光相关内容更丰富，但引发火力军备竞赛。

**玩法/奖励建议**：
- 对应阵营声望大幅提升，解锁阵营版赏金链。
- 另一阵营敌意上升，出现“反制赏金”。

## 设计备注

### 第三幕目标
- 把“继承者协议”的主题落到玩家选择（而不是NPC替玩家决定）。
- 最终Boss不靠纯数值：以顶点逻辑级的“规则破坏”体现其威胁。
- 让结局能自然挂接到“可重复刷”的赏金系统（解锁新赏金池/词缀）。

### 实装对接提示（非强制）
- 终局选择可映射为：解锁不同的赏金 Catalog/权重、不同的 Unique 掉落逻辑。
- 顶点逻辑级的关键观感：瞬移无效化（预知闪避）与节奏破坏（逻辑崩塌）。
- 若需要更“古典引用”风格，可在日志开头加一句短引（例如“因果律只是建议。”已在设定里）。
