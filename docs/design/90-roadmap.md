## 2. 全局设计规则（所有阶段遵守）

1. **玩法自由空间**：不做"惩罚型锁死"设计。偏离定位只损失加成，不常驻惩罚；禁用类效果改为可权衡的软代价。
2. **数值口径**：下限克制、上限放开。凡概率 / 上限 / 浮动类数值，一律给出 **基线值 + 难度缩放上限** 两个数，挂到数值缩放系统（D10）。
3. **文案规范**：禁止"不是/并非…而是…"否定起手句；禁止"闭环/回路/循环"等工程化名词进机制描述（既有专有命名"弧光回路接口"除外）；模式名称用直白词（解限 / 锚定）。
4. **文档即台账**：设计文档必须标注状态（原始案 / 重构中 / 已定案 / 已冻结），文档与实装分叉时以本台账登记的决策为准。
