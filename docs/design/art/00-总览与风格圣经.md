# ASTD 美术总览与风格圣经

> 用途：作为 Asteria Directorate（阿斯忒里亚遗构局）整体视觉开发的总入口，统一世界观语气、阵营视觉、制作边界与跨工种协作口径。

## 1. 项目定位

ASTD 是一个围绕“失落军工文明遗产”展开的 Starsector 模组阵营。它不是单纯的高科技舰队包，而是一个把**历史遗产、技术分裂、自动化守望、继承者审判**融合在一起的叙事型内容集。

视觉上需要同时承载三层信息：

1. **领域纪元末期的大型军工复合体**
   - 要有“曾经庞大、严密、昂贵”的工业文明质感。
2. **三百年后的遗迹与残存秩序**
   - 不是纯废土垃圾感，而是“仍然运行的废墟”。
3. **两条技术路线的哲学分裂**
   - 蓝线 ARC：火力、热量、正面压制、执行。
   - 紫线 LENS：观测、误导、空间扭曲、信息战。

## 2. 世界观关键词

根据 `docs/story/README.md`、`docs/story/STYLE_GUIDE.md` 与主线赏金文本，ASTD 的核心关键词如下：

- 时代断层
- 技术神秘学
- 守望者精神
- 继承者测试
- 被延迟的审判
- 自动化舰队仍在执行命令
- 不是纯粹邪恶，而是“把选择留给未来”的残酷理性

### 应避免的方向

- 过度赛博朋克霓虹
- 夸张宗教神棍风
- 纯原版高科技 TT 复刻
- 纯余晖/Omega 复制品
- 过于脏乱的废品拼装风（除海盗仿制/侧线实验体外）

## 3. 阵营主视觉结构

### 3.1 基底共性：阿斯忒里亚遗构局

所有 ASTD 资产都应共享以下“家族特征”：

- 主体材质偏**高级军工合金 / 陶瓷复合装甲 / 冷色涂层金属**
- 轮廓干净，结构有明确工程逻辑
- 比原版高科技船更“纪律化”、更“工业化”
- 不追求过多装饰，而强调：
  - 功能模块可读
  - 能量路径可读
  - 指挥/感知/散热结构可读
- 常见视觉母题：
  - 外露阵列
  - 几何切面
  - 发光导线/节点
  - 规则重复的模块化单元
  - 仍在工作但经历漫长岁月的设施感

### 3.2 蓝线 ARC（弧光计划）

**叙事语义**：释放、贯穿、撕裂、点燃。

**视觉定位**：
- 正面压制
- 高热负荷
- 武器平台化
- 重工业战舰
- 过驱窗口

**核心配色**：
- 深枪灰 / 炭灰
- 电容蓝（Electric Blue）
- 点缀可使用金白、橙白高温发光

**形体语言**：
- 楔形
- 强对称
- 中轴压迫感强
- 前投影厚重
- 装甲板切面明确
- 大型散热鳍片、导流槽、电容器组外露

**材质印象**：
- 像“昂贵但极端”的实验军工设备
- 表面可有导电回路、热灼痕、过驱发亮边缘

**动态效果关键词**：
- 超频
- 电弧回跳
- 热扭曲
- 高亮光束核心
- 金白/蓝白爆闪
- 直线压制火力墙

### 3.3 紫线 LENS（透镜协议）

**叙事语义**：扭曲、渗透、解构、回响。

**视觉定位**：
- 电子战核心
- 空间控制
- 观测压制
- 无人机/节点/假目标
- 认知欺骗

**核心配色**：
- 暗紫
- 信号紫（Signal Purple）
- 青紫/粉紫作为次级高能点缀
- 局部可加入黑洞感的黑紫、玫红吸积边缘

**形体语言**：
- 不对称
- 开放式结构
- 悬臂、阵列、传感器突起
- 轮廓更像“仪器”而非“装甲盒子”
- 机库、蜂群、节点与透镜结构要明显

**材质印象**：
- 精密、冷静、克制
- 有“数据中心 / 观测设备 / 高级实验室”感
- 可通过点阵灯、扫描线、半透明场表现工作状态

**动态效果关键词**：
- 呼吸灯
- 全息扫描
- 失真
- 局部空间塌缩
- 紫黑裂隙
- 诱导节点 / 干扰蜂群 / 引力透镜

### 3.4 自动化 / 审判者线（AUTOMATED）

**叙事语义**：规则、守望、冷漠执行、测试、协议。

**视觉定位**：
- 不是“野生 AI 怪物”，而是被极端逻辑塑形后的军工造物
- 比 ARC/LENS 更冷、更规则化
- 可借鉴余晖/欧米伽的冷硬感，但必须保留 ASTD 的工程谱系

**核心特征**：
- 六边形栅格
- 折线几何
- 模块化节点
- 白蓝/冷紫发光
- 几乎无有人舰桥痕迹
- “服务器机柜飞船”“算法具象化”的感觉

## 4. 命名与图形语言映射

参考 `docs/story/STYLE_GUIDE.md` 与 `docs/design/ships/00-common.md`：

### 蓝线命名 → 视觉映射

- Arc / Flash / Jet / Flare / Nova / Shockwave / Radiation
- 应联想到：
  - 电弧
  - 烈焰喷流
  - 过热反应堆
  - 强前向冲击
  - 短时爆发

### 紫线命名 → 视觉映射

- Lens / Echo / Nebula / Phantom / Distortion / Tide / Horizon
- 应联想到：
  - 观测阵列
  - 折射/扭曲
  - 假目标
  - 深空迷雾
  - 事件视界

### 自动化命名 → 视觉映射

- Grid / Zigzag / Shimmer / Apex Logic
- 应联想到：
  - 规则图案
  - 逻辑骨架
  - 冷光节点
  - 非人类最优化结构

- 蓝线独特舰：弧光耀斑、断熵弧刃

**ASTD 的视觉不是“未来很酷”，而是“一个过于先进、过于自律、直到文明灭亡仍拒绝停机的旧时代军工幽灵”。**
