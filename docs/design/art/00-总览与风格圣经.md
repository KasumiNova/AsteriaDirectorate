# ASTD 美术总览与风格圣经

> 用途：作为 Asteria Directorate（菀星设计总局）整体视觉开发的总入口，统一阵营视觉、制作边界与跨工种协作口径。
> 叙事框架以 `docs/story/00-组织命名与设定基调.md`、`docs/story/01-势力描述-菀星设计总局.md` 为唯一权威；本文档只做视觉转译，不新增设定。

## 1. 项目定位

ASTD 的内容主体是**菀星设计总局**——人之领旗下曾经最负盛名的军工复合体之一，大崩塌后迅速没落，距今约两百年。模组内容由两部分构成：

1. **两局制式装备**：星坠理事会（ARC，武备端）与紫菀理事会（LENS，观测端）遗留的舰船与武器。
2. **总局的行政主线**：赏金签发、核销、审计——英仙座无政府环境里的中立第三方文书机构。

视觉上需要同时承载三层信息：

1. **人之领旧时代的大型军工复合体**
   - 要有「曾经庞大、严密、昂贵」的工业文明质感。
2. **大崩塌约两百年后的遗物**
   - 不是废土拼装感，而是「仍然完好、仍然昂贵的遗产」。
   - 承认坠落，但不怀旧——不做凭吊式的破败美学。
3. **两局的分工互补（不是分裂）**
   - 星坠理事会：武备端——弹道、能量弧、打击系统。「我们制造坠落的星」。
   - 紫菀理事会：观测端——传感、制导、火控透镜，深耕人工智能与各类力场技术。
   - ARC 负责让星星坠落，LENS 负责让它落在该落的地方：两家是互相依赖的军工组织，视觉上是同一巨头下的两种专业气质，不是对立阵营。

## 2. 阵营视觉关键词

- 旧时代军工遗产
- 纪律化工程
- 两局分工互补
- 行政机构的中立与克制（签发、裁决、记录）

### 应避免的方向

- 过度赛博朋克霓虹
- 夸张宗教神棍风
- 纯原版高科技 TT 复刻
- 纯余晖/Omega 复制品
- 过于脏乱的废品拼装风（遗物可以旧，不能是垃圾）
- 对立阵营式的红蓝对抗视觉（两局不是敌对关系）

## 3. 阵营主视觉结构

### 3.1 基底共性：菀星设计总局

所有 ASTD 资产都应共享以下「家族特征」：

- 主体材质偏**高级军工合金 / 陶瓷复合装甲 / 冷色涂层金属**
- 轮廓干净，结构有明确工程逻辑
- 比原版高科技船更「纪律化」、更「工业化」
- 不追求过多装饰，而强调：
  - 功能模块可读
  - 能量路径可读
  - 指挥/感知/散热结构可读
- 常见视觉母题：
  - 外露阵列
  - 几何切面
  - 发光导线/节点
  - 规则重复的模块化单元
  - 经历漫长岁月但依然完好的设施感

### 3.2 星坠理事会（ARC）

**叙事语义**：投射、弹道、能量弧、打击。「我们制造坠落的星」。

**视觉定位**：
- 正面压制
- 高热负荷
- 武器平台化
- 重工业战舰

**核心配色**：
- 深枪灰 / 炭灰
- 电容蓝（Electric Blue）
- 点缀可使用金白、橙白高温发光

**形体语言**：
- 楔形
- 强对称
- 中轴压迫感强
- 前投影厚重
- 装甲板切面明确
- 大型散热鳍片、导流槽、电容器组外露

**材质印象**：
- 像「昂贵但极端」的实验军工设备
- 表面可有导电回路、热灼痕、发亮边缘

**动态效果关键词**：
- 电弧回跳
- 热扭曲
- 高亮光束核心
- 金白/蓝白爆闪
- 直线压制火力墙

### 3.3 紫菀理事会（LENS）

**叙事语义**：观测、制导、力场。「让它落在该落的地方」。紫菀花瓣放射状排列，形态即一枚光圈叶片/虹膜——「透镜」的植物学隐喻。

**视觉定位**：
- 传感 / 制导 / 火控透镜
- 力场技术（引力光束、涡旋、护盾系）
- 人工智能（无人机、节点、自动化火控）
- 观测压制

**核心配色**：
- 暗紫
- 信号紫（Signal Purple）
- 青紫/粉紫作为次级高能点缀
- 引力系武器使用绯红（引力红移语义，见 `20-武器与特效需求.md` §3.2）

**形体语言**：
- 不对称
- 开放式结构
- 悬臂、阵列、传感器突起
- 轮廓更像「仪器」而非「装甲盒子」
- 机库、蜂群、节点与透镜结构要明显

**材质印象**：
- 精密、冷静、克制
- 有「数据中心 / 观测设备 / 高级实验室」感
- 可通过点阵灯、扫描线、半透明场表现工作状态

**动态效果关键词**：
- 呼吸灯
- 全息扫描
- 失真
- 局部空间塌缩
- 紫黑裂隙
- 诱导节点 / 干扰蜂群 / 引力透镜

### 3.4 自律线（AUTOMATED）

> 该线叙事定位与 design type 均未定案（见 story 00），本节只给视觉方向，不设定任何叙事语义。

**视觉定位**：
- 比 ARC/LENS 更冷、更规则化的军工造物
- 可借鉴余晖/欧米伽的冷硬感，但必须保留 ASTD 的工程谱系

**核心特征**：
- 六边形栅格
- 折线几何
- 模块化节点
- 白蓝/冷紫发光
- 几乎无有人舰桥痕迹

## 4. 命名与图形语言映射

命名体系以 `docs/story/00-组织命名与设定基调.md` 为准：

- **剧情叙述、势力描述、flavor 文本**：用寓意中文名——星坠、紫菀、菀星、总局；不用缩写讲设定。
- **型号/装备命名**：ARC、LENS 作为系列代号前缀。
- **ARC/LENS 展开词**：多版本并存制，任何官方视觉物料不得钦定唯一展开词。

### design type 与显示颜色

| 系列 | design type | 显示颜色 | 视觉对应 |
|---|---|---|---|
| 星坠 | `菀星设计局-星坠` | 淡蓝色 | ARC 电容蓝体系 |
| 紫菀 | `菀星设计局-紫菀` | 淡紫色 | LENS 信号紫体系 |
| 联制（两局联合设计品） | `菀星设计局-联制` | 金色（近橙） | 两局语汇融合 + 金色点缀 |
| 自律线 | 待定（现值 `自律核心`） | 待定 | 见 §3.4 |

hullmod/物品 tooltip 正文中的彩色设计方前缀同样使用 design type 名。

## 6. 资产范围概览

### 舰船
- 独特舰：星坠、淬刃、决明、密蒙、统律
- 量产与变体：各线量产中坚舰、原型版、旧化版、被回收版
- 联制档：锻萼（首舰）

### 武器
- 现役武器全量清单与逐件需求见 `docs/design/art/weapons/`（13 份），统一风格与技术规范见 `docs/design/art/20-武器与特效需求.md`
- ARC 量产：电荷针刺族、电驱加速炮、重型离子脉冲、"穷距"相位轨道炮、正电子冲击波、双子星 DEM
- ARC 稀有/超规格：贯星之矛、"七星"折跃发射器
- LENS：引力坍缩炮族（GCP×4）、辉星 MRM、湮灭涡旋
- 旧版遗留武器集（DRV/SLT/VPD/RCT/JMB/MNL/FDP/TSM/GSP/SGL 及 Ω 变体）已废弃，仅余贴图素材可参考

### 界面
- 词缀图标
- Threat Tier 边框
- Intel / 任务底纹
- 通讯框与协议印记
