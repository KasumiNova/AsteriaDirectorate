# ASTD 美术需求文档索引

本目录用于把 Asteria Directorate 项目的背景设定、舰船/武器设计案与实际数据整理为面向美术团队的可执行文档。

## 文档结构

- `00-总览与风格圣经.md`
  - 阵营总体视觉定位
  - ARC / LENS / 自动化三线风格
  - 世界观关键词与跨工种统一口径

- `10-舰船美术需求.md`
  - 舰船资产分线整理
  - 独特舰、量产舰、自动化舰需求
  - 涂装、轮廓与发光规范

- `20-武器与特效需求.md`
  - 现役武器统一美术风格案（技术规范、线路调色板、验收清单）
  - 逐武器需求索引与交付优先级

- `weapons/`
  - 逐武器美术需求文档（11 份，覆盖现役武器）
  - 每份含：定位读感、现状、资产清单（命名/画布基准）、视觉需求、验收要点

- `30-剧情场景与界面需求.md`
  - UI、词缀图标、Threat Tier 边框
  - Intel、通讯框与协议界面需求
  - 线路识别、印记与标签包装需求

- `40-制作优先级与交付规范.md`
  - 工作包拆分
  - 工种分发建议
  - 交付格式与验收清单

## 建议使用方式

### 如果你是原画/美术总监
先看：
1. `00-总览与风格圣经.md`
2. `10-舰船美术需求.md`
3. `30-剧情场景与界面需求.md`

### 如果你是武器贴图设计
先看：
1. `00-总览与风格圣经.md`
2. `20-武器与特效需求.md`
3. `weapons/` 下对应武器的需求文档

### 如果你是项目统筹/外包对接
先看：
1. `40-制作优先级与交付规范.md`
2. 其余按资产类别分发

## 一句话总结

这套文档的目标是把 ASTD 从“策划案 + 数据表 + 文案设定”转成**可以直接给原画、Sprite、武器贴图与 UI 分工使用的美术需求包**。
