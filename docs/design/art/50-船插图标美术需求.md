# ASTD 船插图标美术需求

> 用途：覆盖本模组全部船插（hullmod）的图标现状盘点与新图标制作需求，供后续统一补齐美术资源。
> 数据来源：`contents/data/hullmods/hull_mods.csv`（45 条）、`contents/data/hulls/*.ship`（内置船插装配范围）、`contents/graphics/hullmods/`（图标现状逐一核查）、`modules/internal/astd-combat/.../hullmods/`（实现类）。
> 风格口径以 `docs/design/art/00-总览与风格圣经.md` 为准。

## 1. 通用规范

### 1.1 尺寸与格式（原版基准）

- 原版船插图标位于 `graphics/hullmods/`，**32×32 px PNG**，透明背景（已在本机原版安装目录逐一抽样验证）。
- 本模组现状图标多为 64×64（游戏内会被缩放显示），其中 `astd_arc_loop_interface.png` 与 `astd_vectorized_jet_array.png` 为 32×32，尺寸不统一，建议补齐时统一为 **32×32 原生**（如交 64×64 高分辨率版，需保证缩至 32×32 后仍可读）。

### 1.2 素材政策（硬性要求）

- **船插图标禁止使用 game-icons.net 素材**（用户明确要求）。
- 全部图标按**自绘 / AI 生图**口径提需求；参考意象仅描述视觉目标，不指向任何现成素材库。
- 现状中 `astd_arc_loop_interface.png`、`astd_vectorized_jet_array.png` 两张为扁平剪影风格（黄色圆形 / 蓝白喷流），与 game-icons.net 典型渲染风格高度一致，**判定为疑似借用，列入替换清单**。

### 1.3 风格口径

- ARC（星坠）系：深枪灰底 + 电容蓝发光，硬几何、导能回路、散热结构。
- LENS（紫菀）系：暗紫底 + 信号紫发光，透镜、节点、波纹、点阵灯；引力系可用绯红点缀。
- 联制档：两局语汇融合 + 金色（近橙）描边。
- 图标需在 32×32 下保持单一识别点，优先剪影可读性，不堆砌细节。

### 1.4 现状判定图例

| 状态 | 含义 |
|---|---|
| 已齐备 | 图标为成稿（非占位、非借用），可直接使用 |
| 占位 | 黑底 + 文件名文字水印的占位图（约 1 KB），或多船插共享同一占位图 |
| 疑似借用 | 文件存在但风格疑似 game-icons.net 素材，需替换 |
| 缺失 | 声明的图标文件在 `contents/graphics/` 下不存在 |
