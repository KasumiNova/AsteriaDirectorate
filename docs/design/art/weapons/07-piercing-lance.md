# 07 贯星之矛 美术需求

> 贯星之矛 `astd_piercing_lance`（大型混合槽 HYBRID，能量结算）
> 实装规格：`docs/design/weapons/impl/09-piercing-lance.md`；线路：ARC 蓝线**稀有掉落**（赏金）

## 1. 定位与读感目标

2 秒充能、单发 2500 极速贯穿的重型长矛，命中沿弹道撕开锥状冲击区。读感应为「蓄力一击的贯穿长矛」——全 ARC 武器库中最强的单发前压姿态，炮口即矛尖。

- 关键词：长矛、充能、贯穿、单发重击

## 2. 现状

- 炮塔/挂点贴图当前为 `graphics/fx/empty.png`，无 `astd_piercing_lance_*` 资产，装配界面无图标
- 弹体视觉已实现（大圆形光弹 + flare 覆盖 w36 glowScale 4，冷蓝白），命中锥面复用共享 `astd_shard_tri.png`，**均不需要新贴图**
- HYBRID 槽：实弹/能量槽皆可装，贴图需在两种槽位上都不违和

## 4. 视觉设计需求

- 单主炮管，前段收束为**矛尖形炮口**（四棱/锥形收口），与轨道炮的细圆口、针刺的针口形成三级区分
- 身管中段环绕**充能线圈/电容环**（2~3 节），冷蓝白 RGB(140,199,255) 发光，蓄能感靠结构表达（充能动画由代码特效负责，贴图静态即可）
- 基座比穷距更厚重前倾，整体投影呈楔形前压姿态
- 配色：深枪灰装甲 + 冷蓝白发光；稀有武器允许一处金白高温点缀（炮口内膛）

## 5. 验收要点

- [ ] 与穷距（细管狙击）、重型离子脉冲（双管重锤）并置时轮廓不混淆
- [ ] 矛尖炮口在图标尺寸下可读
- [ ] 装于实弹槽与能量槽截图各一，均不违和
