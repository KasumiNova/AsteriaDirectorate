# 05 正电子冲击波 美术需求

> 正电子冲击波 `astd_positron_shockwave`（小型能量，点防御 PD）
> 实装规格：`docs/design/weapons/impl/06-positron-shockwave.md`；线路：ARC 蓝线量产（tier1 蓝图）

## 1. 定位与读感目标

近炸破片 PD：射弹贴到导弹/战机锥面即引爆成片破片雨，到最大射程无条件自爆。读感应为「小型速射破片撒布炮」——原版高射炮（Flak）的 ARC 能量版，短粗、泼洒、不精密但可靠。

- 关键词：点防御、近炸、破片雨、短粗多膛

## 2. 现状

- 四件套贴图全为 `BUtil_NONE.png`（全隐），装配界面无图标
- 弹体视觉已由 texTrail 管线承担（白蓝小箭弹 w5 短拖尾），引爆锥面特效复用共享 `astd_shard_tri.png`，**均不需要新贴图**

## 4. 视觉设计需求

- 短粗炮管 + 喇叭形破片撒布口（与电荷针刺的针状收口明确区分：这是「撒」不是「刺」）
- 小尺寸下结构从简：炮管 + 撒布口 + 一处冷蓝白发光点即可，不要堆细节
- 配色：深枪灰 + 冷蓝白 RGB(140,199,255)，明度可比主战武器略低（PD 是配角，不抢主炮视觉）

## 5. 验收要点

- [ ] 26×26 图标下与电荷针刺小型版可区分（喇叭口 vs 针口）
- [ ] 作为 PD 武器在舰上小槽位不喧宾夺主
