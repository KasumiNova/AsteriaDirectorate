# 04 "穷距"相位轨道炮 美术需求

> "穷距"相位轨道炮 `astd_qiongjue_phase_railgun`（大型实弹，射程 1200）
> 实装规格：`docs/design/weapons/impl/05-qiongjue-phase-railgun.md`；线路：ARC 蓝线量产（tier2 蓝图）

## 1. 定位与读感目标

高斯级射程的站桩主炮，同目标连续命中叠层「持续演算」增伤增速。读感应为「长身管电磁轨道狙击炮」——原版高斯炮的 ARC 表达：长、稳、贵。站桩狙杀的武器性格要靠身管长度与基座稳定性传达。

- 关键词：长身管、轨道线圈、狙击、站桩、精密

## 4. 视觉设计需求

- 身管占枪身覆层长度的大头，**分段式轨道线圈**（3~5 节）沿身管均布，线圈间冷蓝白微光
- 炮口为细收口而非喇叭口，配合「细长光矛」弹体观感
- 基座低矮稳定、带驻锄/配重块语义的结构，表达站桩定位
- 配色：深枪灰装甲 + 冷蓝白发光（弹体为高亮白 (0.92,0.95,1)，发光缝可比族内其他武器更亮一级）

## 5. 验收要点

- [ ] 身管长度观感明确超过同尺寸 ARC 武器（对照重型离子脉冲）
- [ ] 66×66 图标下「长管轨道炮」轮廓可读
- [ ] 与原版高斯炮轮廓不撞型
