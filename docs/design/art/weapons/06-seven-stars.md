# 06 "七星"折跃发射器 美术需求

> "七星"折跃发射器 `astd_seven_stars`（大型能量，点防御）
> 实装规格：`docs/design/weapons/impl/07-seven-stars.md`；线路：ARC 蓝线**超规格**（特定赏金/主线限定）

## 1. 定位与读感目标

发射即折跃、固定 7 跳连锁裂隙爆炸的超规格 PD。这件武器**没有可见弹体**（全程隐形，视觉全由折跃电弧与裂隙爆炸脚本承担），因此炮塔本身是它在战场上的唯一常驻可见面，读感必须特殊：不是「炮」，而是「折跃锚定阵列」。

- 关键词：折跃、七节点、锚定阵列、超规格、裂隙

## 2. 现状

- 炮塔/挂点贴图 `astd_seven_stars_turret.png` / `astd_seven_stars_hp.png` 待补（当前 `BUtil_NONE` 顶替），装配界面无图标
- 弹体全隐形为设计刻意，**不需要弹体贴图**
- 折跃电弧 fringe #6FB4FF / core #F0F8FF，裂隙爆炸为蓝色族共享组件，均已实现

## 4. 视觉设计需求

- **7 节点母题**：发射环/锚点上布置可数的 7 个发光节点（对应 7 跳连锁），节点冷蓝白 fringe RGB(111,180,255)、芯 RGB(240,248,255)
- 无传统炮管：开放式环形/叉形锚定结构，中心留空（折跃出口），允许比普通 ARC 武器更「实验设备」化，但保持 ARC 的装甲切面与对称纪律
- 超规格武器的稀有感：结构复杂度允许高于量产武器一档，可加入原版武器没有的非常规轮廓（悬浮环、分离式锚点）
- 配色：深枪灰 + 冷蓝白节点发光，禁止紫色（紫是 LENS 识别色）

## 5. 验收要点

- [ ] 7 节点在图标尺寸下仍可数或可读为「星芒阵列」
- [ ] 与 ARC 量产武器并置时一眼可辨「这不是常规炮」
- [ ] 无炮管结构不与导弹发射架混淆
