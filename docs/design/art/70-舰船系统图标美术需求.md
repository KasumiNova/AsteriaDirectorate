# ASTD 舰船系统图标美术需求

> 用途：覆盖本模组新增全部舰船系统（ship system）的图标现状盘点与新图标制作需求。
> 数据来源：`contents/data/shipsystems/ship_systems.csv`（20 条）+ `.system` 实现类、`contents/data/hulls/ship_data.csv`（装配舰船）、`contents/data/strings/descriptions.csv`（效果描述）。
> 风格口径以 `docs/design/art/00-总览与风格圣经.md` 为准。

## 1. 通用规范

### 1.1 尺寸与格式（原版基准）

- 原版舰船系统图标位于 `graphics/icons/hullsys/`，**64×64 px PNG**，透明背景（已在本机原版安装目录抽样验证）。
- 战斗内系统充能条与改装界面均以 64×64 为基准显示；充能 / 冷却状态由游戏叠灰色遮罩，图标本体无需预留状态层。

### 1.2 素材政策

- 本文档**允许标注 game-icons.net 作为可选素材来源**（用户特许：仅限本文档与殖民地特性图标文档；船插图标不在此列）。
- 也可以自绘 / AI 生图；若用 game-icons.net 素材需记录素材名与授权口径（CC BY 3.0，credits 署名）。

### 1.3 风格口径

- ARC（星坠）系统：电容蓝主导，电弧 / 导能 / 散热意象。
- LENS（紫菀）系统：暗紫 + 信号紫，透镜 / 引力 / 相位 / 蜂群意象；引力系裂隙用绯红。
- 原版借用期间部分系统图标语义偏差明显（如全息分身借用相位cloak图），替换时以效果语义为准重新配意象。

## 3. ARC（星坠）系统（5 条）

### 3.1 落叶飞花 `astd_lh_001_burst_flow`
- 装配舰船：星坠 `astd_xc_001`、飞星（ARC）`astd_lh_001`
- 当前图标：`graphics/icons/hullsys/temporal_shell.png` —— **借用原版**（时间壳）
- 效果：按当前航向附加爆发冲刺动量（150%~300% 最大航速），期间锁定朝向，获得时间流速 / 加减速 / 辐能耗散与武器备弹恢复加成
- 设计意图：一片叶形舰影拖出花瓣状流光残迹，向前冲刺；电容蓝流光，动感是全系统里最强的一档
- 素材建议：game-icons.net 可选方向：leaf / wind / sprint 类剪影

### 3.2 裂隙折跃 `astd_rift_shift`
- 装配舰船：星翼 `astd_xc_002`
- 当前图标：`graphics/icons/hullsys/displacer.png` —— **借用原版**（置换器）
- 效果：进入相位并向鼠标指向折跃（最远 1000su），途中撕开一道虚空裂隙
- 设计意图：舰影前半没入一道垂直裂隙、后半尚在实空间，裂隙按效果描述用紫色描边；虽属 ARC 舰，意象允许偏紫（效果文本即为"紫色裂隙"）
- 素材建议：game-icons.net 可选方向：portal / rift / teleport 类剪影

### 3.3 弧光共享辐能网络 `astd_arc_shared_flux_network`
- 装配舰船：烽燧 `astd_xc_102`
- 当前图标：`graphics/icons/hullsys/ammo_feeder.png` —— **借用原版**（加速弹药供给）
- 效果：开启后友舰获得更宽射击窗口，过量辐能沿链路回灌烽燧，本舰牺牲火力与机动
- 设计意图：旗舰居中向周围友舰放射弧光链路，链路上有辐能回流箭头；电容蓝，与同名船插（`astd_arc_shared_tactical_network`）图标成套设计
- 素材建议：game-icons.net 可选方向：network / share / circuit 类剪影

### 3.4 压制模式 `astd_suppression_mode`
- 装配舰船：列星 `astd_xc_103`
- 当前图标：`graphics/icons/hullsys/ammo_feeder.png` —— **借用原版**
- 效果：锚定为固定火力平台——机动 -50%，武器辐耗 -50%、射程 +30%、射速 +30%，护盾承伤 -30%
- 设计意图：舰影被四根锚定桩 / 驻锄固定，炮口喷焰加大；"钉在地上开火"的静态压迫感
- 素材建议：game-icons.net 可选方向：anchor / turret / deploy 类剪影

### 3.5 装甲护盾增压 `astd_plasma_armor_shield_boost`
- 装配舰船：熔壁 `astd_xc_101`
- 当前图标：`graphics/icons/hullsys/fortress_shield.png` —— **借用原版**（要塞护盾）
- 效果：能量导向装甲护盾，护盾承伤 -50%、装甲承伤 -25%（切换式）
- 设计意图：装甲板表面浮起一层增亮的等离子膜，膜层与装甲融为一体（呼应等离子装甲护盾船插）；建议与 `astd_plasma_armor_shield` 船插图标共享视觉元素
- 素材建议：game-icons.net 可选方向：shield / armor / barrier 类剪影

## 4. LENS（紫菀）系统（7 条）

### 4.1 视界变速 `astd_lh_002_vision_shift`
- 装配舰船：飞星（LENS）`astd_lh_002`
- 当前图标：`graphics/icons/hullsys/quantum_disruptor.png` —— **借用原版**（量子干扰器）
- 效果：本舰获得少量额外时间流速，并锁定一艘敌舰按舰船大小降低其时间流速；期间目标受本舰伤害提高、受其他单位伤害降低
- 设计意图：一对不对等的沙漏 / 双环——本舰环明亮加速，目标环暗淡迟滞，中间一道紫色视线相连；"视界"的观测语义
- 素材建议：game-icons.net 可选方向：hourglass / eye / slow 类剪影

### 4.2 战机引力联结器 `astd_fighter_grav_link`
- 装配舰船：飞蓬 `astd_zw_102`
- 当前图标：`graphics/icons/hullsys/recall_device.png` —— **借用原版**（召回装置）
- 效果：机群时间流速提升 100%~200%、受伤降低，协议结束时全机群折叠回机库
- 设计意图：母舰与若干战机之间拉出引力弦线，弦线末端战机被加速的光轨包围；信号紫，体现"时间轴锚定"
- 素材建议：game-icons.net 可选方向：link / chain / magnet 类剪影

### 4.3 引力空间复制器 `astd_grav_replicator`
- 装配舰船：舜华 `astd_zw_101`
- 当前图标：`graphics/icons/hullsys/entropy_amplifier.png` —— **借用原版**（熵增幅器）
- 效果：激活期间能量武器射弹发射 0.5 秒后在发射点复制两次（50% 伤害 / 50% 辐耗）
- 设计意图：一枚弹体在发射点"重影"成三枚，复制体虚化半透；暗紫 + 绯红引力纹
- 素材建议：game-icons.net 可选方向：duplicate / clone / echo 类剪影

### 4.4 引力裂隙发生器 `astd_grav_rift_generator`
- 装配舰船：茑萝 `astd_zw_103`
- 当前图标：`graphics/icons/hullsys/mine_strike.png` —— **借用原版**（地雷打击）
- 效果：锁定目标舰，在其表面撕开红色引力旋涡并发射裂隙光束，命中处沿舰体周边布下时空引力裂隙（最多 5 枚）
- 设计意图：目标舰剪影表面绽开一枚绯红旋涡，周边散布小型裂隙标记；绯红为主色的引力坍缩语义
- 素材建议：game-icons.net 可选方向：vortex / target / implosion 类剪影

### 4.5 引力磁暴发生器 `astd_grav_storm`
- 装配舰船：密蒙 `astd_zw_002`
- 当前图标：`graphics/icons/hullsys/quantum_disruptor.png` —— **借用原版**
- 效果：充能最多 4 秒后向前方锥形范围释放大量电弧并强制过载目标 1~2 秒，过载还将自身硬辐能按比例转化为软辐能；充能期间 50% 减伤
- 设计意图：锥形爆发区域内密集的紫色电弧风暴，中心一个压缩到极限的能量球；表现"充能—释放"两阶段可用球的压缩程度表达
- 素材建议：game-icons.net 可选方向：lightning-storm / cone / discharge 类剪影

### 4.6 引力相位 `astd_gravity_phase`
- 装配舰船：密蒙 / 舜华 / 茑萝（三舰相位防御系统，替换原版相位cloak）
- 当前图标：`graphics/icons/hullsys/phase_cloak.png` —— **借用原版**（相位cloak）
- 效果：引力投射器将舰体暂时折叠进相位空间，规避一切来袭火力
- 设计意图：舰影被引力透镜"折"进另一侧——一半实体一半扭曲虚影，边缘有光线弯折效果；与原版相位cloak图标区分的核心是引力弯折感而非电子雾
- 素材建议：game-icons.net 可选方向：ghost / eclipse / bend 类剪影

### 4.7 落叶飞花（战机型）`astd_burst_flow_fighter`
- 装配舰船：牵丝 `astd_zw_103_fighter`（茑萝内置重型战斗机）
- 当前图标：`graphics/icons/hullsys/temporal_shell.png` —— **借用原版**
- 效果：1 秒内时间流速 / 加减速 / 弹匣充能大幅提升并附加冲刺动量，最多 2 次充能
- 设计意图：与 3.1 落叶飞花同族但为战机规格——更小的机影、更短的流光；建议与 3.1 成套设计，用体量与残迹密度区分舰载版 / 战机版
- 素材建议：同 3.1
