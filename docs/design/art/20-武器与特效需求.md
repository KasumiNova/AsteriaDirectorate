# ASTD 武器美术需求总案

> 用途：ASTD 现役武器的统一美术风格案与逐武器需求索引。本文档只覆盖**当前已实装的武器**，以 `contents/data/weapons/*.wpn`、`modules/**` 的 VFX 规格与 `docs/design/weapons/impl/**` 为事实源。装饰层 bloom 武器随舰船美术走 `10-舰船美术需求.md`。

## 1. 现状口径（为什么需要这批美术）

本期 13 族武器中，炮座/枪身贴图只有 GCP 族与湮灭涡旋接的是自有贴图（且 6 件武器共用 `astd_ftb_omega_*` 同一对），其余全部为原版占位（龙炎发射架、反物质 SRM 弹头）或空图。

更关键的是：Starsector 的 `.wpn` 没有独立图标键，**装配界面与图鉴里的武器图标直接取 `turretSprite` / `hardpointSprite`**。因此所有填空图（`graphics/fx/empty.png`、`BUtil_NONE.png`）的武器在装配列表里**连图标都是不可见的**。本期美术的第一优先级就是让每件武器都有真实炮座贴图，顺带解决图标问题。

## 2. 技术规范

### 2.1 每件武器的资产构成

| 资产 | 文件槽位 | 必要性 | 说明 |
|---|---|---|---|
| 炮塔底图 | `turretSprite` | 必需 | 兼作装配/图鉴图标 |
| 炮塔枪身覆层 | `turretGunSprite` | 按需 | 需要后坐/分层动画时使用，单体贴图可省略 |
| 炮塔发光层 | `turretGlowSprite` | 必需 | 开火/充能时加法混合显示的发光贴图 |
| 挂点底图 | `hardpointSprite` | 必需 | 隐性安装槽（内置/战机）使用 |
| 挂点枪身覆层 | `hardpointGunSprite` | 按需 | 同上 |
| 挂点发光层 | `hardpointGlowSprite` | 必需 | 同上 |
| 导弹弹体 | `.proj` 的 `sprite` | 导弹类必需 | 实弹/能量弹体已由 texTrail 渲染接管，**不需要** bullet 贴图 |
| 特效贴图 | `graphics/fx/` | 已实现 | 见 §4，原则上不新增 |

### 2.1.1 发光层（_glow）绘制规范

- 与底图**同画布、同对齐**，只画发光部位（发光缝、节点、炮口内膛、线圈充能段），其余区域留空（透明）
- 发光色取 §3 调色板对应颜色，可带由内向外的高亮到透明渐变；引擎负责加法混合与开火时的显隐动画，贴图本身保持常亮状态即可
- 底图上原有的发光区域应相应压暗或留空，避免底图+发光层叠加后过曝
- 一个安装位一张发光层（覆盖底图与枪身覆层的全部发光部位），不逐层拆分

### 2.2 命名与路径约定

- 炮座类：`contents/graphics/weapons/astd_<武器短名>_base.png` / `astd_<武器短名>_gun.png` / `astd_<武器短名>_glow.png`（挂点对应 `_hp.png` / `_hp_gun.png` / `_hp_glow.png`）
- 导弹弹体：`contents/graphics/missiles/astd_<武器短名>.png`
- 武器短名取 `.wpn` id 去掉 `astd_` 前缀（如 `astd_qiongjue_base.png`、`astd_stellar_mrm.png`）；同族多尺寸共用一张底图时按族名命名（如 `astd_charge_needle_base.png` 小/中通用）
- 交付后由开发侧改 `.wpn` 路径接线，美术只交 PNG

### 2.3 方向与结构约定

- 炮座/挂点贴图**炮口朝上**（与原版一致，如 gauss 66×66、annihilator 44×44 均为竖构图朝上）；安装位锚点即旋转轴心：**炮塔锚在画布中心，挂点锚在画布底部 1/4 高度处**（引擎 `WeaponSpriteRenderer.setSpriteCenter` 行为）
- **画布底部不得留全透明死区**：底部死区会把可视主体顶高（挂点武器尤其明显）；底图与发光/蓄能层必须同量裁除，保持同画布对齐
- `.wpn` 炮口偏移约定：`turretOffsets`/`hardpointOffsets` = [前向, 横向]，横向 = 炮口像素 x − 画布宽/2；前向以炮口像素 y（从顶量）计：炮塔 = 画布高/2 − y，挂点 = 3×画布高/4 − y；画布高度变化后偏移须同步回填
- 导弹弹体贴图**弹头朝上**（原版惯例，弹体贴图为竖构图，如 dragonfire 15×24）；**例外**：走 spriteBody 渲染路径（BoxUtil SpriteEntity 接管）的弹体贴图**弹头朝右**（file-right = 飞行正向），如源生冰晶子射弹 `fx/astd_ice_shard.png`，交付前确认该弹体走哪条路径
- 底图为正方形画布、主体居中；枪身覆层与底图同画布对齐

### 2.4 画布尺寸基准（实测原版贴图）

| 槽位 | 炮塔底图基准 | 原版参照 |
|---|---|---|
| 小型 | 24~28 × 24~28 | light_autocannon 26×26 |
| 中型 | 36~44 × 36~44 | ion_cannon 36×36、heavy_autocannon / flak 42×42、dragonfire_rack_med 40×40 |
| 大型 | 64~72 × 64~72 | gauss 66×66、plasma_cannon / tachyon_lance 72×72、dragonfire_launcher_lrg 64×64 |
| 挂点 | 同槽位，纵向可拉长 | gauss_hardpoint 34×68、tachyon_hardpoint 48×72 |
| 导弹弹体 | 宽 13~16 × 长 17~24 | am_srm 13×17、dragonfire 15×24 |

贴图允许超出基准 10~15% 以容纳散热片等外延结构，但炮口前端不得超出画布右缘。

### 2.5 格式

PNG（RGBA），不带调色板压缩；不留 1px 半透明描边杂点；深色主体在游戏深色背景下需自带明度对比。

## 3. 线路视觉规范

阵营总体语汇以 `00-总览与风格圣经.md` 为准，本节只定义武器层的落地规范与**精确调色板**（取自代码实现，特效与贴图必须同色系，不得各画各的）。

### 3.1 ARC 蓝线（星坠理事会）

**职能语义**：直射、速射、贯穿、过驱。武器读感应是「军工速射火炮」而非「科幻光枪」。

**调色板**：

| 用途 | 值 | 色样 |
|---|---|---|
| 能量主色 冷蓝白 | RGB(140,199,255) / 代码 (0.55,0.78,1.0) | 弹体、电弧、发光缝 |
| 亮核 | RGB(240,248,255) | 炮口蓄能、弹头核心 |
| 点缀 电驱黄 | RGB(255,209,64) / 代码 (1.0,0.82,0.25) | 仅电驱加速炮系使用 |
| 高爆暖橙白 | RGB(255,190,130) | 仅双子星高爆弹头使用 |

**形体语言**：炮管粗壮、散热鳍片外露、电容块/导轨/脉冲线圈可读、强对称、装甲切面明确。同级别内按职责区分轮廓（速射=弹匣/复进结构，重锤=双管，长距=长身管线圈）。

### 3.2 LENS 紫线（紫菀理事会）

**职能语义**：观测、诱导、空间扭曲。武器读感应是「仪器」而非「炮塔」。

**调色板**：

| 用途 | 值 | 色样 |
|---|---|---|
| 信号紫 主色 | RGB(168,107,255) / 代码 (0.66,0.42,1.0) | 导弹弹体、EMP 电弧、发光节点 |
| 引力绯红 core（GCP 量产族，亮） | RGB(255,70,70) / fringe RGB(255,25,25) | GCP 族光束核心/边缘、发光缝 |
| 引力绯红 core（湮灭涡旋，深） | RGB(255,60,70) / fringe RGB(180,20,40) | 湮灭涡旋光束核心/边缘 |
| 深寒冰蓝（源生冰晶族专用） | RGB(170,225,255) / 亮核 RGB(224,244,255) | 冰晶母弹/子冰晶、发射架发光缝、星云 |

> 双色系是既有实现：引力系光束武器走绯红（引力红移语义），且量产（GCP，亮）与准超规格（湮灭涡旋，深）分明度层级；制导/干扰系（辉星 MRM）走信号紫；源生冰晶族主题为「深寒」，走独立冰蓝色族，**不套 LENS 紫**。贴图发光色跟随所属子系，不要混用。

**形体语言**：透镜组、节点环、非对称支架、开放式结构、点阵灯与扫描线式的精密设备感。避免常规火炮炮塔语汇。

### 3.3 共通禁止项

- 不得撞型原版高科技（TT 蓝绿三角）与余晖/Omega（红黑生物质）
- 不得使用赛博霓虹渐变与纯装饰性尖刺
- 贴图发光区域配色必须与 §3 对应调色板一致（与弹体/光束特效同屏出现时色偏会立刻穿帮）

## 4. 弹体与特效资产现状（不重做）

以下共享特效资产已实装并经实机评审，**不在本期美术范围内**，新贴图只需在配色上与之协调：

- 拖尾族：`graphics/fx/astd_trails_{twin,smooth,zappy}.png`（另有 zappysmooth/flow/surge/contrail 已注册备用）
- 弹头网格：`graphics/fx/astd_bolt_body.png`
- 锥面破片：`graphics/fx/astd_shard_tri.png`
- 光圈环：`graphics/fx/astd_generated_ring.png`
- 光束束体：暂用原版 `beamcoreb/beamfringeb`，自有束体贴图为低优先可选项
- 实弹/能量弹体视觉全部由 texTrail 管线渲染（原版 bullet 贴图已隐藏），**不需要为弹体绘制贴图**；只有导弹类（双子星、辉星、摧锋、源生冰晶母弹/子冰晶）需要真实弹体贴图

旧版遗留贴图（`astd_drv*/jmb*/mnl*/slt*/tsm*/vpd*/fdp4/gsp12/rct6/sgl8`、`smd_*`）对应已废弃的旧武器集，代码无引用，仅可作风格参考素材，**不得直接接线使用**。

## 6. 通用验收清单

每件武器交付时逐项确认：

- [ ] 炮塔/挂点的底图 + 发光层齐备，尺寸在 §2.4 基准容差内
- [ ] 发光层只含发光部位、与底图对齐，叠加不过曝
- [ ] 炮口/弹头朝上（原版约定）、转轴居中
- [ ] 装配界面图标清晰可读（小尺寸下主轮廓不糊）
- [ ] 发光区域配色与 §3 调色板一致
- [ ] 线路归属一眼可辨（ARC 军工火炮 / LENS 精密仪器）
- [ ] 与既有弹体拖尾、命中特效同屏不偏色（截图对比）
- [ ] 未撞型原版与余晖武器轮廓
- [ ] 命名与路径符合 §2.2，交付物只含 PNG
