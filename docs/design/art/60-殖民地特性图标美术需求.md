# ASTD 殖民地特性图标绘制委托需求

> 委托内容：为模组 Asteria Directorate（菀星设计总局）绘制 4 枚殖民地特性（market condition）图标，用于游戏内殖民地详情界面的特性栏。
> 本文档自足，无需查阅任何其他资料即可开工。

## 1. 项目背景

ASTD 的内容主体是"菀星设计总局"——人之领（旧时代人类星际政权）旗下曾经最负盛名的军工复合体之一。大崩塌之后总局没落，距今约两百年。总局旗下有两个理事会：**星坠理事会**（武备端，主色深枪灰 + 电容蓝）与**紫菀理事会**（观测端，主色暗紫 + 信号紫，引力系技术用绯红）。

本次委托的 4 枚图标对应三处剧情地点的殖民地特性，全部是"大崩塌两百年后仍在运转的总局遗产"。核心气质：**遗址不是废土垃圾，而是仍然完好、仍然昂贵的设施**——承认坠落，但不怀旧，不做凭吊式的破败美学。

三处地点：

- **兰台**：Asteria Seven 星系的宜居行星，总局英仙座第七分局的行政中枢所在地。签发、审计与归档系统在两百年后仍以最低功率运转着。
- **锻原**：Asteria Arc 星系（一颗蓝超巨星）的行星，星坠理事会的武器试验场。自动化锻压线仍按两百年前的工单运转，产出的军备无人问津，也无人停机。
- **拾光**：Asteria Lens 星系（一个黑洞）轨道上的生活空间站，紫菀理事会遗留的轨道设施，至今仍在黑洞边全功率运转。

## 2. 全局风格要求

- 原版游戏此类图标为剪影主体 + 单色发光点缀的扁平语汇，新图标需与原版图标并置时不突兀。
- 四枚图标共享一个家族特征："遗产仍在运转"的待机微光——主体是静默的设施剪影，但必有一处克制的发光细节表明它并未死去。
- 40×40 像素下单主体剪影清晰可读，不堆砌细节。
- **禁用方向**：废墟垃圾场式的破败美学、过度霓虹、宗教神棍风。
- 素材政策：可参考 game-icons.net 等图标库的构图方向，但必须重绘为统一风格，不得直接使用库内素材。

## 3. 交付规格

- 尺寸：40×40 px（原版基准尺寸，游戏内原生显示，不做缩放容错假设）。
- 格式：PNG，透明背景，主体居中、四边留 1~2 px 呼吸边距。
- 命名：`astd_<条目ID>.png`（逐条目 ID 见下文，例如 `astd_event_horizon_power.png`）。
- 投放目录：`graphics/icons/markets/`。

## 4. 委托条目

共 4 枚。

### 1. 菀星行政部遗址 `astd_wanxing_admin_ruins`
- 所在殖民地：兰台（Asteria Seven 星系）。
- 特性效果：提升殖民地的流通、收入、稳定与舰队规模——两百年前的行政便利至今仍在无人申请地自动提供。
- 背景：总局的行政中枢。这里的核心意象不是"废墟"，而是"官僚机构的秩序感"：签发、审计、归档，运转如常。
- 画面：一栋保存完好的机构建筑正面剪影（对称、柱廊或方正式轮廓），画面前景叠一枚签发印章 / 印鉴的圆形轮廓，或一角悬着一张待办签呈的剪影；建筑某扇窗口透出一点微光，表示系统仍在最低功率运转。
- 配色与光效：主体暖灰石材质感，发光细节用克制的金白色（总局行政色系）。

### 2. 星坠工程部遗址 `astd_starfall_engineering_ruins`
- 所在殖民地：锻原（Asteria Arc 星系）。
- 特性效果：提升流通、重工业产量、舰队规模、地面防御与工业设施上限——自动锻压线仍在按两百年前的工单产出军备。
- 背景：星坠理事会的武器试验场，无人产线至今运转。重工业、军备、高热。
- 画面：一组重工业厂房 / 锻压机架的剪影（横梁、立柱、烟囱或压机锤头任选其一为主体），构图横向稳定；锻压口或产线缝隙透出刚锻造完成的高热发光。
- 配色与光效：主体深枪灰，发光用电容蓝到橙白的高温热色（星坠谱系）。

### 3. 视界动力 `astd_event_horizon_power`
- 所在殖民地：空间站"拾光"（Asteria Lens 星系，黑洞轨道）。
- 特性效果：增加工业设施上限、大幅降低建筑维护费与危险度，并为附近舰队屏蔽黑洞环境——力场锚定在事件视界边缘，直接从黑洞汲取近乎无限的能量。
- 背景：紫菀理事会打造的实验性空间站动力系统。四枚图标中**唯一仍在全功率运转**的设施，发光可以最亮。
- 画面：一个小型空间站 / 采能环剪影悬在画面上缘，下方（或背景）是黑洞的吸积盘弧光——一道被引力弯成弧形的亮带；空间站与吸积盘之间以一道细力场线相连，表现"锚定在事件视界边缘"。
- 配色与光效：吸积盘用绯红（引力红移语义）到亮橙的渐变，空间站剪影暗紫，力场线信号紫。

### 4. 紫菀科研部遗址 `astd_aster_research_ruins`
- 所在殖民地：空间站"拾光"（与第 3 条同一殖民地并列显示，两枚图标需可明显区分）。
- 特性效果：提升流通、舰队规模与移民吸引力——研究设施遗址。实验室日志的最后一页都写完了，没人写"停笔"。
- 背景：紫菀理事会的研究设施，观测与制导技术的心脏。气质是精密仪器，而非工业厂房。
- 画面：一组实验舱 / 观测透镜阵列的剪影（圆环形镜组 + 支架为主体），镜组某处仍亮着一点扫描微光；可加 2~3 个悬浮的仪器舱小剪影增加层次。
- 配色与光效：主体暗紫灰，发光用信号紫点阵灯（紫菀谱系），与第 3 条的绯红黑洞暖光形成冷暖区分。
