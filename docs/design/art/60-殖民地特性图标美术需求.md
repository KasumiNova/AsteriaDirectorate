# ASTD 殖民地特性图标美术需求

> 用途：覆盖本模组新增全部殖民地特性（market condition）的图标现状盘点与新图标制作需求。
> 数据来源：`contents/data/campaign/market_conditions.csv`（4 条）、`modules/internal/astd-campaign/.../world/StoryConditions.kt`（效果实现）、`StorySystemSpecs.kt` / `strings.json`（所在殖民地与星系）。
> 风格口径以 `docs/design/art/00-总览与风格圣经.md` 为准。

## 1. 通用规范

### 1.1 尺寸与格式（原版基准）

- 原版殖民地特性图标位于 `graphics/icons/markets/`，**40×40 px PNG**，透明背景（已在本机原版安装目录抽样验证）。
- 殖民地界面特性栏以 40×40 原生尺寸显示，图标需在该尺寸下直接可读，不做缩放容错假设。

### 1.2 素材政策

- 本文档**允许标注 game-icons.net 作为可选素材来源**（用户特许：仅限本文档与舰船系统图标文档；船插图标不在此列）。
- 也可以自绘 / AI 生图；若用 game-icons.net 素材需在交付时记录具体素材名与授权口径（CC BY 3.0，需在模组 credits 署名）。

### 1.3 风格口径

- 四个特性均为"大崩塌两百年后仍在运转的总局遗产"：遗址不画成废土垃圾，画成"仍然完好、仍然昂贵的设施"。
- 行政类（菀星）用金白 / 暖灰的克制官僚感；星坠系用电容蓝工业感；紫菀系用暗紫 + 点阵灯的仪器感；黑洞相关可用绯红引力语义。
- 与原版图标并置时风格不应突兀：剪影主体 + 单色发光点缀的原版语汇。

## 3. 逐条需求

### 3.1 菀星行政部遗址 `astd_wanxing_admin_ruins`
- 当前图标：`graphics/icons/markets/ruins_widespread.png` —— **借用原版**（广泛遗址图标）
- 所在殖民地 / 星系：兰台（condition-only 市场）·"菀星第七分局"星系
- 效果：流通 +10~50%、收入 +5~20%、稳定 +1~4、舰队规模 +25~100%（随难度系数缩放；兰台当前形态下叙事效果为主）
- 设计意图：行政中枢遗址——档案网格 / 签发印章轮廓叠在保存完好的机构建筑剪影上，金白微光；关键词"签发、审计、归档系统两百年后仍以最低功率运转"。与原版泛用遗址拉开差异的核心是"官僚机构的秩序感"，可加一枚待办印章 / 印鉴元素
- 素材建议：自绘或 AI 生图优先；game-icons.net 可选方向：seal / archive / temple-gate 类剪影

### 3.2 星坠工程部遗址 `astd_starfall_engineering_ruins`
- 当前图标：`graphics/icons/markets/ruins_vast.png` —— **借用原版**（庞大遗址图标）
- 所在殖民地 / 星系：锻原（condition-only 市场）·"星坠"星系（蓝超巨星）
- 效果：流通 +5~25%、重工业产量 +2~6、舰队规模 +50~200%、地面防御 +200~800%、最大工业设施 +1~3（重工业加成当前叙事为主）
- 设计意图：武器试验场 + 自动化锻压线——厂房 / 锻压机架剪影 + 电容蓝火花与过热发光边缘，"仍在按两百年前的工单运转"的无人产线感；ARC 重工业气质
- 素材建议：自绘或 AI 生图优先；game-icons.net 可选方向：factory / anvil / forge 类剪影

### 3.3 视界动力 `astd_event_horizon_power`
- 当前图标：`graphics/icons/markets/solar_array.png` —— **借用原版**（太阳能阵列图标）
- 所在殖民地 / 星系：轨道生活空间站"拾光"（FULL 市场，效果真实生效）·"紫菀"星系（黑洞）
- 效果：最大工业设施 +2~4、建筑维护费 -15~75%、危险度 -10~50%；另为附近舰队提供 1500su 事件视界环境免疫（生涯脚本承担）
- 设计意图：黑洞吸积盘 + 锚定在事件视界边缘的力场环 / 采能空间站剪影；绯红（引力红移语义）+ 暗紫，是四个特性里唯一"仍在全功率供能"的设施，发光可以最亮
- 素材建议：自绘或 AI 生图优先（黑洞意象 game-icons.net 覆盖较弱）；可选方向：eclipse / vortex 类剪影

### 3.4 紫菀科研部遗址 `astd_aster_research_ruins`
- 当前图标：`graphics/icons/markets/rogue_ai.png` —— **借用原版**（失控 AI 图标）
- 所在殖民地 / 星系：空间站"拾光"·"紫菀"星系（与 3.3 同市场并列显示）
- 效果：流通 +10~50%、舰队规模 +25~100%、移民权重 +5~20（真实生效）
- 设计意图：研究设施遗址——透镜阵列 / 实验舱剪影 + 点阵紫灯与扫描线，"实验室日志最后一页都写完了"的完好但无人感；LENS 仪器气质
- 素材建议：自绘或 AI 生图优先；game-icons.net 可选方向：lens / network / laboratory 类剪影
- 备注：借用 `rogue_ai.png` 与"科研遗址"语义偏差较大（AI 叛乱 vs 研究设施），替换优先级四个中最高

## 4. 替换优先级

1. `astd_aster_research_ruins` —— 借用图语义偏差最大
2. `astd_event_horizon_power` —— 剧情核心星系招牌特性，太阳能阵列图无法承载黑洞意象

4. `astd_starfall_engineering_ruins` —— 现借用图语义偏差最小，可最后做
