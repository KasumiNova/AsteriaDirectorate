# ASTD 界面美术需求

> 用途：面向 UI 边框、词缀图标、Intel 视觉包装、通讯框、标题底图与协议印记制作。信息来源主要来自 `docs/design/bounty-expansion-requirements.md` 与现有阵营设定文档。

## 1. 目标

ASTD 的 UI 资源承担以下职责：

- 帮助玩家快速区分 ARC、LENS 与自动化 / 审判线
- 在小尺寸下准确传达威胁等级、词缀类型与协议状态
- 让通讯、Intel 与赏金界面共享统一的视觉系统
- 用边框、底纹、图标与协议纹样强化阵营身份

---

## 2. 视觉系统

## 2.1 ARC（蓝线）UI

### 关键词
- 硬几何
- 电容蓝
- 热量约束
- 工业级边框

### 视觉方向
- 线条厚实，转角明确，适合表现高压能量回路与重型军工感
- 可使用导能线、分段电容槽、矩形或楔形框体作为基础语汇
- 发光应集中在边缘节点、主标签区与激活标记区

## 2.2 LENS（紫线）UI

### 关键词
- 节点
- 波纹
- 透镜
- 干扰投影

### 视觉方向
- 轮廓可以更轻、更精密，允许局部非对称与镜组结构
- 可使用同心环、观测点、波形线与点阵网格强化“信息投影”印象
- 发光层应保持克制，优先服务信息层级与状态提示

## 2.3 自动化 / 审判线 UI

### 关键词
- 冷感几何
- 协议印记
- 双核
- 规则裁决

### 视觉方向
- 采用高度纪律化的几何构图，减少情绪化修饰
- 可使用双重边框、垂直中轴、规则化节点和冷白 / 冷蓝对比强化压迫感
- 适合承载高威胁等级、协议校验和终局类标签

---

## 3. 核心 UI 资源需求

## 3.1 赏金词缀图标

至少需要支撑以下词缀组：

### ARC 词缀组
- 超频线圈
- 零余量纪律
- 电弧共振

### LENS 词缀组
- 干扰节点
- 相位不稳定
- 引力透镜

### 通用技术词缀组
- 熵化护盾
- 超压推进

### 图标设计原则
- 小尺寸下保持清晰可读
- ARC 图标优先使用硬边几何、电光、热量与导能结构
- LENS 图标优先使用节点、透镜、波纹与干扰网格
- 通用词缀图标优先表现系统结构与协议层级

## 3.2 Threat Tier / 边框资源

按威胁等级 T1–T5 设计统一 UI 套件：

- 边框
- 背景底纹
- 标签底板
- 小图章或角标

### 视觉建议
- T1–T2：工业级、克制、信息优先
- T3：发光与边缘强调适度提升
- T4：加入更复杂的协议纹样与结构层次
- T5：使用强对比边框、终局纹样与审判级识别符号

## 3.3 Intel / 任务界面元素

建议统一以下资源：

- 标题底图（Intel / 通讯共用视觉母版）
- Intel 卡片底纹
- 任务标签底板
- 协议章印与校验标记

### 设计要求
- 标题底图与 Intel 卡片保持同一视觉家族
- 标签底板需要兼容不同威胁等级与线路颜色
- 协议章印可以作为赏金与终局事件的通用识别件

## 3.4 通讯框与协议界面

建议至少准备以下样式：

- ARC 通讯框：稳定、硬边、蓝线导能感
- LENS 通讯框：节点化、透镜化、带轻度波形结构
- 继承者协议界面：双重校验、印记、冷感几何底纹（同名机制资产命名沿用，界面语言待剧情重做后复核）
- 审判级警示覆盖：高对比边框、异常状态角标、规则化标记

### 设计要求
- 通讯框需要兼容头像、文本、选项与状态提示四类元素
- 协议界面应支持标题底图、警示标签、验证印记与特殊事件包装
- 审判级样式要与普通任务 UI 保持明显层级差异

## 3.5 通用小图标与印记

建议补充以下通用 UI 元件：

- 双重校验标记
- 协议锁定标记
- 阵营印记
- 审判级警告角标
- 阵营通道 / 线路识别小图标

这些元件应与赏金词缀、Threat Tier 与 Intel 包装共享基础线条与色彩逻辑。

---

## 4. 资源范围

界面资源建议覆盖以下类型：

- 词缀图标套件
- Threat Tier 边框套件
- Intel 与任务底纹
- 通讯框样式
- 协议界面底图
- 通用印记、角标与标签底板

所有资源都应优先适配 Starsector 的小尺寸显示环境，并保证与舰船、武器两类资源共享同一阵营识别体系。

---

## 5. 检查清单

- [ ] UI 资源是否能帮助区分 ARC、LENS 与自动化 / 审判线
- [ ] 图标在小尺寸下是否仍可识别
- [ ] 边框、底纹与角标是否共享统一视觉语汇
- [ ] Threat Tier 各等级是否具备稳定层级差异
- [ ] 通讯框与协议界面是否兼容实际文本与标签布局
- [ ] 整套 UI 是否与舰船、武器资源保持统一的工业科幻气质
