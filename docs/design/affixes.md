## 真实设定（in-universe）

词缀 = **菀星设计总局的通用改装标准（改装件）**。

- 定位：**军官技能 Pro**——以标准化改装件形式存在的舰队强化，层级即稀有度：
  **R >> M > S**，越高层级的改装件越稀有、提供的强度越高。
- 数值与数量均受**难度系数**影响。
- 叙事口径：赏金目标身上搭载的改装件是总局标准品，核销系统按编目号识别，
  在赏金文书的"追加条款"栏列出（条款编号 = 改装件编目号，沿用 06 文书既有口径，
  无需改名）。

## 搭配规则（按难度系数抽取）

| 类型 | 数量 | 出现条件 |
|---|---|---|
| S 型 | 2 ~ 4 | 始终 |
| M 型 | 1 ~ 2 | 始终 |
| R 型 | 1 ~ 2 | **仅第三章赏金与结局后的无限赏金** |

- R 型在允许出现的章节内仍按高稀有度走低权重。
- 原"章节数量挂钩表"（序章 0 / 一批 0 / 二批 1~2 / 三批 3 / 二章 3/5/7）作废：
  词缀数量完全由难度系数搭配表决定（D20 定案）。
- 组合约束：
  - 同 ID 词缀不叠加；
  - **互斥表**：
    - 六相冰辐能网络 ↔ 极限辐能线圈扩容；
    - 相位线圈调谐 ↔ 相位线圈降频；
    - 电网深化升级（含六相冰捆绑效果）↔ 极限辐能线圈扩容；
  - **舰船约束**：相位线圈调谐 / 相位线圈降频 / P空间深潜器 仅相位舰船可搭载。

## 数值规范

- "X% ~ Y%" 区间 = 难度系数 1.0 取下限、5.0 取上限，分段线性映射
  （80 文档三锚点写法的区间简写：v1 = 下限，v5 = 上限，v2 = 区间中点）。
- 舰船大小分档顺序统一为：护卫舰 / 驱逐舰 / 巡洋舰 / 主力舰。
- "最终乘区" = 在全部其他修正计算完成后最后叠乘。

## S 型词缀（8 条）

### 1) 铁甲重装
- **ID**：`astd_affix_ironclad_plating`
- 按难度系数：提升舰船 **15%~45%** 最大装甲值（最终乘区）。
- 按舰船大小与难度系数：提升最小装甲计算值 **50~100 / 100~200 / 200~400 / 300~600**。
- 降低 **15%** 最大航速与机动性（最终乘区）。
- 实现路径：纯 HullMod。

### 2) 六相冰辐能网络
- **ID**：`astd_affix_cryo_flux_network`
- 按难度系数：提升 **10%~20%** 辐能耗散；提升 **20%~40%** 强制排辐速率；
  降低 **20%~40%** 受到的 EMP 伤害（最终乘区）。
- 与极限辐能线圈扩容互斥。
- 实现路径：纯 HullMod。

### 3) 极限辐能线圈扩容
- **ID**：`astd_affix_flux_coil_expansion`
- 按难度系数：提升 **20%~40%** 辐能容量（最终乘区）。
- 降低 **20%** 辐能耗散。
- 与六相冰辐能网络互斥。
- 实现路径：纯 HullMod。

### 4) 极化护盾发生器
- **ID**：`astd_affix_polarized_shield`
- 按难度系数：降低 **25%~50%** 护盾受到的伤害（最终乘区）。
- 提升 **50%** 舰船过载时间。
- 实现路径：纯 HullMod。

### 5) 引擎超频
- **ID**：`astd_affix_engine_overclock`
- 按难度系数：提升 **25%~50%** 最大航速（最终乘区）。
- 降低 **25%** 机动性。
- 实现路径：纯 HullMod。

### 6) 维度专长
- **ID**：`astd_affix_dimensional_specialty`
- 按难度系数：提升 **100%~200%** 峰值时间；降低 **25%~50%** CR 削减速率（最终乘区）。
- 按难度系数：降低舰船系统 **10%~20%** 充能时间与 **10%~20%** 冷却时间（最终乘区）。
- 实现路径：纯 HullMod。

### 7) 相位线圈调谐
- **ID**：`astd_affix_phase_coil_tuning`
- 按难度系数：提升 **50%~100%** 相位状态下的时间流速（最终乘区）。
- 按难度系数：提升 **100%~200%** 峰值时间；降低 **25%~50%** CR 削减速率（最终乘区）。
- 仅相位舰船可搭载；与相位线圈降频互斥。
- 实现路径：纯 HullMod。

### 8) 相位线圈降频
- **ID**：`astd_affix_phase_coil_detuning`
- 按难度系数：降低 **25%~50%** 相位状态下的时间流速（最终乘区）。
- 按难度系数：降低 **25%~50%** 相位状态下的辐能产出；降低 **25%~50%** 相位线圈冷却时间。
- 仅相位舰船可搭载；与相位线圈调谐互斥。
- 实现路径：纯 HullMod。

## M 型词缀（6 条）

### 9) 递归式目标定位系统
- **ID**：`astd_affix_recursive_targeting`
- 按难度系数与舰船大小：每艘友军舰船（**不含自身与舰载机**）为自身额外提供
  **1%~2% / 2%~4% / 3%~6% / 4%~8%** 舰船武器最大射程，以及同数值的
  能量与实弹武器射弹飞行速度；
  上限：射程最大 **15%~30% / 20%~40% / 30%~60% / 40%~80%**，
  射弹飞行速度最大 **40%~80%**（最终乘区）。
- 实现路径：HullMod（编队光环，需逐帧友军扫描计数）。

### 10) 反应式辐能装甲
- **ID**：`astd_affix_reactive_flux_armor`
- 按难度系数：降低 **75%~90%** 强制排辐期间受到的装甲与船体伤害（最终乘区）。
- 强制排辐速率降低 **35%**。
- 实现路径：纯 HullMod（排辐状态判定 + 伤害修正）。

### 11) P空间深潜器
- **ID**：`astd_affix_pspace_diver`
- 按难度系数：降低 **50%~100%** 相位舰船因相位期间硬辐能水平提升导致的
  最大航速降低效果（最终乘区；100% = 完全免疫该降速）。
- 仅相位舰船可搭载。
- 实现路径：纯 HullMod。

### 12) 引擎辐能网隔离
- **ID**：`astd_affix_engine_flux_isolation`
- 按难度系数：提升 **20%~40%** 零辐能加速阈值；
  提升 **25%~50%** 零辐能加速的航速增益（最终乘区）。
- 实现路径：纯 HullMod。

### 13) 蜂群协同网络
- **ID**：`astd_affix_swarm_coordination`
- 按难度系数：每存在一艘**全自动**友军舰船（判定口径：具有"全自动舰船"船插，
  或舰船军官为 AI 核心），为自身额外提供 **1%~2%**
  全伤害减免与非导弹武器射速提升；上限 **25%~50%**（最终乘区）。
- 实现路径：HullMod（编队光环，逐帧友军扫描计数，过滤全自动舰）。

### 14) 等离子装甲护盾
- **ID**：`astd_affix_plasma_armor_shield`
- 按难度系数：舰船护盾获得 **20%~40%** 的装甲计算值减免；
  具体机制参考同名船插「等离子装甲护盾」的既有实现。
- 实现路径：复用同名船插机制（HullMod）。

## R 型词缀（3 条）

### 15) 电网深化升级
- **ID**：`astd_affix_grid_deepening`
- 强制获得**六相冰辐能网络**与**反应式辐能装甲**的提升效果；
  并按难度系数：提升 **25%~50%** 强制耗散速率；提升 **10%~20%** 硬辐能耗散速率
  （最终乘区）。
- 优化自动驾驶（包括友军舰船）AI 的强制排辐机制，使其更智能、激进
  （排辐 AI 参考 Polaris_Prime 模组的排辐优化 AI 实现）。
- 与极限辐能线圈扩容互斥（捆绑六相冰效果，避免规则冲突）。
- 实现路径：HullMod（数值与捆绑效果）+ AI 行为侧（排辐决策改造）。

### 16) 激进式集群作战网络
- **ID**：`astd_affix_aggressive_swarm_network`
- 按难度系数：获得 **100%~200%** 指挥点恢复速率（最终乘区）。
- **歼灭指令**：每隔 **45 秒**（固定值，不随难度系数缩放），对敌方部署点最高的单位发起
  歼灭指令，至少一半左右的舰船响应，持续 30 秒：
  - 按难度系数：响应舰船对目标造成的伤害提升 **15%~30%**；
    目标舰船受到响应舰船造成的伤害降低 **15%~30%**（最终乘区）。
- 实现路径：HullMod（指挥点恢复）+ CombatPlugin（歼灭指令事件与伤害修正）
  + AI 行为侧（指令响应）。

### 17) 奇点驱动
- **ID**：`astd_affix_singularity_drive`
- 按难度系数：舰船获得 **300%~900%** 峰值时间；降低 **20%~40%** 武器产生的辐能；
  免疫所有环境导致的峰值时间降低效果；降低 **25%~75%** 过载时间（最终乘区）。
- 舰船获得子系统**「奇点爆发」**（MagicSubSystem）：
  - 按难度系数：激活时逐渐提升 **100%~200%** 时间流速，持续 10s，
    冷却 20s，不可充能；
  - AI 逻辑沿用原版「时流之壳」。
- 实现路径：HullMod（数值）+ MagicSubSystem（子系统）+ 复用时流之壳 AI。

## 实现路径汇总

| 路径 | 词缀 |
|---|---|
| 纯 HullMod | 铁甲重装 / 六相冰辐能网络 / 极限辐能线圈扩容 / 极化护盾发生器 / 引擎超频 / 维度专长 / 相位线圈调谐 / 相位线圈降频 / 反应式辐能装甲 / P空间深潜器 / 引擎辐能网隔离 / 等离子装甲护盾（复用船插） |
| HullMod + 编队光环扫描 | 递归式目标定位系统 / 蜂群协同网络 |
| HullMod + AI 行为侧 | 电网深化升级（排辐 AI）/ 奇点驱动（MagicSubSystem + 时流之壳 AI） |
| HullMod + CombatPlugin + AI | 激进式集群作战网络（歼灭指令） |
