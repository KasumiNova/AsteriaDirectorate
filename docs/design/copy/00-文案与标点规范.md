# 文案与标点符号使用规范

> 适用范围：全部游戏内可见文本（descriptions、tooltip、对话、文书、UI 字符串）。
> 设计文档正文不受游戏渲染限制，可继续使用「」等全角符号；但文档中引用/起草游戏内文本时，一律按本规范的游戏写法。
> 与既有规范的关系：roadmap §2 规则 3（禁用句式/用词）继续有效，本文档是其展开；CSV 层面的换行/变量/百分号安全见 skill `csv-text-guidelines`，本文档不重复。
> 状态：v2.0（2026-09-10）。符号体系按原版 CJK 排版问题全量改订；SHIP 介绍结构按原版/模组实机考证重做。

## 1. 标点符号规范（v2.0）

**硬性禁止**：`「」` `《》` `【】` `“”`。原版游戏的 CJK 排版会严重扭曲这些全角符号，游戏内文本一律不得出现。

| 用途 | 统一写法 | 说明 |
|---|---|---|
| 标注/别名/编目/型号 | `[ ]` | 如 `[Polaris Prime]`、`轴炮-[驱雷]`、编目 `[XC-001]` |
| 强调/引用专名 | `< >` | 如 `<执行官>`、打法名 `<列星逐电>`；嵌套层也用 `<> <>` |
| 直引号 | `"`（ASCII） | 引述原话/带反讽的词，如 `档案评价它为"决斗者"` |
| 冒号/句号/逗号 | `：` `。` `，`（全角） | 无渲染问题，正常使用 |
| 破折号 | `——` | 补充说明/转折 |
| 省略号 | `……` | 两个 U+2026 |
| 级后缀 | `名-级`（半角连字符） | 与原版一致：`攻势-级`、`淬刃-级驱逐舰`；不写 `「淬刃」级` |
| 数字 | 半角阿拉伯数字 | 不写千分位分隔符：1200su；数字与单位/中文之间不加空格 |
| 百分号 | 放 `{%s}` 替换字段 | 见 csv-text 规范 3 |
| 英文缩写 | ARC / LENS / ECM 大写直排 | 与中文之间不加空格 |

**关于 `"` 与 CSV**：文本中直接写 `"` 即可，无需手写转义。生成器 `CsvCodec.csvEscape` 按 RFC4180 处理（字段含 `"` 时整体加引号、内部 `"` 双写），已验证实现正确。若将来发现生成产物转义错误，修生成器，不得为规避转义问题改文本格式。

## 2. 句式与用词红线（沿用 roadmap §2 规则 3，此处细化）

- 禁止"不是/并非……而是……"否定起手句。
- 禁止"闭环/回路/循环"等工程化名词进机制描述（既有专名 [弧光回路接口] 除外）。
- 模式名称用直白词（解限 / 锚定）。
- 介绍文本以陈述句为主；形象句每段至多一句，且必须落在事实之后。控制专名密度：单段内模组专名不超过三个，其余靠上下文解释。

## 3. 舰船介绍（SHIP 型 descriptions）结构规范（v2.0）

### 3.1 字段用法（经原版实机考证）

- **正文全部写入 text1**：原版 SHIP 描述（攻势/星体/亥伯龙）均为 text1 单字段多段落，text2~text5 与 notes 留空；游戏对 SHIP 只渲染 text1（法典整段、装配界面取首段 `getText1FirstPara`）。
- **text2~text5、notes 对 SHIP 一律留空**。写入这些字段也不会渲染，本项目旧文案 text2/notes 内容在游戏内不可见，这是"介绍过短"的部分原因。
- 段落分隔：text1 内用真实换行 + 空行分段（properties 中写 `\n\n`）。

### 3.2 段落公式（3~4 段，总长 150~400 字）

1. **定位段**：`名-级` + 舰种 + 阵营/设计性质 + 核心机制概述（1~2 句，陈述事实，不用形象句）。
2. **战法/背景段**：关键系统如何转化为打法、与舰队中其他舰的关系、可查证的战绩记录（2~4 句）。
3. **历史段**：大崩塌带来的时间纵深，包括蓝图/产线/档案的去向，现存个体的来源与稀缺性（1~3 句）。
4. **收尾段（可选）**：编目号 + 命名由来，或一句冷峻收束（1~2 句）。编目号格式：`[类目-三位序号]`，类目码 XC = 星坠、ZW = 紫菀、LH = 联制、ZL = 自律；0xx = 样机/独特，1xx = 量产。

### 3.3 冻结舰说明

冻结舰（D6 星坠/熔壁）的机制与数值不动，**文案可动**（命名已由 D26 覆盖）。

## 4. 范例（v2.0 定稿样板）

> 以下为最终游戏内文本（text1 全文），段落之间空一行即空行分段；写入 properties 时使用 `\n\n`。全部范例已经用户修订（2026-09-11），现行 SHIP 文案以本节文本为唯一风格基准：定位段冒号起手、2~3 段正文、收尾统一"代号 [编号] + 命名由来一句"。

### 4.1 星坠 `astd_xc_001`（ARC 旗舰 · 冻结）

星坠-级主力舰是星坠理事会的旗舰样机，依靠双重指挥协议在载人指挥与自律核心之间切换，能够在正面战场维持极端密度的持续火力。

在理事会尚存的年代，星坠-级出现在战线哪一段，哪一段的交火就会迅速失去悬念：宽阔舰首容纳的多层弧光母线为一门内置主炮与两翼炮列供能，整套火控只为"让星星坠落"这一件事服务。现存的作战记录里，它极少需要第二次齐射窗口。

大崩塌之后，星坠-级的蓝图与船坞档案一并消失，如今偶尔被目击的个体都被认为是崩塌前下水的同型舰。它们听命于谁、由谁驾驶，没有一份档案能够回答。

实验代号 [XC-001]。理事会以自局名称呼自己的旗舰，就足以显现该舰的地位了。

### 4.2 逐电 `astd_xc_104`（ARC 量产护卫）

逐电-级护卫舰是星坠理事会量产的高速电弧突击艇，与列星-级驱逐舰共同构成星坠狼群战术的锋矢，专司撕扯敌方防线与近身瘫痪。

为了在护卫舰的狭小龙骨内塞入高功率放电阵列，逐电-级大幅削减了冗余隔舱，将电容母线直接裸露于外层装甲之下。在狼群合围阶段，逐电-级会借由极高的航速切入敌舰近防死角，激活静电释放系统瘫痪目标的引擎与点防炮塔，为紧随其后的列星-级创造绝杀窗口。

在星坠理事会的资产台账中，逐电-级是损耗率最高、补产批次也最多的轻型舰艇。它在战场上从不吝惜结构寿命，只求在电弧熄灭前咬碎猎物的咽喉。

代号 [XC-104]。与[列星]合称<列星逐电>，为星坠理事会最负盛名的狼群番号。

### 4.3 决明 `astd_zw_001`（LENS 旗舰样机 · 独特）

> 用户定稿（2026-09-10），后续舰船描述按此风格编写。此处仅做格式归一：text1/text2/text3/notes 四段合并进 text1（SHIP 只渲染 text1），`「」` 改 `[ ]`。

决明-级巡洋舰是紫菀理事会的实验性舰船设计，以远超于同规格巡洋航母的规格在战场上创造绝对的统治力。

据目前能够得知的档案里，决明-级的首次出现是在一处边缘星垣的星系中，紫菀理事会几乎将所有最前沿的引力技术都投入在了这艘舰船。而成果显然非常令人满意：在首轮同规模的集群作战测试中就以压倒性的优势取得了胜利。这些无疑是归功于能够直接改变战场环境的引力投射器，又或是能够极大幅度提升战机作战效率的视界甲板。并且因为决明-级出色的生存能力，一度让常驻于旗舰地位的飞蓬-级受到严重的威胁。

然而，决明最后并没能走出实验阶段，大崩塌发生后，大量的实验性引力科技器材断供导致第七分局无法再造出这样惊人的舰船了。如今我们能够见到的这艘决明-级很可能就是档案中所描述的，从边缘星垣造出的第一艘实验性引力科技舰船，也是最后一艘。也许未来的某个时刻英仙座可以重新创造出它的仿舰，但那很可能是非常久之后的事了。

实验代号 [ZW-001]。紫菀的造物以明目本草为名——[决明] 即明目之药，古别名还瞳子。

### 4.4 衔星（联制护卫 · `astd_lh_001`，已实装）

衔星-级先进炮艇是星坠与紫菀两局罕见的联合设计品，以护卫舰的体量装载了为单舰对决校准的整套火控。

作为仅次于决明-级的技术复杂度，在护卫舰级的体量中几乎塞入了菀星设计总局所有已知的前沿技术，其目的只有一个：以超规格的武装和最先进的辐能网络来以小博大，并从中取胜。很显然，衔星-级目前能够展示在我们眼前，就说明它已经做到了。

尽管档案中经常记录该舰级夸张的舰船维护开销，和极高的飞船驾驶员技能需求，但这些都无法掩盖衔星-级出色的战斗能力。作为两局联制品，该舰级的产量记录在大崩塌中佚失，现存个体的火控铭牌上同时留着两个理事会的签章——星坠铸骨，紫菀凝眸。

代号 [LH-001]。双局共衔一星；它的造价栏比某些巡洋舰还长。

### 4.5 星翼 `astd_xc_002`（ARC 独特驱逐）

星翼-级驱逐舰是星坠理事会的实验性猎杀平台，围绕一门内置的[坠星残翼]直射炮建造，并依靠裂隙折跃在战场上穿行，执行高风险的精确突袭。

档案中该级只有一艘的下水记录，没有量产计划，也没有后续编号。大崩塌后它数度易主，每一位新主人都宣称摸清了它的折跃节律，每一份作战报告都在同一个窗口期里中断。

实验代号 [XC-002]。高速机动时舰体两侧会展开高频闪烁的全息光翼——[星翼] 之名由此而来。

### 4.6 熔壁 `astd_xc_101`（ARC 量产巡洋 · D6 冻结，仅文案）

星坠理事会量产的战线中坚：熔壁-级巡洋舰。能够以单舰之躯承载主力舰级的火力，其形象也与低端科技的一艘热门巡洋舰型颇为相似。

熔壁-级在档案中出现的频率可谓是相当之高，是组织里最常见的装甲舰。当然，让熔壁-级真正出名的是它独特的分布式等离子装甲护盾，这种高度集成于整艘舰船的设计让熔壁-级的护盾具有极高的抗动能打击能力，并通过反冲蓄能器再将打击产生的冲击能量回敬给周围的对方。也因如此，即便是处于武器下线状态的熔壁-级也颇具威胁。熔壁-级也因为其出色的生存能力在各位宇宙民之间颇受好评，无疑是星坠理事会里最成功的量产型巡洋舰。

代号 [XC-101]。熔铸的墙壁。

### 4.7 烽燧 `astd_xc_102`（ARC 量产主力）

星坠理事会的主要舰队支点：烽燧-级堡垒主力舰，无论是单独作战还是集群作战都是一个不容小觑的威胁，其形象似乎与速子科技旗下的一项秘密 AI 计划中所设计的舰船颇为相似。

烽燧-级的武装和形象可谓是极为暴力：大量的广阔前向火炮槽位，夸张的堡垒式长翼造型，以及遍布舰船全身的辐能网络，每一项设计都能完美诠释星坠理事会的舰船设计风格。

烽燧-级还能够承担火控中心的作用，其内置的共享战术网络能够与周围的所有舰船建立共享链接，并提升友舰的射程。当战术系统激活的时候，还能额外建立辐能链接，为周围的舰船缓解辐能压力。

代号 [XC-102]。边塞燃火为号、列台传讯。

### 4.8 列星 `astd_xc_103`（ARC 量产驱逐）

由星坠理事会设计的列星-级驱逐舰，可以看作是淬刃-级的量产化版本。通常会与同级和逐电-级成群结队在战场中以追猎者的形式出现。

根据目前的档案中得知，我们目前见到的这类舰船已经是经过了多轮现代化改造的版本。列星-级依靠充沛的武装配置和极具进攻性的战术系统，能够在短时间的爆发窗口中快速对同级目标造成毁灭性的打击，如果在这一轮攻势下敌舰还残存一息，那么它很快就会被下一艘列星-级或逐电-级所终结。

成群结队的列星-级威胁极大，它们能够在各自舰船间建立追猎网络，反复调谐舰船的各类系统，并相互掩护，如果进攻方没有专门用于对抗狼群作战体系的配装，那么整个战场将会变成列星-级的无伤狩猎场。正因如此，列星-级也深受狼群作战体系的舰长们所青睐。

代号 [XC-103]。诸星成列。

### 4.9 密蒙 `astd_zw_002`（LENS 独特相位巡洋）

密蒙-级相位巡洋舰是紫菀理事会的认知剥夺实验舰，围绕高功率的引力电子干扰力场与磁暴发生器建造，专职在正面交锋前瓦解敌方舰队的感知与火控网络。

与常规相位潜袭舰不同，密蒙-级极少孤身深入敌后。它更擅长潜伏在战线交汇处的引力阴影中，利用半随机性的引力异常持续迟滞周边敌舰的机动与准星；一旦敌方阵型因传感器致盲而出现脱节，密蒙-级便会短暂上浮并超载奇点核心，向前方扇面倾泻足以令整条战线强制过载的引力磁暴。

大崩塌前，第七分局仅完成了极少数密蒙-级原型舰的船体合拢。由于其核心力场对周边电子设备的侵蚀不分敌我，它在总局内部的调拨记录中始终被列为特管资产，如今仅在深空边缘的封存编队中偶现踪影。

实验代号 [ZW-002]。密蒙花本为明目之药，花繁则致翳——密蒙花开，观者目迷。

### 4.10 舜华 `astd_zw_101`（LENS 量产相位驱逐）

舜华-级相位驱逐舰是紫菀理事会量产的突击型空间操纵平台，依靠局部维度折叠与弹道复写技术，在中近距离交火中具备远超同吨位舰船的生存与爆发能力。

紫菀理事会将前沿的短距空间编辑技术浓缩进了舜华-级的奇点核心：常态下，环绕舰体的扭曲力场会将迎面袭来的高威慑射弹直接折跃至舰体另一侧；而在进入进攻窗口时，引力空间复制器则能锁定刚出膛的能量射弹，在原发点连续复写出两轮延迟齐射，瞬间将单舰火力密度推升至巡洋舰水准。

作为紫菀序列中少有的独立猎杀舰，舜华-级无需依赖主力舰的贴身掩护即可在侧翼游刃有余地收割小型目标。即便在两百年后的今天，它神出鬼没的相位节律依然是各势力护航舰长的梦魇。

代号 [ZW-101]。命名取自木槿之古称[舜华]——朝开暮落，顺应相位出没之瞬。

### 4.11 飞蓬 `astd_zw_102`（LENS 量产航空战列舰）

飞蓬-级航空战列舰是紫菀理事会的量产型战场中枢，以三座维度折叠甲板与重型远距离火力为核心，承担整支透镜舰队的防空压制与机群调度职责。

得益于紫菀独有的子空间容器技术，飞蓬-级单座机库的舰载机吞吐量与整备效率均达到了常规航母的数倍。当战局进入决胜阶段，母舰会激活战机引力联结器，将外放机群的时间轴与母舰奇点核心强行锚定，令漫天无人战机在数倍时间流速下倾泻弹雨，随后在瞬息之间折叠召回、满编再出。

在总局的作战教范中，飞蓬-级从不追求单舰突进，而是作为移动的空天母巢稳坐中军。只要它的逻辑中继阵列仍在运转，敌方就必须面对永远无法清空的无人战机狂潮。

代号 [ZW-102]。菊科飞蓬，蓬种乘风四散——恰如无人战机离舰铺满星海之景。

### 4.12 茑萝 `astd_zw_103`（LENS 量产相位护航航母）

茑萝-级相位护航航母是紫菀理事会专为伴随主力舰作战而设计的近距格斗航母，通过母舰与内置[牵丝]重型无人战机的同步相位网络，在大型友舰侧翼构筑致命的近防绞杀区。

茑萝-级的引力相位甲板与[牵丝]战机高度耦合：母舰潜入相位时，外放战机亦随之隐入虚空，并将交战中积累的辐能跨维度导回母舰耗散。面对企图贴近主力舰的突击敌舰，茑萝-级会超载能源核心，在目标表面直接撕开红色引力旋涡，以贯穿护盾与装甲的裂隙光束配合机群完成定点清除。

受限于高度特化的伴随火控逻辑，脱离主力舰掩护的茑萝-级很难独自维持长线战局；但当它依附于烽燧或飞蓬身侧时，任何试图切入内圈的猎手都会在引力裂隙中化为残骸。
