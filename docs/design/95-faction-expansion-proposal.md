## 1. 扩展总体原则：保持“中立军工遗存与契约裁决者”基调

根据 `00/01` 号设定文档，菀星设计总局（Asteria Directorate）**不是**人之领复兴军阀，也不直接作为常规争霸势力在核心星域刷出占领军。因此，后续势力扩展不应走传统的“铺满全图的常规派系巡逻队”路线，而应围绕 **“三大遗址星系深度开发 + 第七分局特许承包商网络 + 跨模组第三方工程支援”** 展开，把三个固定星系打造成玩家中后期的核心根据地与高难挑战中枢。

## 2. 方向一：三大遗址星系的“三阶重启工程”

目前 `Asteria Seven`（主星系·兰台/洪炉/淬池）、`Asteria Arc`（星坠系·锻原）、`Asteria Lens`（紫菀系·拾光）三个星系已在生涯开局固定生成，并预留了多个 `astd_reserved_station`（未启用的轨道站/船坞）与 `astd_story_aster_singularity`（奇点跃迁器）占位实体。

### 2.1 第一阶段：外围勘探与封存防线核销
- **星系守备生态**：在玩家完成前中期赏金（如 `科目一~三`）前，星坠遗址星系与紫菀遗址星系的核心轨道设施周边可刷出 1~2 支中立偏警惕的 **“封存自动巡哨队”**。
- **通行签章机制**：当玩家通过赏金链积累一定声望或回收首枚制式核心后，第七分局应答机将玩家舰队识别为 **`[在册外部承包商]`**，星系内守备舰队与 IndEvo 轨道炮台转为友军/中立护航状态。

### 2.2 第二阶段：预留轨道设施与“奇点跃迁器”激活
利用 `StoryWorldIds.kt` 中已预留的 TODO 实体，提供资源投入型工程项目：

| 星系与预留实体 ID | 设施名称 | 激活条件草案 | 激活后战役功能 |
|---|---|---|---|
| **主星系 (`Asteria Seven`)**<br>`astd_story_main_reserve_b` | **第七分局·联合装配船坞** | 投入制式 Beta 核心 ×2 + 重型机械/金属/稀有金属 | 解锁 **【双模式基底改装】** 与 **【总局标准改装件（Affix）合法加装】** 服务；允许消耗剧情点为玩家自有舰船安装 1~2 项 S/M 级词缀。 |
| **星坠星系 (`Asteria Arc`)**<br>`astd_story_starfall_dockyard` | **星坠动力船坞（重启态）** | 完成赏金 `特遣四` + 投入特务核心 `[司炉]` 或 Alpha 核心 | 解锁 `ARC` 量产舰无损定制订单，以及 `七星 / 摧锋 / 贯星之矛` 等星坠超规格武器的月度定额配给制造。 |
| **紫菀星系 (`Asteria Lens`)**<br>`astd_story_aster_dockyard` | **紫菀引力船坞（重启态）** | 完成赏金 `特遣五` + 投入特务核心 `[司瞑]` 或 Alpha 核心 | 解锁 `LENS` 量产舰与无人战机 LPC 定制订单，以及 `湮灭涡旋 / 辉星 MRM / 源生冰晶` 等紫菀超规格武器的月度定额配给制造。 |
| **紫菀星系 (`Asteria Lens`)**<br>`astd_story_aster_singularity` | **奇点跃迁器** | 拾光站稳定度达标 + 投入大量挥发物与超空间拓扑数据 | 建立连通 `Asteria Seven ↔ Asteria Arc ↔ Asteria Lens` 三大星系的**零燃料瞬时折跃网**；并支持消耗挥发物向已激活星门进行单向超远距投送。 |

### 2.3 第三阶段：四大遗址市场状况（Market Conditions）的殖民地进阶联动
在现有 `StoryConditions.kt`（属性加成随难度系数缩放）基础上，当玩家殖民或接管对应星球/空间站时，提供独特机制：
- **兰台（`菀星行政部遗址`）**：殖民地设立指挥部/最高指挥部后，自动生成包含 ASTD 制式舰船的**“承包商协防特遣队”**巡弋主星系。
- **锻原（`星坠工程部遗址`）**：殖民地建造轨道工业/重工业时，本星系产出的舰船自动附带免费的实弹/能量武器弹速微调增益（或降低 OP 维护）。
- **拾光（`视界动力` + `紫菀科研部遗址`）**：除现有的 `1500su` 黑洞事件视界免疫外，允许驻泊舰队在拾光站免费执行高速 CR 整备，并提供科技挖掘（Tech-Mining）产出本模组专属蓝图与武器的小概率周期性检出。

## 3. 方向二：第七分局“自律军需联络终端”与声望契约循环

在不重做复杂全屏自定义 UI 的前提下，采用原版轻量化的 **联系人（Contact）/ 空间站特殊对话选项（Rule / Dialog DSL）** 实现完整的势力交互闭环：

1. **常驻联络终端**：
   - 在 `第七分局空间站`（兰台轨道）与 `拾光站` 停靠时，提供 **`[接入第七分局军需与核销终端]`** 选项。
2. **多维履约声望获取**：
   - 除完成 10 阶固定赏金外，玩家可向终端提交 **余晖 AI 核心、异星/深渊武器样本、多余的军用蓝图** 进行“技术审计归档”，换取 `菀星设计局` 声望与 **[总局核销凭据]**。
3. **分级军需配给（受控产出）**：
   - 解决玩家“打完赏金前拿不到 ASTD 船与武器、或者只能靠随机黑市碰运气”的痛点：按声望等级分批解锁 `ARC / LENS` 量产武器箱、战机联队 LPC、量产舰体蓝图，以及高声望专属的 `衔星-级 (ARC/LENS)` 联制炮艇提货权。
4. **终局可重复玩法——“封存演习序列调阅（Custom Trial Generator）”**：
   - 当玩家完成全部 10 阶固定赏金后，可在终端主动消耗星币或核销凭据，生成**可重复挑战的动态高难演习舰队**：
     - 玩家可自选演习科目：**[星坠重装突击科]**、**[紫菀引力诡道科]**、**[两局联制混编科]**；
     - 奖励高价值的制式 Alpha 核心、超规格武器整箱与高稀有度改装件权限。

## 4. 方向三：舰船池收尾、隐藏终局与 `共轭终端` 转正

### 4.1 `[ZW-001] 决明-级` 与 `[XC-001] 星坠-级` 双旗舰终局联动
- 目前 `astd_zw_001`（决明-级指挥巡洋舰）已完成 P4 机制重做，并正式作为第 9 阶孤品裁决赏金 **`astd_bounty_zw_001`（孤品裁决：[ZW-001] 决明）** 接入主线赏金链（与 `astd_bounty_zw_002` 密蒙-级强度对齐，共同拱卫第 10 阶 `astd_bounty_xc_001` 星坠-级终局赏金）。
- **后续深化方向**：当玩家同时回收 `[XC-001] 星坠` 与 `[ZW-001] 决明` 两艘理事会冠名旗舰后，可在第七分局联络终端触发专属的**【双院首舰合验】**档案事件，解锁两局联席的隐藏工程批注与专属双旗舰协同改装权限。

### 4.2 `astd_conjugate_terminal`（共轭终端）的定位转正方案
针对 `90-roadmap.md §6` 中挂起的 `astd_conjugate_terminal`（现有数据与贴图，为无盾高机动小型无人机单位），提出两个转正方向供后续二选一：

- **方案 A：两局联制（LH）舰船/船插的战术伴飞信标**
  - 作为后续联制线新舰（或 `决明-级` / `烽燧-级` 协同船插）释放的**战场战术中继无人机**。在场时为母舰提供跨屏视野锚定、引力武器开火中继或友军幅能分流节点。
- **方案 B：高阶赏金舰队的“协议共轭锚点”**
  - 在 T5+ 高难赏金战斗中，随敌方旗舰一同部署数枚 `共轭终端`。终端存活期间为敌方旗舰提供持续的词缀增幅或时流护盾；玩家可通过快速猎杀外围的 `共轭终端` 来削弱敌方主控旗舰的护体光环，增加高难 Boss 战的战术博弈层次。

### 4.3 `SecondInCommand`（SiC）副官系统正式实装
- 结合 `docs/design/integrations/second-in-command.md` 与 `docs/design/skills/20-ai-core-rework-proposal.md`，将 **【引力相位工程院】** 天赋树作为本模组的标准软依赖扩展落地：
  - 通过通讯目录（第七分局/拾光站高权重）、休眠舱打捞以及特务核心 `[司契]` 转化三种途径获取；
  - 10 个技能围绕 **双模式切换增益、相位线圈调谐、引力武器破盾协同、制式 AI 核心点数减免** 展开，使 ASTD 舰船在 SiC 环境下拥有完整的专属流派构筑体验。
