# 赏金扩展包：需求案（概要版）

> 目标：作为 Starsector 模组的“赏金扩展包”，提供可重复游玩的动态赏金内容；具备动态可变难度配置；并通过“独特强力舰船/装备”形成明确的成长与收集闭环。

> **详细设计文档索引**：
> - **武器设计**：见 `docs/design/weapons/`
> - **舰船设计**：见 `docs/design/ships/`

## 1. 设计目标

- **可重复刷**：通过“赏金模板 + 词缀（Affix）+ 舰队拼装”组合生成大量变体。
- **动态难度**：难度不仅体现在数值，也体现在可读的机制与可视化标签（边框颜色、词缀图标、简短风味文本）。
- **强奖励驱动**：提供少量“独特舰（Unique）”作为里程碑奖励；并提供一条可量产的势力舰系作为内容承载。
- **两条战斗风格线**：
  - **蓝线（弧光计划）**：过驱窗口 / 正面压制 / 幅能节奏系统。
  - **紫线（透镜协议）**：电子战 / 无人机与干扰 / 机制取胜。

## 2. 世界观与势力

### 2.1 失落势力：阿斯忒里亚遗构局（Asteria Directorate）
域时代末期的军工-科研复合体，留下了两条彼此竞争的技术路线——ARC（蓝）与 LENS（紫）。

### 2.2 势力竞逐
- **Tri-Tachyon (TT)**：追求 LENS 的电子战垄断。
- **Hegemony (HE)**：追求 ARC 的正面火力优势。
- **Remanent (余晖)**：作为 T4+ 的高阶威胁介入，控制着被“转化”的原型舰。

## 3. 动态难度与赏金生成

### 3.1 三层标签体系
- **Threat Tier**：T1-T5。
- **Affix**：改变战斗机制的词缀（如“超频线圈”、“干扰蜂群”）。
- **Reward**：掉落预览。

### 3.2 赏金类型
- **科技回收**：抢黑盒。
- **旗舰抢夺**：抢原型船。
- **护送/封锁**：穿过封锁线或拦截船队。
- **余晖压制**：清理被AI占据的设施。

## 4. 舰船设计概览（详见 ships 目录）

### 4.1 独特舰（Unique）
- **弧光耀斑级**（蓝/战巡）：战术超频旗舰。
- **引力透镜级**（紫/巡洋）：干扰蜂群母舰。
- **星云回声级**（紫/驱逐）：相位侦察尖兵。

### 4.2 量产舰（Production）
- 提供了从主力舰到护卫舰的完整量产序列，用于填充赏金舰队。

### 4.3 核心机制：双模式（Dual-Mode）
所有高阶舰船均搭载“指令集切换套件”Hullmod：
- **无人模式**：消耗无人点数，需要 AI 核心，性能解限。
- **载人模式**：低后勤压力，高改装自由度，性能稳定。

## 5. 美术需求

### 5.1 视觉识别
- **蓝线**：深枪灰 + 电容蓝（Electric Blue）。楔形，工业感。
- **紫线**：暗紫 + 信号紫（Signal Purple）。不对称，传感器风格。

### 5.2 必须产出
- 4 艘独特舰 Sprite。
- 6 艘量产舰 Sprite。
- 16+ Affix 图标。
- UI 边框与背景资源。

## 6. 开发计划 MVP

1.  **阶段一**：实现弧光耀斑（蓝）与引力透镜（紫），以及基础量产舰，跑通赏金生成流程。
2.  **阶段二**：补全剩余舰船，丰富 Affix 库，实装剧情线索链。
