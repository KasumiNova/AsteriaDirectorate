# 蓝线（ARC）：原型与独特舰

## 1. 旗舰：星坠级（XC-001）

- **级别**：主力舰 / 战列舰（Capital / Battleship）
- **定位**：战线锚点 / 短窗爆发 / 玩家旗舰
- **获取**：唯一（Unique），赏金关键目标

### 舰船系统：烁雨繁花

根据难度系数，获得瞬间爆发（不随时间线性增长和减弱）的 100%/150%/300% 额外时流速度、额外加减速、额外辐能耗散速率、额外非导弹武器备弹恢复速度。
激活时按舰船当前向量附加 150%/200%/350% 最大航速的冲刺动量（不提升最大航速），附加冲刺动量期间**不**锁定舰船朝向控制。
舰船系统持续期间，按武器类型调整冷却：
- 导弹武器保持原有冷却，按武器类型判定，与安装槽位无关。
- 有弹匣的射弹武器，以及无弹匣但每轮连发多次的射弹武器：轮间基础冷却取连射间隔（burstDelay）与 0.05s 中较大者。
- 无弹匣、每轮只发射一次的射弹武器：基础冷却缩短 75%，最低 0.25s。
- 点射光束：冷却缩短 75%，最低 0.5s。冷却与光束渐灭同时计时；若武器必须完成渐灭，新一轮在两者都结束后开始。持续光束可连续照射。

射弹武器保留原有的蓄力时间和轮内连射间隔。
持续时间 2s，冷却时间 2s，充能间隔 12s，可充能 2 次。

玩家可见描述：
  激活时，舰船根据当前航向附加爆发冲刺动量，并获得高额爆发性时间流速、加减速、辐能耗散速率与武器备弹恢复加成。持续期间所有非导弹武器的开火冷却时间大幅降低。

## 2. 星翼级（XC-002）

- **级别**：驱逐舰（Destroyer）
- **定位**：高机动突击 / 星梭压制 / 游走猎杀
- **获取**：唯一（Unique）/ 赏金获得
- **资源继承**：实体与注册数据使用 `astd_xc_002`

### 核心定位

- **高机动星梭猎手**：以 120 基础航速、放宽的零辐能加速阈值与纯正向航速收益为基础，在高速游走中持续发射可追踪的四色星梭。
- **整图光翼与虚数充能池**：舰体两侧的全息光翼绑定连续百分比能量池 `[0% ~ 100%]`，主炮命中与自然恢复共同累积充能，充能按比例强化后续星梭，并可在系统次数为 0 时兑换一次折跃。
- **手操与 AI 双优体验**：自动追踪高弹速主炮、折跃净空推开与终点冲击、充能兑换的额外交战窗口，确保手操行云流水且 AI 零门槛发挥满额战力。

#### 虚数之翼（`astd_imaginary_wings`）

1. **虚数充能池（`0% ~ 100%`）**：
   - 战斗中每秒自动恢复虚数充能，速率按难度分档（见下表）。

2. **虚数滑翔（纯正向航速收益）**：
   - 舰船零辐能加速触发阈值放宽至 **硬辐能 ≤ 20%**。
   - 根据当前航速与基础最大航速的比例（`0% ~ 100%`），线性提供 **`0% ~ +20% / +40% / +100%`** 的非导弹武器射速与弹药回复速率加成。

难度缩放点（迟暮 `v1` / 砺刃 `v2` / 破晓 `v5`）：
- 虚数充能自然恢复：`+2%` / `+4%` / `+10%`
- 满航速非导弹武器射速与弹药回复加成：`20% / 40% / 100%`

### 舰船系统：星翼折跃（取代裂隙折跃）

- **基础充能与时间**：最大 **2 次充能**，充能恢复时间 `15.0s / 次`；激活后延迟 `0.15s`（IN）→ 曲线位移 `0.6s`（ACTIVE）→ 现身收束 `0.1s`（OUT），单次总时长 `0.85s`，使用间隔冷却 `0.5s`。系统不进入相位、不改变舰船时流。
- **十字光斑与曲线位移**：
  - 激活瞬间在原位产生蓝色十字光斑（`SMOOTH_DISC` 与旋转 `+90°` 的 `SMOOTH_DISC`，起止尺寸 `280 → 600`、厚度 `36`，约为摧锋命中十字的一半规模），缓慢扩散至位移结束。
  - 延迟结束后沿当前舰速方向（静止时沿舰首方向）在 `0.6s` 内位移 **`400su`**（受系统射程加成影响），轨迹为 easeInOutExpo 曲线；位移期间**锁定转向**，舰体保持可见（不进相位），沿路径持续生成大量残影（含 `*_bloom` 发光层）。中途关停时只结算已走完的位移段。
- **落点冲击**：位移进度到达终点的同一帧立即结算（不等 OUT 收束），产生扭曲震荡实体，并生成快速扩散的 `astd_shockwave`、慢速扩散的 `astd_shockwave_ring` 与向外飞散的三角碎片；所有冲击特效锚定舰体随舰移动。对周围敌方目标造成 **`400`** 点随距离衰减的能量伤害与冲击推力，表现类似摧锋鱼雷命中但冲击感更弱。
- **净空力场**：
  - 起跳瞬间（IN）与现身瞬间（OUT），在舰体周围 **`250su`** 释放逆熵冲击，对范围内除施放舰自身外的所有目标（舰船、战机、导弹、射弹）施加径向推力，不造成伤害；空间站及其模块保持位置固定。
- **虚数充能**：
  - 当系统充能次数为 `0` 时，若舰船当前 **[虚数充能]** 水平大于 `60%`，则立即消耗 `60%` 充能为舰船系统增加一次充能；不等按键、不强制施放、不清除自然恢复进度，HUD 使用同一阈值。

### 特殊特效与 UI 表现：虚数光翼 & HUD Bar

1. **整图光翼动态演进（复用 `astd_xc_002_ghost_dark.png` 与 `astd_xc_002_ghost_light.png`）**：
   - 使用双层 `SpriteEntity` 整图挂载于舰体中心（无需切分贴图），呼吸频率、透明度、色调与残影密度随 **[虚数充能]** 档位实时演进：
     - **低充能（`0% ~ 30%`）**：呼吸周期 `2.5s ~ 3.0s`，alpha 范围 `0.15 ~ 0.45`，呈待机微光电容蓝，不生成残影。
     - **中充能（`30% ~ 80%`）**：呼吸周期线性缩短至 `1.0s ~ 1.5s`，alpha 范围抬升至 `0.45 ~ 0.85`，每 `0.08s` 渲染一次 `ghost_dark` 蓝色残影（alpha `0.12`，持续 `0.4s`）。
     - **高充能（`80% ~ 100%`）**：呼吸周期加快至 `0.5s`，`ghost_light` alpha 常驻 `0.85 ~ 1.0`。
   - 光翼贴图始终保持原色，不叠加任何着色，也不渲染额外的常驻光斑；`alpha` 越高，光翼的随机抖动幅度越大。
2. **玩家 UI 反馈（仅使用单条 HUD Bar，不占用左下角状态栏图标）**：
   - 不调用 `maintainStatusForPlayerShip` 生成左下角状态栏卡片，保持界面干净。
   - 仅通过 `MagicUI.drawHUDStatusBar` 在玩家舰船 HUD 位置绘制一条 **[虚数之翼] 进度条**：
     - **常态下**：进度条填充比例对应当前 **[虚数充能]（`0% ~ 100%`）**；充能 `≤ 60%` 时条色为深蓝，充能 `> 60%`（可兑换折跃次数阈值）时条色变为浅蓝，条旁首行显示当前百分比（如 `75%`），次行显示状态词 `虚数充能`。
