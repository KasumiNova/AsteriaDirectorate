## 2. 星翼级（XC-002）

- **级别**：驱逐舰（Destroyer）
- **定位**：高机动突击 / 弹幕打击 / 游走猎杀
- **获取**：唯一（Unique）/ 赏金获得
- **资源继承**：实体与注册数据使用 `astd_xc_002`

### 核心定位

- **高机动弹幕猎手**：以 120 基础航速、放宽的零辐能加速阈值与纯正向航速收益为基础，在高速游走中持续倾泻主炮脉冲与双翼追踪光矢弹幕。
- **整图光翼与虚数充能池**：舰体两侧的全息光翼绑定连续百分比能量池 `[0% ~ 100%]`，交火命中与自然恢复共同驱动光翼自动发射追踪星羽，并支持在系统次数耗尽后直接消耗充能透支折跃。
- **手操与 AI 双优体验**：24° 宽射界高弹速主炮、现身自动对齐准星、折跃净空抹弹幕、瞬回主炮弹匣与软幅能排散，确保手操行云流水且 AI 零门槛发挥满额战力。

#### 虚数之翼（`astd_imaginary_wings`）

1. **虚数充能池（`0% ~ 100%`）**：
   - **自然恢复**：战斗中每秒自动恢复 `+5%` 虚数充能。
   - **交火共鸣**：本舰任何非导弹武器（含内置主炮与两侧中型槽武器）每次命中敌舰恢复 `+3%` 虚数充能（最短触发间隔 `0.1s`）；内置主炮的 `[断熵]` 强化贯通弹命中敌舰时直接恢复 `+10%` 虚数充能。
2. **星羽翼装弹幕（自动倾泻）**：
   - 当虚数充能 `≥ 20%` 且周围 `1100su` 内存在敌舰时，每 `0.3s` 消耗 `8%` 虚数充能，从舰体两侧全息光翼的预设相对坐标锚点（左 3、右 3 共 6 个发射点）交替射出 **2 枚 [星羽追踪光矢]**。
   - **[星羽追踪光矢] 属性**：
     - 初速 `350su/s` 沿翼侧外扩方向（`±45° ~ ±75°`）射出，飞行 `0.25s` 拉开弧线后加速至 `1100su/s` 强追踪扑向当前锁定敌舰（无锁定则追踪最近被主炮命中的敌舰）。
     - 视为不可被点防拦截的纯能量射弹（穿透友军、战机与导弹，仅对敌舰护盾或船体碰撞结算），单枚造成 **`120 / 150 / 250` 能量伤害 + `100` EMP**。
     - **振频蚀穿**：每枚 `[星羽追踪光矢]` 命中敌舰护盾时，为目标附加 1 层持续 `4s` 的 `[振频蚀穿]`（每层使目标最终护盾承伤效率劣化 `2%`，最多叠加 15 层即 `+30%` 护盾易伤，劣化后承伤效率不超过 `1.0`）。
3. **虚数滑翔（纯正向航速收益）**：
   - 舰船零辐能加速触发阈值放宽至 **硬辐能 ≤ 20%**。
   - 移除低航速下的负面伤害惩罚；根据当前航速与基础最大航速的比例（`0% ~ 100%`），线性提供 **`0% ~ +20% / +30% / +100%`** 的非导弹武器射速与弹药回复速率加成，以及 **`0% ~ 15% / 20% / 35%`** 的所受射弹与导弹伤害减免。

难度缩放点（迟暮 `v1` / 砺刃 `v2` / 破晓 `v5`）：
- 满航速非导弹武器射速与弹药回复加成：`20% / 40% / 100%`
- 满航速所受射弹与导弹伤害减免：`15% / 20% / 35%`
- `[星羽追踪光矢]` 单发能量伤害：`120 / 150 / 250`

### 舰船系统：星翼折跃（取代裂隙折跃）

- **基础充能与时间**：最大 **3 次充能**，充能恢复时间 `10.0s / 次`；激活切入 `0.1s`（IN）→ 虚数滑行 `0.25s`（ACTIVE）→ 现身收束 `0.15s`（OUT），单次总时长 `0.5s`，使用间隔冷却 `0.5s`。
- **位移与朝向对齐**：
  - 激活后沿当前移动方向（静止或手操输入方向键时沿输入方向矢量；AI 沿战术机动方向）高速相位滑行 **`400su`**（受系统射程加成影响）。
  - 滑行期间舰船处于**相位状态**并获得 **`2.5x` 舰船时流**；舰首朝向以 **3 倍转向速率**自动平滑对齐鼠标准星（AI 对齐当前攻击目标），保证现身瞬间主炮准星锁定目标。
- **净空力场（进出双次抹弹幕）**：
  - 起跳瞬间（IN）与现身瞬间（OUT），在舰体周围 **`250su`** 释放逆熵波纹：**直接抹除范围内所有单发伤害 `≤ 600` 的敌方非导弹射弹，并将单发伤害 `> 600` 的敌方重型射弹伤害永久削减 `50% / 60% / 80%`**，同时强制断开当前所有锁定本舰的敌方导弹诱导。
- **漫天星羽（现身满额齐射）**：
  - 每次激活系统现身（OUT）瞬间，**立即将 [虚数充能] 拉满至 `100%`，并直接消耗 `30%` 充能（保留 `70%`），由两侧 6 个光翼锚点呈扇面一次性齐射 6 枚 [星羽追踪光矢]**。
- **瞬装排幅与 [超翼过载]**：
  - 每次激活系统，立即为内置主炮 `坠星残翼` 装填 **`8 / 12 / 18` 发弹药**，并立即排散本舰 **`800 / 1200 / 2000` 点软辐能**。
  - 现身后的 **`3.0s`** 内进入 **[超翼过载]** 状态：本舰所有非导弹武器射速额外提升 **`+25% / +40% / +80%`**，且内置主炮 `坠星残翼` 的 `[断熵]` 强化贯通弹触发周期由**每第 6 发缩短至每第 3 发（破晓为每第 2 发）**。
- **虚数透支（0 充能强行折跃）**：
  - 当系统充能次数为 `0` 时，若舰船未过载且当前 **[虚数充能] `≥ 50%`**，仍可激活 `星翼折跃`：直接消耗 `50%` 虚数充能发动一次完整折跃（触发该次折跃时不再额外拉满虚数充能，但依然触发 6 枚星羽齐射、主炮装填、软幅排散与 3s 超翼过载）。

难度缩放点（迟暮 `v1` / 砺刃 `v2` / 破晓 `v5`）：
- 重型射弹（`> 600` 伤）伤害削减比例：`50% / 60% / 80%`
- 现身瞬间主炮弹药装填量：`8 / 12 / 18`
- 现身瞬间软辐能排散量：`800 / 1200 / 2000`
- `[超翼过载]` 3s 武器射速加成：`25% / 40% / 80%`

### 特殊特效与 UI 表现：虚数光翼 & HUD Bar

1. **整图光翼动态演进（复用 `astd_xc_002_ghost_dark.png` 与 `astd_xc_002_ghost_light.png`）**：
   - 使用双层 `SpriteEntity` 整图挂载于舰体中心（无需切分贴图），呼吸频率、透明度、色调与残影密度随 **[虚数充能]** 与 **[超翼过载]** 状态实时演进：
     - **低充能（`0% ~ 30%`）**：呼吸周期 `2.5s ~ 3.0s`，alpha 范围 `0.15 ~ 0.45`，呈待机微光电容蓝，不生成残影。
     - **中充能（`30% ~ 80%`）**：呼吸周期线性缩短至 `1.0s ~ 1.5s`，alpha 范围抬升至 `0.45 ~ 0.85`，每 `0.08s` 渲染一次 `ghost_dark` 蓝色残影（alpha `0.12`，持续 `0.4s`）。
     - **高充能（`80% ~ 100%`）**：呼吸周期加快至 `0.5s`，`ghost_light` alpha 常驻 `0.85 ~ 1.0`，整图色调由电容蓝平滑插值渐变为**星冕蓝紫（`RGB 160, 130, 255`）**，并在两侧翼尖固定相对坐标处点缀微型十字星芒 `FlareEntity`。
     - **系统折跃及 [超翼过载] 期间（`0.5s + 3.0s`）**：双翼整图切换为**高饱和虚数紫红（`RGB 210, 70, 255`）**，每 `0.04s` 生成一道高对比度紫红色整翼残影（持续 `0.5s`）。
2. **玩家 UI 反馈（仅使用单条 HUD Bar，不占用左下角状态栏图标）**：
   - 不调用 `maintainStatusForPlayerShip` 生成左下角状态栏卡片，保持界面干净。
   - 仅通过 `MagicUI.drawHUDStatusBar` 在玩家舰船 HUD 位置绘制一条 **[虚数之翼] 进度条**：
     - **常态下**：进度条填充比例对应当前 **[虚数充能]（`0% ~ 100%`）**；充能 `< 50%` 时条色为电容蓝，充能 `≥ 50%`（可透支折跃阈值）时条色变为星冕蓝紫，右侧文本显示当前百分比（如 `75%`）。
     - **[超翼过载] 期间（折跃现身后 3s）**：进度条切换为**亮紫红色倒计时条**（填充比例随剩余超频时间 `3.0s → 0.0s` 递减，右侧文本显示剩余秒数如 `2.4s`），直观提示高频爆发窗口。
