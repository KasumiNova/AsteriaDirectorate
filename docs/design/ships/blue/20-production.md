# 蓝线（ARC）：量产舰

> **设计哲学**：守卫秩序，拒绝妥协。量产型号在削弱极端性能的同时，通过标准化的散热与结构工程，确保即使在最绝望的战线，阿斯忒里亚的意志也能坚如磐石。

## 1. 战列舰：烽燧级（XC-102）

- **级别**：主力舰（Capital）
- **定位**：长线作战中坚支点 / 前向火力压制核心 / 战术网络中继
- **获取**：高阶赏金掉落 / 蓝图制造
- **设计状态**：重构草案

### 文案描述
烽燧级是弧光阵列量产体系中的正面压制主力。它不追求快速突入，而是依靠高韧性舰体、先进电网和覆盖友军的战术网络，在长时间交战中稳定推进战线。舰体的宽大翼面并非单纯装甲结构，而是为分布式火控与辐能共享网络提供的阵列平台。

### 核心定位

- **长线作战中坚支点**：预定峰值时间 720s，承担持续作战和阵线维持职责。
- **绝对前向火力压制**：正面武器布局与火控机制鼓励持续开火，持续输出越久收益越高。
- **低机动高韧性主力舰**：机动较差，中等航速，依靠护盾、装甲和舰体韧性顶住正面压力。
- **舰队战术网络核心**：通过共享战术网络强化小中型友军，主力舰本体承担代价和辐能压力。

### 独特 Hullmod：先进火控集成

常态下，舰船武器辐能消耗提高 **20%**。该负面效果用于表示弧光火控系统在低负载状态下的高额校准成本。

当大型非点防武器持续开火时，火控网络逐步进入稳定态，并在 **6s** 内达到最大效果：

| 效果 | 最大值 |
|---|---:|
| 武器辐能消耗降低 | -40% |
| 非导弹武器射速 | +20% |
| 射弹速度 | +20% |
| 非导弹武器伤害 | +20% |

设计意图：
- 让烽燧级在持续正面交战中越来越强，而不是依靠短爆发完成击杀。
- 要求玩家维持火线和开火节奏；被迫停火、转向或切换目标时会失去部分优势。
- 额外辐能消耗的常态惩罚用于防止其在短交火和零散补枪场景中过强。

### 独特 Hullmod：弧光共享战术网络

舰船自身非导弹非点防武器射程降低 **20%**，作为承担战术网络中继的代价。常态获得 **4% 电子战网络加成**。

阵营与子类型修正：

| 条件 | 效果 |

| 设计类型为菀星设计局旗下（星坠/紫菀） | 加成效果 +25% |

设计意图：
- 将烽燧级定义为小中型舰队的战术网络核心，而非单纯数值巨舰。
- 自身射程惩罚迫使它进入阵线中段或前段，避免在超远距离无风险提供光环。
- 主力舰无加成，避免多艘主力舰互相堆叠成过强战列线。

| 最远距离效果 | 25% 起，随距离衰减 |
| 范围修正 | 受到军官系统射程影响 |

设计意图：
- 系统不是自身爆发按钮，而是舰队爆发窗口。
- 本舰承担友军辐能压力，使其高容量、高耗散和高韧性真正参与战术循环。
- 高辐能强制关闭防止玩家无代价把全队压力转嫁给单舰。

### 设计风险与待验证项

- **网络光环堆叠风险**：需要确认与电子战、军官技能、射程 hullmod 和其他光环的叠加顺序。
- **AI 使用风险**：系统需要避免 AI 在自身高辐能或脱离友军时无效开启。
- **数值风险**：友军射程与射速加成较高，首轮应重点验证护卫舰和驱逐舰是否过度受益。
- **体验风险**：本舰自身 -20% 射程和系统激活期 -50% 射速可能导致玩家误解为“开系统变弱”，需要通过视觉和状态文本明确其支援定位。

## 2. 巡洋舰：熔壁级（XC-101）

- **级别**：巡洋舰（Cruiser）
- **定位**：战线中坚 / 极端重盾重甲 / 反冲承压节点
- **获取**：蓝线赏金常见
- **设计状态**：重构草案

### 文案描述
熔壁级是弧光阵列量产体系中的防御侧中坚。它不负责打开突破口，而是通过高度集成的等离子装甲护盾承受正面压力，为舰队提供可依赖的防线节点。相较烽燧级，它牺牲更多机动性和火力投射能力，换取接近主力舰级别的护盾与装甲承压能力。

### 核心定位

- **战线中坚**：预定峰值时间 600s，负责长时间维持战线完整。
- **主力舰级防御能力**：以重盾、重甲和方位装甲计算机制承担伤害。
- **火力投射一般**：不作为主输出舰，武器与系统均围绕承压和反冲防御展开。
- **中速低机动巡洋舰**：中等航速，机动较差，需要依赖阵线位置和友军掩护。

### 独特 Hullmod：等离子装甲护盾

#### 设定

熔壁级的护盾生成器并非传统大型投射器，而是拆散为多个微型护盾单元，并完全集成于全舰装甲。护盾本身会表现出类似装甲的分区承压特征。

#### 方位装甲计算

舰船护盾和装甲受击时，会按受击方位取战斗内最终装甲值的一部分参与额外装甲减伤。该数值使用战斗内最终装甲值，而非基础装甲值，并使用与原版装甲减伤相同的算法。

| 受击方位 | 参与装甲计算值 |
|---|---:|
| 正前方 **60°** | 最终装甲值的 30% |
| 左右侧前方 **60°~180°** | 最终装甲值的 20%~30%，越靠近正前方越高 |
| 后方 **180°~360°** | 最终装甲值的 10%~20%，越靠近后方越低 |

受到装甲减伤抵消的伤害会弹出伤害数字。常态数字使用护盾蓝色，系统启动期间使用紫色，两者不叠加。

#### 伤害类型修正

护盾受到伤害时获得以下伤害类型修正：

| 伤害类型 | 修正 |
|---|---:|
| 能量 | -15% |
| 动能 | -33% |
| 高爆 | +33% |
| 破片 | +50% |

#### 负面影响

- 禁止安装护盾分流与强化护盾，因为护盾系统已完全集成于装甲结构。
- 固定降低 **50%** 最大装甲值。

### 独特 Hullmod：离子化反冲蓄能器

舰船护盾和装甲受到伤害时，有概率产生电弧打击周围目标。该效果不由结构伤害触发。

#### 触发与目标

| 参数 | 数值 |
|---|---:|
| 起始触发辐能水平 | 25% |
| 最大触发辐能水平 | 85% |
| 冷却时间 | 1s |
| 基础射程 | 800su |

- 舰船辐能水平越高，触发概率越高，在 25% 辐能水平开始触发，并在 85% 辐能水平达到最大值。
- 触发概率不再受到受击位置和伤害类型修正。
- 光束伤害会降低 **90%** 触发概率。
- 触发概率会根据原始伤害强度调整：以舰船最大辐能的 **2%** 为基准，最终倍率限制在 **0.1x~3x**。
- 电弧优先打击周围舰船的武器或引擎。
- 电弧有概率根据本舰硬辐能水平击穿目标护盾。
- 电弧射程受到本舰能量射弹武器射程影响。
- 如果周围没有目标，则打击随机区域。
- 电弧不会攻击友军。
- 触发时播放 EMP 发生器打击音效。

#### 辐能转换与伤害

触发打击时，转换自身当前 **3% 硬辐能** 为等额软辐能。系统启动期间，辐能转换量与软辐能生成同步翻倍。

| 项目 | 数值 |
|---|---:|
| 伤害 | 转换辐能量的 100% |
| EMP 伤害 | 转换辐能量的 200% |
| 硬辐能转换 | 当前硬辐能的 3% |
| 软辐能生成 | 与被转换硬辐能等额 |

### 舰船系统：等离子装甲护盾增压

熔壁级进入持续承压姿态，强化等离子装甲护盾与离子化反冲蓄能器，但显著牺牲非点防火力。

#### 系统效果

| 效果 | 数值 |
|---|---:|
| 护盾减伤 | 逐渐提高至 +50% |
| 装甲减伤 | 逐渐提高至 +25% |
| 非点防、非导弹武器 | 禁用 |
| 大额护盾单次伤害 | 超出最大辐能 5% 的部分降低 50% |
| 离子化反冲蓄能器打击伤害 | 2 倍 |
| 离子化反冲蓄能器辐能转换 | 2 倍 |
| 硬辐能生成 | 每秒 2% 基础辐能容量 |
| 持续方式 | 可持续开启 |

系统开启期间，等离子装甲护盾的方位装甲计算值翻倍，即额外装甲计算区间从 **10%~30%** 提高为 **20%~60%**。
激活期间护盾受到的单次伤害大于舰船最大辐能的 **5%** 时，超出的伤害部分降低 **50%**。该削减先于等离子装甲护盾的方位装甲计算生效。

#### AI 与实现备注

- 系统 AI 可直接复用原版“堡垒护盾”逻辑。
- 系统需要明确表达“承压强化”而不是“输出爆发”，避免玩家误判开启窗口。
- 常态护盾颜色为偏深蓝色，系统启动时护盾从蓝色转为紫色。
- 护盾边缘出现整根原版 EMP 电弧；端点允许从护盾边缘向中心约 15% 范围内偏移，路径需要更贴近边缘流动。
- 护盾电弧更倾向于出现在近期受击方向。
- 电弧端点使用小型 MagicLensFlare 光斑，颜色跟随当前护盾电弧颜色。
- 系统开启期间电弧生成频率翻倍。

  - 武器辐能产出减免：40%/50%/80%
  - 武器射程加成：20%/30%/60%
