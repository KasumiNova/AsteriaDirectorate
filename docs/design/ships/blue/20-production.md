# 蓝线（ARC）：量产舰

> **设计哲学**：守卫秩序，拒绝妥协。量产型号在削弱极端性能的同时，通过标准化的散热与结构工程，确保即使在最绝望的战线，阿斯忒里亚的意志也能坚如磐石。

## 1. 战列舰：弧光喷流级（Arc Jet Class）

- **级别**：主力舰（Capital）
- **定位**：阵线核心 / 秩序执行者
- **获取**：高阶赏金掉落 / 蓝图制造

### 文案描述
虽然移除了耀斑级那危险的超频反应堆，弧光喷流级依然保留了令人望而生畏的正向投影。它被设计为舰队的移动堡垒，厚重的正面装甲板下隐藏着两组高能喷射阵列。在舰长的指挥下，这种庞然大物能在那神圣的瞬间，以战列舰的身躯做出巡洋舰级别的突击，如同代天行罚的将军。

### 内置 Hullmod：定向喷流阵列（Vectorized Jet Array）
*“正义需要速度，职责需要铁甲。”*
- **效果**：大幅提升正向与侧向的瞬时加速度，但转向性能依然笨重。
- **特性**：舰船在按住 `Shift`（保持朝向）移动时，最高航速提升 10%。

### 舰船系统：微型燃烧推进（Micro-Burn Drive）
- 类似这种短距离冲刺，但更注重保持开火姿态。
- 允许在开火时使用（不打断射击）。

### 数值规格（v0）
- **基础属性**：
  - 船体：14000
  - 装甲：1400
  - 极速：45
  - 幅能散耗：800
  - 幅能容量：16000
  - 部署点：45 DP
- **槽位**：
  - 1x 大型实弹（中轴），1x 大型能量（中轴），2x 中型导弹（侧舷）。

## 2. 巡洋舰：等离子拱级（Plasma Arch Class）

- **级别**：巡洋舰（Cruiser）
- **定位**：战列线中坚 / 坚定屏障
- **获取**：蓝线赏金常见

### 文案描述
等离子拱级是弧光计划中更“务实”的一面。比起毁灭对手，它更关注于保护战友。其标志性的双环结构支撑起了被算法高度强化的复合护盾，使其能在敌方猛烈的火网中长时间屹立不倒。它就像一个锚点，将支离破碎的战线强行重新连接。
*教官训诫：只要拱级的环还没碎，后续的支援就还有意义。它是我们的底线。*

### 内置 Hullmod：拱桥稳定器（Arch Stabilizer）
*“立于深渊之上，我即是桥梁。”*
- **效果**：护盾开启时，武器后坐力减少 50%，且实弹武器射程增加 100su。
- **代价**：机动性略有下降（极速 -5%）。

### 舰船系统：火力引导阵列（Fire Control Array）
- **效果**：在 10s 内，所有非导弹武器的自动瞄准精度大幅提升，且对战机/导弹的伤害 +50%。

### 数值规格（v0）
- **基础属性**：
  - 船体：7500
  - 装甲：900
  - 极速：60
  - 幅能散耗：550
  - 幅能容量：10000
  - 部署点：24 DP
- **槽位**：
  - 2x 大型实弹（前置），4x 中型通用（侧舷）。

## 3. 驱逐舰：辐射带级（Radiation Belt Class）

- **级别**：驱逐舰（Destroyer）
- **定位**：高热共振 / 撕裂者
- **获取**：常见于蓝线赏金舰队

### 文案描述
这种舰船通常成对出现，利用其搭载的中型弹道槽位交替开火，形成连绵不绝的共振弹幕。其外露的散热管在全速运转时会发出不详的蓝光，这种光芒如同死神的呼吸，预示着目标的护盾即将崩坏。

### 内置 Hullmod：冗余散热格栅（Redundant Vents）
*“热量是它存在的唯一证明，亦是它的诅咒。”*
- **效果**：幅能耗散率（Dissipation）提高 15%。
- **负面**：受到高爆（HE）伤害时，装甲损伤加深 20%（格栅结构脆弱）。

### 舰船系统：高能装填（High Energy Loader）
- **效果**：短时间内（3s）将所有弹道武器的射速翻倍。
- **代价**：期间产生的幅能也翻倍。

### 数值规格（v0）
- **基础属性**：
  - 船体：3500
  - 装甲：400
  - 极速：85
  - 幅能散耗：350 (+15% 来自插件)
  - 幅能容量：4500
  - 部署点：11 DP
- **槽位**：
  - 2x 中型实弹（炮塔），1x 中型通用（硬点）。

## 4. 护卫舰：电弧闪级（Arc Flash Class）

- **级别**：护卫舰（Frigate）
- **定位**：自燃先锋 / 刹那之光
- **获取**：非常普遍

### 文案描述
小巧、凶猛、且极其不稳定。电弧闪级本质上是把一个超标的反应堆强行塞进了一个刚好能飞起来的壳子里。它不被期望从战场返回。在阿斯忒里亚的战术手册中，它的使命就是在敌阵中燃烧自己，用最后的过载脉冲为后续的主力舰扫清障碍。
*底层协议：当判断生存概率低于 5% 时，立即进入“最后时刻”自燃模式。*

### 舰船系统：静电释放（Static Discharge）
*“在熄灭前，我曾见过至高的光。”*
- **效果**：向周围 300su 内释放 EMP 电弧，瘫痪敌方导弹和战机。
- **用途**：冲入敌方导弹雨中强行清场。

### 数值规格（v0）
- **基础属性**：
  - 船体：1200
  - 装甲：200
  - 极速：140
  - 幅能散耗：180
  - 幅能容量：2000
  - 部署点：5 DP
- **槽位**：
  - 2x 小型能量（前置），2x 小型导弹（硬点）。
