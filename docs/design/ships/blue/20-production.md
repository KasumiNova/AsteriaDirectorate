# 蓝线（ARC）：量产舰

> **设计哲学**：守卫秩序，拒绝妥协。量产型号在削弱极端性能的同时，通过标准化的散热与结构工程，确保即使在最绝望的战线，阿斯忒里亚的意志也能坚如磐石。

## 1. 战列舰：弧光喷流级（Arc Jet Class）

- **级别**：主力舰（Capital）
- **定位**：长线作战中坚支点 / 前向火力压制核心 / 战术网络中继
- **获取**：高阶赏金掉落 / 蓝图制造
- **设计状态**：重构草案

### 文案描述
弧光喷流级是弧光阵列量产体系中的正面压制主力。它不追求快速突入，而是依靠高韧性舰体、先进电网和覆盖友军的战术网络，在长时间交战中稳定推进战线。舰体的宽大翼面并非单纯装甲结构，而是为分布式火控与辐能共享网络提供的阵列平台。

### 核心定位

- **长线作战中坚支点**：预定峰值时间 720s，承担持续作战和阵线维持职责。
- **绝对前向火力压制**：正面武器布局与火控机制鼓励持续开火，持续输出越久收益越高。
- **低机动高韧性主力舰**：机动较差，中等航速，依靠护盾、装甲和舰体韧性顶住正面压力。
- **舰队战术网络核心**：通过共享战术网络强化小中型友军，主力舰本体承担代价和辐能压力。

### 独特 Hullmod：弧光先进火控

常态下，舰船武器辐能消耗提高 **20%**。该负面效果用于表示弧光火控系统在低负载状态下的高额校准成本。

当大型非点防武器持续开火时，火控网络逐步进入稳定态，并在 **6s** 内达到最大效果：

| 效果 | 最大值 |
|---|---:|
| 武器辐能消耗降低 | -40% |
| 非导弹武器射速 | +20% |
| 射弹速度 | +20% |
| 非导弹武器伤害 | +20% |

设计意图：
- 让弧光喷流级在持续正面交战中越来越强，而不是依靠短爆发完成击杀。
- 要求玩家维持火线和开火节奏；被迫停火、转向或切换目标时会失去部分优势。
- 额外辐能消耗的常态惩罚用于防止其在短交火和零散补枪场景中过强。

### 独特 Hullmod：弧光共享战术网络

舰船自身非导弹非点防武器射程降低 **20%**，作为承担战术网络中继的代价。常态获得 **4% 电子战网络加成**。

| 巡洋舰 | +20% | - | -10% |

阵营与子类型修正：

| 条件 | 效果 |
|---|---:|
| 设计类型为“阿斯忒里亚遗构局” | 加成效果 +25% |
| 子设计类型为“弧光” | 额外加成 +25% |

设计意图：
- 将弧光喷流级定义为小中型舰队的战术网络核心，而非单纯数值巨舰。
- 自身射程惩罚迫使它进入阵线中段或前段，避免在超远距离无风险提供光环。
- 主力舰无加成，避免多艘主力舰互相堆叠成过强战列线。

### 舰船系统：弧光共享辐能网络

激活时，弧光喷流级将自身电网转入共享耗散状态，牺牲本舰火力和机动，强化周围友军的输出窗口，并代为承接一部分友军辐能压力。

| 最远距离效果 | 25% 起，随距离衰减 |
| 范围修正 | 受到军官系统射程影响 |

友军激活期间效果：

| 效果 | 数值 |

系统限制：

| 参数 | 暂定值 |
|---|---:|
| 冷却时间 | 20s |
| 激活时间 | 10s |
| 强制关闭阈值 | 本舰辐能水平高于 90% |
| 启用限制 | 本舰辐能水平高于 90% 时无法启用 |

设计意图：
- 系统不是自身爆发按钮，而是舰队爆发窗口。
- 本舰承担友军辐能压力，使其高容量、高耗散和高韧性真正参与战术循环。
- 高辐能强制关闭防止玩家无代价把全队压力转嫁给单舰。

### 设计风险与待验证项

- **网络光环堆叠风险**：需要确认与电子战、军官技能、射程 hullmod 和其他光环的叠加顺序。
- **AI 使用风险**：系统需要避免 AI 在自身高辐能或脱离友军时无效开启。
- **数值风险**：友军射程与射速加成较高，首轮应重点验证护卫舰和驱逐舰是否过度受益。
- **体验风险**：本舰自身 -20% 射程和系统激活期 -50% 射速可能导致玩家误解为“开系统变弱”，需要通过视觉和状态文本明确其支援定位。

## 2. 巡洋舰：等离子拱级（Plasma Arch Class）

- **级别**：巡洋舰（Cruiser）
- **定位**：战线中坚 / 极端重盾重甲 / 反冲承压节点
- **获取**：蓝线赏金常见
- **设计状态**：重构草案

### 文案描述
等离子拱级是弧光阵列量产体系中的防御侧中坚。它不负责打开突破口，而是通过高度集成的等离子装甲护盾承受正面压力，为舰队提供可依赖的防线节点。相较弧光喷流级，它牺牲更多机动性和火力投射能力，换取接近主力舰级别的护盾与装甲承压能力。

### 核心定位

- **战线中坚**：预定峰值时间 600s，负责长时间维持战线完整。
- **主力舰级防御能力**：以重盾、重甲和方位装甲计算机制承担伤害。
- **火力投射一般**：不作为主输出舰，武器与系统均围绕承压和反冲防御展开。
- **中速低机动巡洋舰**：中等航速，机动较差，需要依赖阵线位置和友军掩护。

### 独特 Hullmod：等离子装甲护盾

#### 设定

等离子拱级的护盾生成器并非传统大型投射器，而是拆散为多个微型护盾单元，并完全集成于全舰装甲。护盾本身会表现出类似装甲的分区承压特征。

#### 方位装甲计算

舰船护盾和装甲受击时，会按受击方位取战斗内最终装甲值的一部分参与额外装甲减伤。该数值使用战斗内最终装甲值，而非基础装甲值，并使用与原版装甲减伤相同的算法。

| 受击方位 | 参与装甲计算值 |
|---|---:|
| 正前方 **60°** | 最终装甲值的 20% |
| 左右侧前方 **60°~180°** | 最终装甲值的 15%~20%，越靠近正前方越高 |
| 后方 **180°~360°** | 最终装甲值的 10%~15%，越靠近后方越低 |

受到装甲减伤抵消的伤害会弹出伤害数字。常态数字使用护盾蓝色，系统启动期间使用紫色，两者不叠加。

#### 伤害类型修正

护盾受到伤害时获得以下伤害类型修正：

| 伤害类型 | 修正 |
|---|---:|
| 能量 | -15% |
| 动能 | -33% |
| 高爆 | +33% |
| 破片 | +20% |

装甲受到伤害时获得以下伤害类型修正：

| 伤害类型 | 修正 |
|---|---:|
| 动能 | -33% |

#### 负面影响

- 禁止安装护盾分流与强化护盾，因为护盾系统已完全集成于装甲结构。
- 固定降低 **50%** 最大装甲值。

### 独特 Hullmod：离子化反冲蓄能器

舰船护盾和装甲受到伤害时，有概率产生电弧打击周围目标。该效果不由结构伤害触发。

#### 触发与目标

| 参数 | 数值 |
|---|---:|
| 起始触发辐能水平 | 25% |
| 最大触发辐能水平 | 85% |
| 冷却时间 | 1s |
| 基础射程 | 800su |

- 舰船辐能水平越高，触发概率越高，在 25% 辐能水平开始触发，并在 85% 辐能水平达到最大值。
- 触发概率会根据受击类型调整：
  - 护盾受击：动能伤害 **+75%**，高爆伤害 **-50%**，破片伤害 **-75%**。
  - 装甲受击：动能伤害 **-50%**，高爆伤害 **+150%**，破片伤害 **-75%**。
  - 光束伤害会在以上规则基础上额外 **-75%**。
- 触发概率会根据原始伤害强度调整：以舰船最大辐能的 **2%** 为基准，最终倍率限制在 **0.1x~3x**。
- 电弧优先打击周围舰船的武器或引擎。
- 电弧有概率根据本舰硬辐能水平击穿目标护盾。
- 电弧射程受到本舰能量射弹武器射程影响。
- 如果周围没有目标，则打击随机区域。
- 电弧不会攻击友军。
- 触发时播放 EMP 发生器打击音效。

#### 辐能转换与伤害

触发打击时，转换自身当前 **2% 硬辐能** 为等额软辐能。系统启动期间，辐能转换量与软辐能生成同步翻倍。

| 项目 | 数值 |
|---|---:|
| 伤害 | 转换辐能量的 100% |
| EMP 伤害 | 转换辐能量的 200% |
| 硬辐能转换 | 当前硬辐能的 2% |
| 软辐能生成 | 与被转换硬辐能等额 |

### 舰船系统：等离子装甲护盾增压

等离子拱级进入持续承压姿态，强化等离子装甲护盾与离子化反冲蓄能器，但显著牺牲非点防火力。

#### 系统效果

| 效果 | 数值 |
|---|---:|
| 护盾减伤 | 逐渐提高至 +50% |
| 装甲减伤 | 逐渐提高至 +25% |
| 非点防、非导弹武器射速 | -50% |
| 大额护盾单次伤害 | 超出最大辐能 5% 的部分降低 50% |
| 离子化反冲蓄能器打击伤害 | 2 倍 |
| 离子化反冲蓄能器辐能转换 | 2 倍 |
| 硬辐能生成 | 每秒 2% 基础辐能容量 |
| 持续方式 | 可持续开启 |

系统开启期间，等离子装甲护盾的方位装甲计算值翻倍，即额外装甲计算区间从 **10%~20%** 提高为 **20%~40%**。
激活期间护盾受到的单次伤害大于舰船最大辐能的 **5%** 时，超出的伤害部分降低 **50%**。该削减先于等离子装甲护盾的方位装甲计算生效。

#### AI 与实现备注

- 系统 AI 可直接复用原版“堡垒护盾”逻辑。
- 系统需要明确表达“承压强化”而不是“输出爆发”，避免玩家误判开启窗口。
- 常态护盾颜色为偏深蓝色，系统启动时护盾从蓝色转为紫色。
- 护盾边缘随机出现原版 EMP 电弧；端点允许从护盾边缘向中心约 15% 范围内偏移，路径需要更贴近边缘流动。
- 电弧端点使用小型 MagicLensFlare 光斑，颜色跟随当前护盾电弧颜色。
- 系统开启期间电弧生成频率翻倍。

## 3. 驱逐舰：辐射带级（Radiation Belt Class）

- **级别**：驱逐舰（Destroyer）
- **定位**：高速火力投射 / 单挑追猎 / 同型狼群作战
- **获取**：常见于蓝线赏金舰队
- **设计状态**：重构草案

### 文案描述
辐射带级是弧光阵列量产体系中的高速追猎驱逐舰。它依靠优秀电网、扩展弹仓和短促时流推进在中近距离持续压迫目标；单舰具备较强单挑能力，多艘同型舰或轻型友军协同时则形成高速狼群。

### 核心定位

- **火力投射**：以非导弹武器射程和弹仓强化保证持续压制能力。
- **高机动追猎**：高基础航速配合短冷却推进系统，负责追击、侧压和补刀。
- **单挑能手**：依靠射程、机动和时流窗口取得驱逐舰级别的节奏优势。
- **狼群作战**：通过分布式追猎网络强化周围护卫舰/驱逐舰，尤其鼓励同类舰种协同。
- **中等长线能力**：预定峰值时间 360s，具备持续作战能力但不承担阵线支点职责。

### 预定数值规格

|---|---:|
| 船体 | 5500 |
| 装甲 | 650 |
| 极速 | 95 |
| 幅能容量 | 6500 |
| 幅能耗散 | 500 |
| 护盾效率 | 0.70 |
| 部署点 | 14 |
| 峰值时间 | 360s |

### 内置原版 Hullmod

| Hullmod | 设计目的 |
|---|---|
| 扩展弹仓 | 强化弹匣/弹药型武器持续投射能力，支撑追猎压制。 |
| 辅助推进器 | 强化转向和机动控制，使其能维持追击角度与侧向压力。 |

### 独特 Hullmod：弧光先进目标定位系统

辐射带级搭载轻型弧光火控定位系统，专门补足中短射程武器在高速追猎中的有效交战距离。

| 效果 | 数值 |
|---|---:|
| 非导弹武器射程 | +20% |
| 基础射程小于 600 的武器额外基础射程 | 最多 +150 |

限制：
- 不兼容任何其他目标定位系统。
- 该系统用于强化追猎距离控制，不应与常规目标定位系统叠加。

### 独特 Hullmod：分布式追猎网络

辐射带级能够与舰船周围至多 **5 艘** 友军护卫舰或驱逐舰形成追猎网络。网络加成不受距离衰减影响，但目标必须处于最大距离内。

| 参数 | 数值 |
|---|---:|
| 最大连接数量 | 5 |
| 最大距离 | 1200 |
| 有效目标 | 友军护卫舰 / 驱逐舰 |
| 距离衰减 | 无 |

每艘已连接友军提供以下加成：

| 效果 | 每艘加成 |
|---|---:|
| 最大航速 | +4% |
| 机动性 | +4% |
| 武器射程 | +4% |
| 峰值时间消耗速率 | -4% |

目标限制：
- 提升目标不限，即连接目标不要求是弧光舰或同型舰。
- 如果连接目标也具有分布式追猎网络船插，则该连接提供的效果提升 **+50%**。

设计意图：
- 让辐射带级在单舰状态下依然是高机动火力舰。
- 多艘同类或轻型舰协同时形成明显的高速追猎编队。
- 加成集中在航速、机动、射程和峰值消耗，不直接堆叠伤害，降低狼群失控风险。

### 舰船系统：压限时流推进器

辐射带级短时间压缩舰体周围的局部时流，获得瞬时机动窗口，用于追击、横向规避、抢占角度或脱离火线。

| 参数 | 数值 |
|---|---:|
| 持续时间 | 2s |
| 额外时间流速 | +200% |
| 最大航速 | +50% |
| 侧向机动性 | +100% |
| 最大充能 | 3 |
| 充能时间 | 10s |
| 使用冷却 | 1.5s |

机制说明：
- 系统加成在 2s 内瞬时生效，不随时间爬升或衰减。
- 系统主要服务机动和节奏，不直接提高武器伤害。
- 多次充能允许连续调整角度，但 1.5s 使用冷却限制过度连发。
- 战术持续期间添加时流之壳风格 jitter，并复用电弧闪级残影渲染；残影刷新频率为电弧闪级战术系统的 2 倍。

## 4. 护卫舰：电弧闪级（Arc Flash Class）

- **级别**：护卫舰（Frigate）
- **定位**：自燃先锋 / 刹那之光
- **获取**：非常普遍

### 文案描述
小巧、凶猛、且极其不稳定。电弧闪级本质上是把一个超标的反应堆强行塞进了一个刚好能飞起来的壳子里。它不被期望从战场返回。在阿斯忒里亚的战术手册中，它的使命就是在敌阵中燃烧自己，用最后的过载脉冲为后续的主力舰扫清障碍。
*底层协议：当判断生存概率低于 5% 时，立即进入“最后时刻”自燃模式。*

### 舰船系统：静电释放（Static Discharge）
*“在熄灭前，我曾见过至高的光。”*
- **效果**：向周围 300su 内释放 EMP 电弧，瘫痪敌方导弹和战机。
- **用途**：冲入敌方导弹雨中强行清场。

### 数值规格（v0）
- **基础属性**：
  - 船体：1200
  - 装甲：200
  - 极速：140
  - 幅能散耗：180
  - 幅能容量：2000
  - 部署点：5 DP
- **槽位**：
  - 2x 小型能量（前置），2x 小型导弹（硬点）。
