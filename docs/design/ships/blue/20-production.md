# 蓝线（ARC）：量产舰

> **设计哲学**：守卫秩序，拒绝妥协。量产型号在削弱极端性能的同时，通过标准化的散热与结构工程，确保即使在最绝望的战线，阿斯忒里亚的意志也能坚如磐石。

## 1. 战列舰：烽燧级（XC-102）

- **级别**：主力舰（Capital）
- **定位**：长线作战中坚支点 / 前向火力压制核心 / 战术网络中继
- **获取**：高阶赏金掉落 / 蓝图制造
- **设计状态**：重构草案

### 文案描述
烽燧级是弧光阵列量产体系中的正面压制主力。它不追求快速突入，而是依靠高韧性舰体、先进电网和覆盖友军的战术网络，在长时间交战中稳定推进战线。舰体的宽大翼面并非单纯装甲结构，而是为分布式火控与辐能共享网络提供的阵列平台。

### 核心定位

- **长线作战中坚支点**：预定峰值时间 720s，承担持续作战和阵线维持职责。
- **绝对前向火力压制**：正面武器布局与火控机制鼓励持续开火，持续输出越久收益越高。
- **低机动高韧性主力舰**：机动较差，中等航速，依靠护盾、装甲和舰体韧性顶住正面压力。
- **舰队战术网络核心**：通过共享战术网络强化小中型友军，主力舰本体承担代价和辐能压力。

### 独特 Hullmod：先进火控集成

固定效果（不随难度）：舰船武器射程 **-20%**（承担集成火控阵列为舰体结构让位的代价），武器辐能产出 **+20%**（弧光火控系统低负载状态下的高额校准成本）。

当大型非点防武器持续开火时，火控网络逐步进入稳定态，并在 **6s** 内达到最大效果（停火后同长衰减）。以下持续性加成随难度系数缩放（迟暮/砺刃/破晓）：

| 效果 | 迟暮 | 砺刃 | 破晓 |
|---|---:|---:|---:|
| 武器辐能产出 | -30% | -40% | -70% |
| 非导弹武器射速 | +10% | +20% | +50% |
| 非导弹武器伤害 | +10% | +20% | +50% |
| 射弹飞行速度 | +15% | +20% | +35% |

设计意图：
- 让烽燧级在持续正面交战中逐步增强，避免依靠短爆发完成击杀。
- 要求玩家维持火线和开火节奏；被迫停火、转向或切换目标时会失去部分优势。
- 射程劣势与额外辐能消耗的常态惩罚用于防止其在短交火和零散补枪场景中过强。

### 舰船系统：辐能链接网络

> **重做注记（2026-11-01）**：原「弧光共享辐能网络」（对友军提供射速/耗散增益的光环）整体重做为本系统，
> 实装类 `FluxLinkNetworkSystemStats`/`FluxLinkNetworkSystemAI`，调参见 `FluxLinkNetworkTuning`。
> 链路光束复用「引力时流干涉器」的 `GravTimeflowLinkVfx`（蓝色主题，束体大小与 jitter 强度 -33%），
> 仅在存在实际辐能传输时渲染，亮度/粗细/摆动幅度随平滑后的传输速率缩放；
> 光束与粒子流向为 友舰 → 本舰（辐能流向），弧线淡入 0.5s、淡出 1.0s 以避免链路生灭跳变。
> 原冲击波环特效（`Xc102ShockwaveRingEffect`）随旧系统一并移除。

激活时，烽燧级链接周围的所有友舰，以自身辐能耗散的一定速率将友舰的辐能传输到自身，代为承接友军的辐能压力；代价是本舰火力和机动减半。

链接与传输规则：

| 规则 | 数值 |
|---|---|
| 链接范围 | 1000/1200/1800（随难度系数），受系统射程影响 |
| 传输速率 | 自身辐能耗散的 20%/25%/40% 每秒（软辐能全额，硬辐能 ×20%/25%/40%），无条件抽取 |
| 总速率上限 | 全链路合计不超过自身最终辐能耗散的 150%，超额时优先传输辐能水平最高的友舰 |
| 距离效率 | 25% 范围内 100%，75% 范围外降至 25%，中间线性过渡 |

本舰激活期间效果：

| 效果 | 数值 |
|---|---:|
| 辐能耗散速率 | +30%/+40%/+70% |
| 硬辐能耗散速率 | +15%/+20%/+35% |
| 武器射速 | -50% |
| 最大航速 | -50% |
| 机动性 | -50% |

系统限制：

| 参数 | 暂定值 |
|---|---:|
| 冷却时间 | 20s |
| 激活时间 | 10s |
| 强制关闭阈值 | 本舰辐能水平高于 90% |
| 启用限制 | 本舰辐能水平高于 90% 时无法启用 |

设计意图：
- 本舰承担友军辐能压力，使其高容量、高耗散和高韧性参与战术循环。
- 自身输出与机动减半防止开启窗口内本舰同时维持火力。
- 高辐能强制关闭防止玩家无代价把全队压力转嫁给单舰。

### 设计风险与待验证项

- **网络光环堆叠风险**：需要确认与电子战、军官技能、射程 hullmod 和其他光环的叠加顺序。
- **AI 使用风险**：系统需要避免 AI 在自身高辐能或脱离友军时无效开启。
- **数值风险**：传输速率按自身耗散比例结算，高耗散装配下抽能速度可观，首轮应重点验证是否过度抽空友舰或反向灌爆本舰。
- **体验风险**：系统激活期 -50% 射速/机动可能导致玩家误解为“开系统变弱”，需要通过视觉和状态文本明确其支援定位。

## 2. 巡洋舰：熔壁级（XC-101）

- **级别**：巡洋舰（Cruiser）
- **定位**：战线中坚 / 极端重盾重甲 / 反冲承压节点
- **获取**：蓝线赏金常见
- **设计状态**：重构草案

### 文案描述
熔壁级是弧光阵列量产体系中的防御侧中坚。它不负责打开突破口，而是通过高度集成的等离子装甲护盾承受正面压力，为舰队提供可依赖的防线节点。相较烽燧级，它牺牲更多机动性和火力投射能力，换取接近主力舰级别的护盾与装甲承压能力。

### 核心定位

- **战线中坚**：预定峰值时间 600s，负责长时间维持战线完整。
- **主力舰级防御能力**：以重盾、重甲和方位装甲计算机制承担伤害。
- **火力投射一般**：不作为主输出舰，武器与系统均围绕承压和反冲防御展开。
- **中速低机动巡洋舰**：中等航速，机动较差，需要依赖阵线位置和友军掩护。

### 独特 Hullmod：等离子装甲护盾

#### 设定

熔壁级的护盾生成器由多个微型护盾单元组成，并完全集成于全舰装甲。护盾本身会表现出类似装甲的分区承压特征。

#### 方位装甲计算

舰船护盾和装甲受击时，会按受击方位取战斗内最终装甲值的一部分参与额外装甲减伤。该数值使用战斗内最终装甲值，不使用基础装甲值，并采用与原版装甲减伤相同的算法。

| 受击方位 | 参与装甲计算值 |
|---|---:|
| 正前方 **60°** | 最终装甲值的 30% |
| 左右侧前方 **60°~180°** | 最终装甲值的 20%~30%，越靠近正前方越高 |
| 后方 **180°~360°** | 最终装甲值的 10%~20%，越靠近后方越低 |

受到装甲减伤抵消的伤害会弹出伤害数字。常态数字使用护盾蓝色，系统启动期间使用紫色，两者不叠加。

#### 伤害类型修正

护盾受到伤害时获得以下伤害类型修正：

| 伤害类型 | 修正 |
|---|---:|
| 能量 | -15% |
| 动能 | -33% |
| 高爆 | +33% |
| 破片 | +50% |

#### 负面影响

- 禁止安装护盾分流与强化护盾，因为护盾系统已完全集成于装甲结构。
- 固定降低 **50%** 最大装甲值。

### 独特 Hullmod：离子化反冲蓄能器

舰船护盾和装甲受到伤害时，有概率产生电弧打击周围目标。该效果不由结构伤害触发。

#### 触发与目标

| 参数 | 数值 |
|---|---:|
| 起始触发辐能水平 | 25% |
| 最大触发辐能水平 | 85% |
| 冷却时间 | 1s |
| 基础射程 | 800su |

- 舰船辐能水平越高，触发概率越高，在 25% 辐能水平开始触发，并在 85% 辐能水平达到最大值。
- 触发概率不再受到受击位置和伤害类型修正。
- 光束伤害会降低 **90%** 触发概率。
- 触发概率会根据原始伤害强度调整：以舰船最大辐能的 **2%** 为基准，最终倍率限制在 **0.1x~3x**。
- 电弧优先打击周围舰船的武器或引擎。
- 电弧有概率根据本舰硬辐能水平击穿目标护盾。
- 电弧射程受到本舰能量射弹武器射程影响。
- 如果周围没有目标，则打击随机区域。
- 电弧不会攻击友军。
- 触发时播放 EMP 发生器打击音效。

#### 辐能转换与伤害

触发打击时，转换自身当前 **3% 硬辐能** 为等额软辐能。系统启动期间，辐能转换量与软辐能生成同步翻倍。

| 项目 | 数值 |
|---|---:|
| 伤害 | 转换辐能量的 100% |
| EMP 伤害 | 转换辐能量的 200% |
| 硬辐能转换 | 当前硬辐能的 3% |
| 软辐能生成 | 与被转换硬辐能等额 |

### 舰船系统：等离子装甲护盾增压

熔壁级进入持续承压姿态，强化等离子装甲护盾与离子化反冲蓄能器，但显著牺牲非点防火力。

#### 系统效果

| 效果 | 数值 |
|---|---:|
| 护盾减伤 | 逐渐提高至 +50% |
| 装甲减伤 | 逐渐提高至 +25% |
| 非点防、非导弹武器 | 禁用 |
| 大额护盾单次伤害 | 超出最大辐能 5% 的部分降低 50% |
| 离子化反冲蓄能器打击伤害 | 2 倍 |
| 离子化反冲蓄能器辐能转换 | 2 倍 |
| 硬辐能生成 | 每秒 2% 基础辐能容量 |
| 持续方式 | 可持续开启 |

系统开启期间，等离子装甲护盾的方位装甲计算值翻倍，即额外装甲计算区间从 **10%~30%** 提高为 **20%~60%**。
激活期间护盾受到的单次伤害大于舰船最大辐能的 **5%** 时，超出的伤害部分降低 **50%**。该削减先于等离子装甲护盾的方位装甲计算生效。

#### AI 与实现备注

- 系统 AI 可直接复用原版“堡垒护盾”逻辑。
- 系统需要明确表达“承压强化”，避免玩家将其误解为“输出爆发”或误判开启窗口。
- 常态护盾颜色为偏深蓝色，系统启动时护盾从蓝色转为紫色。
- 护盾边缘出现整根原版 EMP 电弧；端点允许从护盾边缘向中心约 15% 范围内偏移，路径需要更贴近边缘流动。
- 护盾电弧更倾向于出现在近期受击方向。
- 电弧端点使用小型 MagicLensFlare 光斑，颜色跟随当前护盾电弧颜色。
- 系统开启期间电弧生成频率翻倍。

## 5. 巡洋舰：贯虹级（XC-105）

- **级别**：巡洋舰（Cruiser）
- **定位**：战线突破 / 高机动突击
- **获取**：蓝线赏金常见

### 文案描述

贯虹-级巡洋舰是星坠理事会量产的高机动破阵平台，专为撕裂敌方正面防线与执行高速突击而设计，与偏重防线维持的熔壁-级共同构成星坠主力舰队的巡洋中坚。

得益于独特的矢量增压推进器，贯虹-级能够在交火状态下依然保持巡航级的推进加成，且舰体表观质量与机动性会随航速攀升而同步倍增。当战局需要打开突破口时，贯虹-级会激活[贯虹突进]系统，如重锤般撞入敌方阵列核心，在撞击瞬间或冲刺终点由舰首释放狂暴的锥状能量冲击，将挡在突进轴线上的敌舰、战机与导弹一并掀飞，紧接着以舰首大型主炮与两翼导弹完成近距绝杀。

在星坠理事会的作战记录中，贯虹-级是撕碎密集盾墙最直接的手段。由于矢量增压效果高度依赖较低的硬辐能水平，老练的舰长往往不会用护盾硬抗远程消耗，而是选择在接敌瞬间全速切入，用无可阻挡的吨位与正面火力强行改写战线走向。

代号 [XC-105]。白虹贯日，锐不可当。

### 核心定位

- 高机动破阵巡洋舰：以 80 基础航速配合常驻零辐能加速（随硬辐能衰减），在巡洋舰级别拥有极强的接敌与转场效率。
- 航速驱动的动量重锤：通过“矢量增压推进器”将航速转化为最高 +100% 的质量与机动加成，越跑越灵活、越跑吨位越重。
- 冲撞与扇面推散控场：“贯虹突进”兼具爆发位移、高额全伤减免与巨幅质量提升，冲刺撞击或收束时的锥状能量冲击可强行推开前方舰船、战机与导弹，打乱敌方阵型与火线。
- 前向重火力倾泻：舰首 1 大混 + 2 中混 + 2 中导的紧凑布局，鼓励在冲刺破阵后利用近身窗口倾泻重火力。

### 独特 Hullmod：矢量增压推进器

> 由奇点核心直接驱动的矢量引力推进阵列。推进场在维持交火期零辐能加速的同时，会将动能实时折算为舰体的等效惯性质量与姿态推力，使舰船在高速机动中愈发灵巧且难以被阻挡；但当护盾承受过多硬辐能冲击时，推进场的增压效率将显著下滑。

舰船质量与机动性会随着舰船航速的增加而增加，最高可增加 100% 舰船质量值和机动性。
零辐能加速将始终启用，但加成会随着舰船硬辐能水平的提升而下降，在硬辐能水平 80% 时效果降低至最低值 10%。

不兼容不稳定喷射器、辅助推进器、安全协议超驰。

### 舰船系统：贯虹突进

> 短暂蓄能后令引擎阵列进入极限超载，驱使舰船沿朝向发起不可阻挡的破阵冲锋，大幅提升舰船质量并偏转来袭火力。冲锋途中一旦与目标发生剧烈碰撞，或冲刺抵达终点，积蓄的动能将在舰首瞬间坍缩为一道锥状能量冲击，重创并强行推开前方扇面内的一切单位。

激活后短暂充能 0.5s，随后获得 2s 的 150%/200%/350% 爆发性最大航速与加速度加成，并降低 80% 的转向速率。
冲刺期间舰船受到的全类型伤害降低 40%/50%/80%，提升舰船 100%/200%/500% 的质量值。
冲刺期间如果遭遇到剧烈撞击、或战术系统结束后，会对舰首前方扇形区（40°/60°/140°，400su/450su/600su 距离）释放一次锥状冲击，造成 600/1000/2200 点能量伤害，并向前方产生一定的冲击性推力（能够推动所有目标：舰船、战机、导弹），随后结束系统。

冷却时间 12s。
