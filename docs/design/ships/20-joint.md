# 联制线（星坠 × 紫菀联合设计品）

> **状态：设计立项（D27，2026-09-10）**
> 联制品 = 两局联合设计的造物。星坠供舰体与炮位，紫菀供火控与观测。
> design type：「菀星设计局-联制」（金色，近橙）；舰名按联名惯例两线词库各取一字（见 00-common §2.3）。

## 1. 超级护卫舰：锻萼级

> **状态：设计立项，机制待深化**——以下为一轮 brainstorm 定稿的设计骨架，数值待设计案深化后补齐。

- **级别**：护卫舰（Frigate）· 超级护卫舰（Super-Frigate）
- **定位**：量产型决斗者——护卫舰体量、限时巡洋级单目标输出；参考「淬刃」级与原版「亥伯龙」级的精英独狼位，但走蓝图量产
- **获取**：蓝图量产（稀有）
- **外形**：炮艇构型（紧凑重炮艇身 + 大推力引擎组，草稿已定，美术待制）
- **命名**：星坠出"锻"、紫菀出"萼"——萼是护花的甲；小船重甲炮艇即"带甲的萼"

### 设计骨架（D27）

- **单舰对决绝对优势**：1v1 环境下具有绝对性优势；
- **代价三件套**：高造价、高部署点、高月维护（对齐轻型主力舰档），以成本换取单体强度、限制泛滥；
- **机制方向「决斗校准」**：持续锁定同一目标数秒后，精度与伤害逐级爬升；同时承受多目标火网时增益清零——"单挑绝对优势"的机制化表达，天然防止群战滥强；
- **双线表达**：星坠供舰体与炮位（HYBRID 槽），紫菀供火控（命中向内置船插）。

### 待深化项

- 槽位与基础数值（v0 待出）；
- 舰船系统选型（围绕"决斗窗口"展开）；
- 「决斗校准」的三锚点数值（挂 P1 缩放体系）；
- 美术：炮艇草稿 → 正式贴图 + bloom 描边层。
