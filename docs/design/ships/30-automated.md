# 自动化体系：T4+ 自动化量产舰

> **设计哲学**：拒绝人性。这些舰船是逻辑的具象化，是余晖（Remnant）与阿斯忒里亚遗构局杂交产生的怪胎。它们摒弃了一切生命维持系统，只为执行最高效率的杀戮指令。

## 1. 自动化巡洋舰：极光栅格级（Aurora Grid Class）

- **级别**：巡洋舰（Cruiser）
- **定位**：防空节点 / 几何厚盾
- **视觉特征**：表面覆盖着密形的六边形散热/护盾栅格，像昆虫的复眼在冷漠地注视着深空。

### 文案描述
极光栅格级是防守主义的极致。它的每一寸外壳都由独立的逻辑栅格组成，可以在受到撞击的百万分之一秒内形成局部的引力补偿，将一切伤害的既成事实彻底拒之门外。

### 内置 Hullmod：分布式栅格（Distributed Grid）
*“逻辑无懈可击。防御亦然。”*
- **效果**：
  - 护盾展开/关闭速度 +100%。护盾受到 EMP 伤害 -50%。
  - **[无人模式特化]**：即便逻辑过载，系统也会强制绕过崩溃序列，拒绝进入传统的瘫痪状态。
  - **[载人模式限制]**：即便进行“软越狱”，人类的操作也无法完全对齐其底层的栅格响应，护盾击破后将产生正常过载。

### 舰船系统：栅格硬化（Grid Hardening）
- **效果**：5s 内护盾效率极大幅度提升（至 0.1），期间武器系统将被锁定，专门作为应对高强度打击的终极防御手段。

### 数值规格（v0）
- **基础属性**：
  - 船体：9000
  - 装甲：600
  - 极速：65
  - 幅能散耗：800
  - 幅能容量：12000
  - 部署点：25 DP
- **槽位**：
  - 自卫：大量小型能量（全向），2x 中型能量（炮塔）。
  - 辅助：1x 中型通用（中心）。

## 2. 自动化驱逐舰：磁暴折线级（Magnetic Storm Zigzag Class）

- **级别**：驱逐舰（Destroyer）
- **定位**：机动点防 / 猎杀辅助
- **视觉特征**：有着极其突兀的折线形装甲板，看起来像是坏掉的多边形。

### 文案描述
这种舰船的运动轨迹如同其名，完全不符合人类的驾驶直觉。它的侧向推进器甚至比主引擎更强。磁暴折线级通常被编入主力舰的侧翼，像牧羊犬一样清理来袭的导弹和战机——或者像狼一样撕咬落单的敌人。

### 内置 Hullmod：无惯性机动（Inertialess Maneuver）
- **效果**：
  - 加速度/减速度 +100%。
  - **[无人模式特化]**：侧向平移速度与前进速度一致（全向机动）。
  - **[载人模式限制]**：侧向速度为前进速度的 60%。

### 舰船系统：电磁爆发（EMP Burst）
- **效果**：瞬发，以自身为中心爆发 EMP 环，造成软幅能伤害并瘫痪周围极近距离的任何物体（包括导弹）。

### 数值规格（v0）
- **基础属性**：
  - 船体：3200
  - 装甲：300
  - 极速：120
  - 幅能散耗：400
  - 幅能容量：4000
  - 部署点：14 DP
- **槽位**：
  - 2x 中型能量（全向），4x 小型点防。

## 3. 自动化护卫舰：回声微光级（Echo Shimmer Class）

- **级别**：护卫舰（Frigate）
- **定位**：蜂群节点 / 一次性干扰器
- **视觉特征**：极小，几乎就是个带推进器的天线球。

### 文案描述
它们在战场上如同尘埃般微不足道，直到你的火控雷达因为处理过多的假目标而此时过热。回声微光级不仅仅是船，它是网络攻击的实体化载体。

### 内置 Hullmod：同调链路（Coherent Link）
- **效果**：
  - 每艘部署的同名舰船（回声微光级）为舰队提供 1% 的 ECM 等级（上限 10%）。
  - **[无人模式特化]**：部署点消耗 -1（变为 3 DP）。

### 舰船系统：信号过载（Signal Overload）
- **效果**：自毁。对周围中等范围造成微量伤害，但产生极其强烈的 EMP 冲击波和视觉致盲效果（大量白色噪点遮蔽屏幕区域）。

### 数值规格（v0）
- **基础属性**：
  - 船体：600
  - 装甲：50
  - 极速：180
  - 幅能散耗：100
  - 幅能容量：1000
  - 部署点：4 DP (无人模式 3 DP)
- **槽位**：
  - 1x 小型通用（全向）。

## 4. 自动化终极旗舰：顶点逻辑级（Apex Logic Class）

- **级别**：主力舰（Capital）
- **定位**：战役 Boss / 演算核心 / 规则篡改者
- **获取**：唯一（Unique），自动化危机的高潮

### 文案描述
如果说其他战舰是士兵，那么顶点逻辑级就是棋手。它没有舰桥，没有舷窗，只有两枚悬浮在力场中的量子核心，如同神明的双眼。这艘船的存在本身就在不断修改周围的物理常数——它从不在某个确定的位置，它只是一段在因果律中不断跳跃的概率。
*「回声」的警告：别试图用眼睛捕捉它。在你看到它的那一刻，它已经成为了你的过去。*

### 内置 Hullmod：零点演算核心（Zero-Point Compute Core）
*“因果是无能者的借口。我自定规则。”*
- **[无人模式机制]**：
  - **预知闪避**：它能感知未来的局部坍缩。每当高能反应即将触及其外壳时，它会自发地向另一种可能性偏移——表现为瞬间的位移。
  - **算力溢出**：它是一座移动的计算塔，为周围的子程序提供无尽的逻辑支援。
- **[载人模式限制]**：
  - 由于人类大脑无法理解其逻辑，移除“预知闪避”。
  - 替换为 **战术预测**：显示所有敌方导弹的轨迹和命中点（UI 辅助），且自带 +50% 自动瞄准精度。

### 舰船系统：逻辑崩塌（Logic Collapse）
*“你引以为傲的循环，也不过是冗余的死代码。”*
- **效果**：选定一艘敌方舰船（射程 2000su），强制将其“状态”回溯。
- **具体表现**：
  - 这种机制旨在跨越常规的物理交火，直接接管目标的系统权线。它能强行逆转敌人的技能运转周期，并在关键时刻引爆其护盾的反馈回路。
- **战术意图**：作为 Boss，它存在的目的就是为了打破平衡。它是完美的 **“节奏收割者”**。

### 数值规格（v0）
- **基础属性**：
  - 船体：14000
  - 装甲：800
  - 极速：50（看起来慢，但有瞬移）
  - 幅能散耗：1500
  - 幅能容量：20000
  - 部署点：60 DP
- **槽位**：
  - 2x 大型通用（软硬通吃），4x 中型协同，大量小型激光点防。
