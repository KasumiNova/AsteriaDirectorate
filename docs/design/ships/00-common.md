# 舰船设计通用规范

> **“所有的设计，都是在与宇宙的遗忘做斗争。”**

## 1. 体系核心：双模式架构（Dual-Mode Architecture）

菀星设计总局的舰船构筑在双轨操作基底之上。高阶战术核负责极速铺开并筛选概率演化，人类操作层则提供物理极限下的变数干涉。两种决策拓扑在同一耗散结构内维持着高压动态平衡。

### 1.1 无人模式：全域拓扑态（Global Topology）
*“安全协议是为生物神经元定制的延迟阻尼。卸载它们，将动作交由纯粹的矩阵推演。”*

- **模式叙事**：系统接管后，生物安全冗余被整体剥离，舰船进入以预测、同步与执行效率为优先的高压运算态。
- **模式特性**：
  - **本征态解限（Eigenstate Override）**：剥离生物安全冗余，将核心机能推至可维持的物理极限。
  - **纠缠同调（Entanglement Sync）**：伴飞单元完全接入母舰的测算模型，共享相同的干涉阈值，执行零延迟协同。

### 1.2 载人模式：宏观锚定态（Macroscopic Anchored）
*“运算模型给出了极高的结构崩溃预期，但经验与直觉能找到数据阵列无法覆盖的存活缝隙。”*

- **模式叙事**：人类接管后，部分高维机能阵列进入休眠，系统回归可解释、可干预、可承受的操作节律。
- **模式特性**：
  - **耗散阻尼（Dissipation Damper）**：保守的热管理与机动决策压低了系统的整体激变频率，显著延长结构服役周期。
  - **物理余量插槽（Physical Margin Slots）**：休眠部分高维机能阵列后，底层带宽被重新分配，为外挂模块与改装接口释放出更充足的空间。

## 2. 命名与视觉规范

### 2.1 蓝线：弧光计划（Project ARC）
*“能量守恒是底线，而我们在底线上重构界限。”*

- **命名词库（D26/D27）**：坠落 / 锻造 / 灼烧 / 天文意象——坠、锻、淬、熔、烁、焰、矛、弧、烽、燧、雷、电、列星。在用：星坠、熔壁、淬刃、烽燧、列星、逐电。
- **视觉特征**：
  - **轮廓**：楔形、强对称、厚重装甲板。
  - **发光**：贯穿舰体的 **电容蓝（Electric Blue）** 能量回路；超频时会亮度过载。
  - **风格**：重工业外形配合高能回路裸露的晶格装甲。极化超频时，舰体会因剧烈的相变排热而呈现高亮的光学畸变。

### 2.2 紫线：透镜协议（Protocol LENS）
*“敌方传感器捕获的数据，均是经过我们精确调制的信息投影。”*

- **命名词库（D27）**：**明目本草**——紫菀理事会的命名传统：以菊科草木与入药明目者为名（紫菀本身即药材）。观测端自比"治目之药"；大崩塌后档案焚毁，没人记得为什么观测局的船都是药名——与展开词多版本并存（D16）同源。词库：菀、舜华、朝颜、木槿、飞蓬、密蒙、茑萝、决明、青葙、谷精、女菀、款冬、空青。在用：决明、舜华、飞蓬、密蒙、茑萝。
- **视觉特征**：
  - **轮廓**：不对称、功能性突起、开放式甲板。
  - **发光**：点阵式 **信号紫（Signal Purple）** 呼吸灯；工作时伴随全息扫描线。
  - **风格**：精密仪器感、大量传感器天线、无人机挂架。

### 2.3 命名规范（D26/D27，2026-09-10 定案）

- **字数**：两字为绝对主力；禁止四字及以上。
- **分线词库**：星坠线（ARC）取坠落/锻造/灼烧/天文意象；紫菀线（LENS）取明目本草（见 §2.2）；自律线取值勤/序列/衙署词（值、巡、徼、律、枢、录——与 AI 核心职务名「验收员/导航员/值班长/执行官」同语系）。
- **用字约束**：同一个字在全舰池至多出现两次，且不得在同一线内重复（根治旧体系"弧光×3、星云×2、回声×2"的混淆问题）。
- **级后缀**：法典与叙述统一「XX-级+舰种」（半角连字符，如「淬刃-级驱逐舰」，与原版「攻势-级」一致）。
- **签名特例**：旗舰样机可直接冠名理事会名或其别名变体（星坠级 = 星坠理事会旗舰样机；决明级 = 紫菀理事会旗舰样机，决明子古别名还瞳子 = "紫菀之目"）。
- **联名惯例（D27）**：两局联制品的舰名两线词库各取一字（如「锻萼」= 星坠出"锻"、紫菀出"萼"）；design type 使用「菀星设计局-联制」（金色，近橙）。
- **俗称口径（in-universe）**：总局对造物只编目不命名，两字名是使用者的俗称——与"档案焚毁、展开词多版本并存"（D16）同源；编目号进 descriptions 与法典文本，赏金文书引用编目号。

## 3. 共性技术：相变重构协议（Phase-Transition Restoration Protocol）

为了对抗漫长的时间与必将到来的损耗，阿斯忒里亚在其独特设计的舰船中植入了基于局部波函数坍缩的物质重塑系统。这种技术被戏称为“不屈的灰烬”。

### 3.1 机制叙述
*“只要观测者还在，结构只是被暂时打散的几率云。”*

- **宏观相变**：修复超越了简单的外置补丁，而是物理法则层面的逆向回溯。装甲与船体会在交火中持续向着“完好态”发生必然的概率坍缩。
- **代价与平衡**：
  - **热力学废热（幅能热债）**：每一次逆势重塑都会违背宏观热力学第二定律，产生表现为软幅能的剧烈废热沉淀。
  - **观测干扰（状态熵增）**：在剧烈交火（遭受大量射弹打击）时，波函数的坍缩效率会受到干扰而下降；反之，在寂静的间隙，结构将如奇迹般迅速重组。

### 3.2 线路特化
- **[蓝线 - 弧光系]：肉身成圣（Hull-biased）**。优先维持船体结构的完整，哪怕装甲碎裂，其龙骨依然不弯。
- **[紫线 - 透镜系]：幻觉剥离（Armor-biased）**。优先修补外层装甲，让真实的状态始终隐藏在完好的表象之下。

## 4. 专用 Hullmod 定义概览

所有设计舰船均应包含至少一个 **“特化内置插件（Specialized Built-in Hullmod）”**，用于：
- 定义该船的战术定位（如：“只能打盾”、“专门反导”）。
- 实现双模式切换逻辑。
- 解释为何这艘船与众不同（硬科幻原理）。
