# 紫线（LENS）：量产舰

> **设计哲学**：观测即重塑。与其去对抗物理法则，不如去欺骗感知这些法则的系统。量产舰船各司其职，共同构建起一个让敌人无法理解、无法反击的信息迷宫。

## 1. 指挥舰：磁层扰动级（Magnetosphere Disturbance Class）

- **级别**：主力舰（Capital）
- **定位**：战场中枢 / 逻辑中继
- **获取**：高阶赏金 / 蓝图

### 文案描述
如果说引力透镜级是某种不可直视的旧神，那么磁层扰动级就是支撑这种恐怖存在的祭坛。它牺牲了坚固的装甲，旨在换取一个覆盖整个战区的局域逻辑网。它并不直接战斗，而是优雅地调拨着数以百计的无人机群，像是在虚空中编织一段名为杀戮的协议。

### 内置 Hullmod：舰队协同中继（Fleet Coordination Relay）
*“不需要看见，只需要同步。”*
- **效果**：只要该舰在场（CR > 40%），所有友军战机/无人机的复活速率（Replacement Rate）衰减速度降低 20%。
- **光环**：周围 1000su 内的友军获得 +5% 射程。

### 舰船系统：紧急召回（Emergency Recall）
- **效果**：立即将所有在外的战机/轰炸机传送到舰体附近，并瞬间恢复其一轮弹药。
- **代价**：大量产生幅能。

### 数值规格（v0）
- **基础属性**：
  - 船体：13000
  - 装甲：900
  - 极速：50
  - 幅能散耗：800
  - 幅能容量：15000
  - 部署点：40 DP
- **槽位**：
  - 3x 飞行甲板，2x 大型导弹（侧舷），大量小型点防。

### 2. 巡洋舰：暗潮星云级（Dark Tide Nebula Class）

- **级别**：巡洋舰（Cruiser）
- **定位**：虚无代理人 / 视觉剥夺
- **获取**：常见

### 文案描述
暗潮星云级游离在战线边缘，如同乌云般笼罩着战场。它搭载的多组相干干扰发射器并不造成物理损伤，它们剥夺的是目标的“认知权力”。在它的阴影下，即使是威力巨大的主炮，也只能对着空无一物的虚空徒劳开火。

### 内置 Hullmod：暗潮干扰器（Dark Tide Jammer）
*“我允许你怀疑，但我禁止你确信。”*
- **效果**：被该舰攻击的敌人（即使被护盾阻挡），武器射程暂时降低 100su（不可叠加，持续 3s）。

### 舰船系统：电磁烟幕（EM Smoke）
- **效果**：向前方喷吐一团阻断视线和锁定的带电烟雾。
- **作用**：穿越烟雾的导弹会失去目标；而在烟雾内的船只无法被锁定。

### 数值规格（v0）
- **基础属性**：
  - 船体：7000
  - 装甲：700
  - 极速：70
  - 幅能散耗：600
  - 幅能容量：9000
  - 部署点：22 DP
- **槽位**：
  - 1x 飞行甲板（支援用），2x 中型能量（光束），2x 中型导弹。

---

### 3. 驱逐舰：衍射级（Diffraction Class）

- **级别**：驱逐舰（Destroyer）
- **定位**：镜像卫士 / 偏转者
- **获取**：紫线赏金常见

### 文案描述
衍射级的设计初衷是作为一个移动的无人机中继站。虽然船体脆弱，但其独特的相位线圈结构允许它通过“衍射”敌方的火力来规避伤害。在它开启护盾的瞬间，现实的轨迹也会发生细微的偏移，让毁灭性的光芒擦肩而过。

### 内置 Hullmod：相位衍射盾（Phase Diffraction Shield）
*“没有什么是坚不可摧的，除了幻觉。”*
- **效果**：护盾展开速度 +100%。护盾受到光束武器（Beam）伤害减少 40%。
- **代价**：护盾受到动能（Kinetic）伤害增加 15%。

### 舰船系统：无人机激化（Drone Surge）
- **效果**：强制激活所有内置支援无人机（Defense Drones），使其在此期间攻击频率大幅提升，并能主动拦截导弹。

### 数值规格（v0）
- **基础属性**：
  - 船体：3000
  - 装甲：350
  - 极速：100
  - 幅能散耗：400
  - 幅能容量：5000
  - 部署点：12 DP
- **槽位**：
  - 1x 内置机库（无法更换，固定为衍射防御无人机），2x 中型能量（全向）。

## 4. 护卫舰：闪烁虚影级（Flickering Phantom Class）

- **级别**：护卫舰（Frigate）
- **定位**：逻辑诱饵 / 消耗品
- **获取**：极易获取

### 文案描述
廉价的无人机载具，也是透镜协议中最廉价的伪装手段。它们在战场上的唯一意义就是制造“存在”的幻觉，诱导敌人的火控计算机在处理海量的虚假信号中彻底宕机。即使被击毁，其残骸散发的电磁噪音也会继续干扰战场。
*「回声」的低语：我也许不存在，但我的痛觉是真的——至少对你们的雷达来说是这样。*

### 舰船系统：全息分身（Holographic Decoy）
*“真相多一个，世界就完美一分。”*
- **效果**：向侧方发射一枚全息诱饵，诱饵具有实体碰撞体积（极低耐久）和高威胁信号。
- **战术**：用来挡枪，或者骗 AI 转火。

### 数值规格（v0）
- **基础属性**：
  - 船体：900
  - 装甲：150
  - 极速：150
  - 幅能散耗：150
  - 幅能容量：1800
  - 部署点：4 DP
- **槽位**：
  - 1x 中型通用（仅硬点，用于安装战术导弹或干扰器），2x 小型能量。
