# 紫线（LENS）：量产舰

> **设计哲学**：观测即重塑。与其去对抗物理法则，不如去欺骗感知这些法则的系统。量产舰船各司其职，共同构建起一个让敌人无法理解、无法反击的信息迷宫。

## 1. 指挥舰：飞蓬级（ZW-102）

> 重做前提：**战列航母**；主要依靠**战机为主要战力和机制**取胜；舰船系统以原版**召回装置**为基线做增强处理并挂难度系数（轨一三锚点）。

- **级别**：主力舰（Capital）；designation「航空战列舰」+ hints `CARRIER`（图鉴按航母类归类，对齐原版军团级判例）
- **定位**：战场中枢 / 逻辑中继
- **获取**：高阶赏金 / 蓝图

### 文案描述（原案）
如果说决明级是某种不可直视的旧神，那么飞蓬级就是支撑这种恐怖存在的祭坛。它牺牲了坚固的装甲，旨在换取一个覆盖整个战区的局域逻辑网。它并不直接战斗，而是优雅地调拨着数以百计的无人机群，像是在虚空中编织一段名为杀戮的协议。

### 内置 Hullmod：维度折叠甲板
根据难度系数，战机 LPC 所需的装配点提升 50%，但每个战机甲板的联队战机数量 +50% ~ 250%。

### 舰船系统：战机引力联结器
- **效果**：根据难度系数，提升战机 100% ~ 200% 的时间流速，降低战机 25%~75% 受到的所有伤害，至多持续 15s（toggle 型，持续期间再次按键可提前关闭；机群全灭时提前结束），战术系统结束后进入 1s 召回窗口：所有部署在外的战机进入相位态（免伤免撞）并渐隐，窗口末召回至航母机库并快速重新出击。
- **冷却时间**：25s
- **代价**：激活时持续产出舰船基础最大辐能的 7% 的软辐能，战术系统结束后将未被耗散的全部软辐能消耗并转换为等量硬辐能。
- **特效**：战机在战术系统持续期间添加持续舰船 jitter 特效；召回窗口内快照战机进入相位态（免伤免撞）并随窗口渐隐、逐机播放召回音效，复用“召回装置”战术系统的视觉语义。

### 数值规格（v0，原案）
- **基础属性**：
  - 船体：12000
  - 装甲：1200
  - 最大航速：50
  - 幅能散耗：1100
  - 幅能容量：16000
  - 部署点：55 DP
- **槽位**：
  - 3x 飞行甲板，1x 大型导弹，2x 大型能量，7x 小型能量。

## 2. 相位护航航母：茑萝级（ZW-103）

> **状态：全重做已定（D27）**——定位/数值/机制全部重做，本节原案内容不追认、仅作考古留存。
> 重做前提：**相位护航航母**；主要对大型舰船（巡洋/战列）进行护航（「施于松柏」绑定方向）；在主力舰船的掩护下于近距离格斗领域具有压倒性的战术与数值优势，但单带能力差。

- **级别**：驱逐舰（Destroyer）
- **定位**：近距护航航母
- **获取**：紫线赏金常见

### 文案描述
茑萝-级最初的定位是用于护航高价值单位的战斗航母，能够在主力舰提供火力掩护的前提下，对近距离的同级目标造成毁灭性的打击。

茑萝-级在近距离的格斗能力相当出色，且最出名的大概就是它的能源核心所搭载的裂隙发生器了 —— 茑萝-级能够短暂超载自身的能源核心，在较短距离的目标展开一道引力裂隙，随后释放一束裂隙喷流，对目标位置产生多段引力坍缩，造成严重的坍缩伤害。

茑萝-级的引力相位甲板搭载了独特的相位无人战机，能够与母舰形成引力联结，当它们同时对单个目标发起进攻时，其威胁等级毫不弱于坠星科研部的列星-级，甚至可以说更强。

### 内置 Hullmod：引力相位甲板
- **效果**：
  - 当母舰进入相位状态时，战机也会一同进入相位状态，且战机不会产生相位维持辐能。
  - 根据难度系数，战机所产生的 50%/60%/90% 软辐能和硬辐能会直接以软辐能的形式返还给母舰，在母舰辐能水平达到 80% 时失效。

### 舰船系统：引力裂隙发生器
- **效果**：需锁定目标舰激活（无目标时系统不可用，HUD 提示「无目标」；已锁定但超出系统射程 1000su（受战术系统射程加成）时提示「超出射程」）。激活时在目标舰体随机位置（8 次采样，优先无护盾覆盖区域）产生红色贴图旋涡（60°/s 自旋，1s 淡入 + 1s 淡出，共 3s；旋涡半径 = 目标碰撞半径 ×0.75，钳制 [90, 260]su）；1s 后旋涡中心向目标发射**真实裂隙光束**（持续 2s，光束基础射程 1000su，受能量武器与光束武器射程加成；光束伤害 1000 DPS 能量）。光束持续命中期间每 0.1s 沿目标周边弧线布下一枚时空（引力）裂隙（数量 =(光束射程 − 命中长度)/200 + 1，最多 5 枚；命中护盾时布点间距 ×0.67）。根据难度系数，每枚裂隙对附近目标造成 600/800/1200 至 1000/1400/2000 的能量坍缩伤害（随生成序位递增：首枚取下限、末枚取上限）。冷却 12s。
- **实现要点**：真实光束由隐藏光束武器 astd_grav_rift_beam（specClass=beam，红色正色 LASER 束体）挂载在 FX drone（原版 dem_drone）上实现——spawnProjectile 不支持 specClass=beam，FX drone 为 mod 界成熟技巧；源舰射程/伤害加成折算到 drone，drone 上的 AdvanceableListener 每帧定位旋涡中心/瞄准目标/强火，到时自移除。光束布雷机制直接复刻原版裂隙洪流发射极（riftcascade）的 BeamEffect（弧线行走、命中护盾减速、bounds 吸附、0.1s 间隔），刻意差异仅三处：不使用反色星云粒子、裂隙伤害走难度三锚点序位插值（非原版 getSizeMult 收束）、母舰经 DRONE_MOTHERSHIP 旗标归属。裂隙爆炸（GravityRiftMineExplosion）改为正色视觉（极淡红中心闪光 + 红→极淡红星云 + 提亮粒子），伤害仍走 explosionSpec。旋涡为单贴图分层渲染插件（contents/graphics/fx/astd_vortex_red.png，由 astd_vortex.png 亮度映射转红；加法混合素材必须圆形、边缘 alpha 归零、无烘焙底色——前两轮方形渐变/蓝白底实机事故的教训），系统打断时 forceFadeOut 收口。时序：chargeUp 1s（旋涡淡入）→ active 1s（光束发射）→ down 1s（旋涡淡出）。系统 AI 走 TARGET_FOR_SHIP_SYSTEM 旗标锁定（原版熵放大器同款约定）。
- **对外玩家描述**：超载奇点核心，需锁定目标舰激活：在目标舰体表面撕开一道红色引力旋涡，旋涡在 1s 延迟后向目标发射裂隙光束，光束命中处沿舰体周边展开时空引力裂隙（最多 5 枚）。根据难度系数，每个裂隙对附近目标造成 600/800/1200 至 1000/1400/2000 的能量坍缩伤害。

## 3. 尖兵：舜华级（ZW-101）

> **状态：全重做已定（D27）**——定位/数值/机制全部重做，本节原案内容不追认、仅作考古留存。
> 重做前提：**相位驱逐舰·量产档**；主要依靠**进攻性舰船系统 + 大量机制**取胜；「残响齐射」（进入相位时重放本舰近期射击的残响）方向可用、暂不深化；生存堆叠需克制（原案 160 航速 + 相位 + 95% 出相位减伤 + 信号伪装，砍至两层）。

- **级别**：驱逐舰（Destroyer）
- **定位**：侦察 / 标记 / 生存
- **获取**：量产（蓝图）

### 机制描述（原案）
舜华级是雷达上的幽灵、通讯链路中的噪音。它体现了透镜计划的作战取向：不以击毁为目的，而是持续破坏目标对战场信息的信任——让敌人在自我怀疑中丧失判断与协同。

### 内置 Hullmod：回声发生器（Echo Emitter）（原案）
- **纳米重构协议**：紫线特化（装甲修复优先）。
- **动态信号**（核心：以传感器信号塑形自身威胁度）：
  - 高速时：传感器信号（Sensor Profile）显著放大（模拟更大吨位单位），更容易吸引火力与锁定。
  - 低速/漂移时：传感器信号急剧降低（进入近似“空白回波”状态），更容易断锁与脱离接触。
- **相位潜航**：具备相位能力（Phase Field）。该舰的相位用于“位置信息战”而非纯输出：进相位后切换存在位置，出相位后重新建立接触。

### 特殊船插（内置 Hullmod）：回声回落缓冲（Echo Reentry Buffer）（原案）
- **效果**：退出相位后的 3s 内，获得 **全伤害减免**，从 **95%** 线性衰减到 **0%**（即：刚出相位几乎打不动，但很快恢复为正常）。
- **设计意图**：避免“刚出相位被秒”导致的体验崩坏，同时通过线性衰减保留追击与预判的反制面。

### 特殊船插（内置 Hullmod）：相位谐振干扰（Phase Resonance Jamming）（原案）
- **效果**：当舜华处于相位状态时，会干扰 1000su 内的其他相位舰船：
  - 提高其峰值时间（PPT）与 CR 消耗速度（更快烧尽）。
  - 削弱其武器精度与机动性（更难命中、更难贴脸）。
- **用途**：在“相位内”打相位战，专门克制对方的相位突击与拖时。

### 舰船系统：信标投放（Targeting Beacon）（原案）
- **效果**：在当前位置留下一枚隐形信标，随后立即进入相位状态并向鼠标方向短距离瞬移。
- **信标作用**：信标持续发出强烈的“诱导信号”，强制吸引周围敌方导弹的锁定，并降低周围敌舰的护盾效率（干扰波）。

### 数值规格（v0，原案）
- **基础属性**：
  - 船体：2000
  - 装甲：300
  - 最大航速：160（极快）
  - 相位：标准相位消耗
  - 部署点：12 DP
- **槽位**：
  - 1x 中型通用（用于安装功能性压制武器），2x 小型导弹。
