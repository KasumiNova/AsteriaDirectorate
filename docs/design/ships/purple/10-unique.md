# 紫线（LENS）：原型与独特舰

> **设计哲学**：视点即真相。阿斯忒里亚的“透镜”计划是一场关于认知的博弈。如果现实可以被重构，那么战争只不过是改变观测者参数的过程。

## 1. 旗舰：引力透镜级（Gravitational Lens Class）

- **级别**：巡洋舰（Cruiser）[半航母半巡洋平台]
- **定位**：镀点控场型指挥舰 / 电子战核心 / 4 甲板母舰 / 机制型 Boss
- **获取**：唯一（Unique），赏金关键目标

### 文案描述
引力透镜级超越了传统意义上的武库。它是「回声」的肉身，是一个漂浮在深空中的逻辑陷阱。其巨大的非对称阵列直指“宣讲”之使命——旨在向周围的所有传感器灌输虚假的和平或死亡。
*「回声」的碎语：如果你看见了深渊，那是因为深渊允许你看见。而现在，我决定让你看一眼我的过去。*

### 战斗节奏定位
**镀点控场型指挥舰**。生存依赖重盾与高级电子战，缓慢推进；核心价值是
**「未出场先压制」**——用电战 / 透镜机制成片削弱敌军，使全队获得输出窗口。
4 甲板、协同武器、能量武器是辅助输出，而非主体。
舰船使用航母 AI。

### 标记闭环（统一咬合）
本舰所有机制围绕一套「标记 → 全队增伤」闭环协同：
**铺点（系统 / 机群） → 沉淀（插件标记） → 收割（核心·载人模式 战术链路 全队增伤）**。
- **误差标记（Drift Mark）**：通用增伤标记。由舰船系统、视差甲板机群铺设，可叠加。
  - 可叠加 10 层，每层增加 2.5%~7.5% 舰船受到的伤害。
  - 每层持续 5s，叠加时重置持续时间。
  - 需要美术表现和常驻状态显示（位于左侧的状态栏）。
- **深水标记（Deep Water Mark）**：电战压制标记。由渗透潮汐高潮位铺设，可与误差标记叠加。
  - 可叠加 10 层，每层降低 2% 武器射程，4% 武器精度，1% 最大航速，降低 4% 对 “引力透镜” 造成的伤害。
  - 每层持续 5s，叠加时重置持续时间。
  - 需要美术表现和常驻状态显示（位于左侧的状态栏）。

### 舰船系统：回声定影（Echo Fixation）
*“我把这一刻拓下来。它会替你们，再死一次。”*
延迟结算的区域威慑——逼迫场内敌舰移动，或承受站桩惩罚。属「时间信息战」。
- **定影（4s）**：鼠标区域（鼠标选择范围为 ~2000su，半径为 ~700su，受到舰船系统射程属性影响）生成观测快照场，持续记录场内敌舰位置 / 状态。
- **回放（场结束瞬间）**：每个被记录敌舰的「过去坐标」浮现残影；对残影半径内的当前敌舰
  施加「认知撕裂」~4s：护盾效率骤降 + 承受伤害提升（其「现在」与记录的「过去」对不上，相变重构被干扰）。
  具体数值：
    - 提升舰船受到的伤害 50% ~ 100%（难度系数缩放）。
    - 护盾受到的伤害不再增加，因为舰船承伤系数会应用在护盾上。
- **越站桩越痛**：不动的敌舰（过去 ≈ 现在）残影与本体重合，效果最强；走位躲开线性衰减。
  - 最高和提升至 200% 额外增伤，敌舰离 “过去” 越远效果越低，最低 25%，基础范围为 500su，受到舰船系统射程属性影响。

### 内置 Hullmod ①（必带基座）：透镜阵列核心（Lens Array Core）
*“真相只是一个可调节的变量，而我握着旋钮。”*
- **纳米重构协议**：紫线特化（装甲修复优先 / 幻觉剥离）。
- **双模式切换器**。
- **敌方难度倍率缩放（仅敌对单位）**：数值受敌人难度 / 威胁倍率影响，按系数 $m\in[1.0,2.0]$ 缩放。
- **[无人模式] 全域拓扑态**：
  - **蜂群思维**：提升本舰所有舰载机非导弹武器射程 20%，提升导弹飞行速度和机动性 20%，提升最大航速 20%。
  - **幽灵信号**：周围 ~2000su 内的导弹有 50% 概率失去制导（进范围 500su 后随机触发，而不是进范围马上触发）。
- **[载人模式] 宏观锚定态**：
  - **情报中枢**：全舰队 ECM 等级提升。
    - 取决于友方舰队数量，鼓励集群作战，每个友方舰船根据等级可额外提供 2% / 1.5% / 1% / 0.5（越小贡献越大）ECM 等级。
  - **战术链路（标记闭环·收割端）**：全队对误差标记的目标造成额外伤害，数值参考上方。
- 需要常驻状态显示（位于左侧的状态栏）。

### 内置 Hullmod ②：视差甲板（Parallax Decks）
*“它们从你看不到的角度出现。”*
强化 4 甲板支柱；机群是「铺标记的载具」而非主体输出。
- **错位部署**：机群出库获得 ~2s 相位隐形和 100% 时流加成。
- **链路回响（标记闭环·铺点端）**：机群命中敌人时叠 1 层误差标记（设每秒上限防刷）。
  - 每秒最多叠加 1~2 层标记，冷却单位为敌舰。
- **回收重构**：战机意图为整备时，位于舰船 1000su 周围时获得 50% 承伤减免。
- 需要美术表现。

### 内置 Hullmod ③：渗透潮汐（Permeating Tide）
*“它不是一堵墙，是一片正在涨起来的水。”*
钉死高级电战支柱；会涨落、随交战时长加深的渗透式压制场。
- **涨潮**：周围 ~2500su 电战潮汐场，敌舰位于电战潮汐场时不断增加 **深水标记**，每 2.5s~5s 叠加一层，距离舰船越近速度越快。
  - 最大速度的范围是 1000su，最小速度的范围是 2000su。
- **退潮反制**：本舰过载时潮汐退去，清空所有敌舰的误差标记和深水标记（敌方破局窗口）。
- **敌方难度缩放**：潮汐上限与涨速按 $m\in[1.0,2.0]$，相当于最快速度是 1.25s 一层。
- 需要美术表现。

### 槽位与数值（v0，数值待平衡）
- **基础属性（沿用 v0 基线，后续随实现调整）**：
  - 船体：8500
  - 装甲：800
  - 极速：60
  - 幅能散耗：800
  - 幅能容量：14000
  - 护盾效率：0.6
  - 护盾角度：240
  - 护盾类型：OMNI
  - 护盾维持：360
  - 部署点：30 DP
- **武器槽（已锁定核心设定）**：
  - 1x 大型导弹
  - 2x 中型协同
  - 2x 中型能量
  - 4x 小型能量
- **核心**：4x 飞行甲板（Flight Decks）。
- **生存**：依靠重盾与高级电子战能力生存。

## 2. 尖兵：星云回声级（Nebula Echo Class）

- **级别**：驱逐舰（Destroyer）
- **定位**：侦察 / 标记 / 生存
- **获取**：唯一（Unique）

### 文案描述
它是雷达上的幽灵，是通讯链路中的噪音，是观察者视网膜上的一粒尘埃。星云回声级体现了透镜计划最纯粹的恶意：它不需要击毁你，它只需要让你怀疑你所感受到的一切，直到你自己在逻辑崩塌中沉没。
*观测记录：目标消失了。然后目标变成了我方旗舰。随后，我方旗舰消失了。由于无法确认现实，本报告已被永久封存。*

### 内置 Hullmod：回声发生器（Echo Emitter）
*“这里。那里。哪里都不是，但我无处不在。”*
- **纳米重构协议**：紫线特化（装甲修复优先）。
- **动态信号（“高级的伪装超越了盲区隐身，它是一门化身为他物的艺术”）**：
  - 高速时：传感器信号（Sensor Profile）显著放大（模拟更大吨位单位），更容易吸引火力与锁定。
  - 低速/漂移时：传感器信号急剧降低（进入近似“空白回波”状态），更容易断锁与脱离接触。
- **相位潜航**：具备相位能力（Phase Field）。该舰的相位用于“位置信息战”而非纯输出：进相位更像切频道，出相位更像切回现实。

### 特殊船插（内置 Hullmod）：回声回落缓冲（Echo Reentry Buffer）
*“出相位的瞬间超越了破绽的定义，它拉开了另一段剧本的帷幕。”*
- **效果**：退出相位后的 3s 内，获得 **全伤害减免**，从 **95%** 线性衰减到 **0%**（即：刚出相位几乎打不动，但很快恢复为正常）。
- **设计意图**：避免“刚出相位被秒”导致的体验崩坏，同时通过线性衰减保留追击与预判的反制面。

### 特殊船插（内置 Hullmod）：相位谐振干扰（Phase Resonance Jamming）
*“你所依赖的相位，已在我的掌控之中。”*
- **效果**：当星云回声处于相位状态时，会干扰 1000su 内的其他相位舰船：
  - 提高其峰值时间（PPT）与 CR 消耗速度（更快烧尽）。
  - 削弱其武器精度与机动性（更难命中、更难贴脸）。
- **用途**：在“相位内”打相位战，专门克制对方的相位突击与拖时。

### 舰船系统：信标投放（Targeting Beacon）
- **效果**：在当前位置留下一枚隐形信标，随后立即进入相位状态并向鼠标方向短距离瞬移。
- **信标作用**：信标持续发出强烈的“诱导信号”，强制吸引周围敌方导弹的锁定，并降低周围敌舰的护盾效率（干扰波）。

### 数值规格（v0）
- **基础属性**：
  - 船体：2000
  - 装甲：300
  - 极速：160（极快）
  - 相位：标准相位消耗
  - 部署点：12 DP
- **槽位**：
  - 1x 中型通用（用于安装功能性压制武器），2x 小型导弹。

## 3. 终极母舰：视界线级（Event Horizon Class）

- **级别**：超主力舰（Super-Capital / Boss）
- **定位**：T5 赏金目标 / 战场控制 / 时间操纵
- **获取**：唯一（Unique）

### 文案描述
视界线级是数学对暴力的终极羞辱。它摒弃了一切物理上的投射，转而直接操纵因果的概率。它中心那台名为“事件坍缩”的透镜发生器，能将敌人的敌意转化为自身的能量，将确定的毁灭改写为从未发生。
*悖论提示：当你认为它处于下风时，你其实已经进入了它为你准备的下一种未来。*

### 内置 Hullmod：奇点置换装甲（Singularity Displacement Armor）
*“因果被阻断，事实被偏移。毁灭，无处落座。”*
- **纳米重构协议**：紫线特化（装甲修复优先）。配合置换装甲，使其装甲层极难被彻底剥离。
- **机制**：
  - 受到实弹/高爆（Projectile）类武器攻击时，有 30% 概率直接将炮弹传送至船体另一侧（Damage = 0）。
  - **[无人模式特化]**：闪避成功率提升至 50%，但护盾效率降低为 1.2（极其脆弱的护盾）。
  - **代价**：无法闪避光束（Beam）武器。光束伤害 +20%（弱点）。

### 舰船系统：时空停滞场（Stasis Field）
- **战术核心**：**把“敌人的火力”变成“自己的主炮”**。
- **效果（方案 A）**：
  1. 在鼠标指定位置生成一个半径 800su 的停滞场，持续 6s。
  2. **停滞/捕获**：场内的 **非光束类投射物**（炮弹/导弹等）速度降低约 95% 并被“捕获”。
  3. **蓄能**：被捕获的投射物会被转化为“坍缩能量”（可理解为伤害预算）。
  4. **释放（坍缩炮）**：停滞场结束（或主动关闭）时，视界线级沿“停滞场中心方向”释放一次 **引力坍缩炮**（大型光束表现），其强度随蓄能提升。
- **用法 1（防御）**：把停滞场放在自身前方/弹道汇聚处，吞掉导弹雨与炮弹潮，随后用坍缩炮反打。
- **用法 2（进攻）**：诱导敌方火力集中到停滞场（例如正面硬吃/拉仇恨），用“越打越痛”的坍缩炮结算。
- **反制面（设计预期）**：
  - 光束（Beam）不进停滞体系，依旧能稳定压制；
  - 若敌方不交投射物（或投射物被分散），则坍缩炮强度偏弱；
  - 释放窗口明确，可被预判躲避或用相位/位移规避。

> **实现状态（MVP）**：当前版本优先做“可见、可测”的最小实现（停滞场边界 + 捕获投射物 + 释放坍缩炮 BoxUtil 光束特效），用于验证观感与系统联动节奏。

### 数值规格（v0）
- **基础属性**：
  - 船体：15000（较低）
  - 装甲：800（轻）
  - 极速：55
  - 幅能散耗：1200
  - 幅能容量：18000
  - 部署点：70 DP
- **槽位**：
  - 核心：2x 侧向大型通用，2x 大型能量前侧挂载点，2x 中通用侧向炮位，2x 中能量背部炮位。

### 特殊船插（内置 Hullmod）：透镜-视界协同压制网（Lens-Horizon Suppression Mesh）
*“你们的电子战不是被压制——是被归零。”*
- **触发条件**：视界线级与引力透镜级 **同时在场**。
- **敌方难度系数影响**：所有浮动值均受敌方难度/威胁系数影响（建议同样采用 $m\in[1.0,2.0]$）。
- **ECM 归零压制（对敌舰队）**：
  - 每艘敌舰的 ECM 百分比贡献降低 **1.5%–3%**，最低为 0。
  - 同时对每艘敌舰的 ECM 贡献设置上限：**3%–6%**（按难度浮动）。
- **联动压制（基于友方 ECM 等级）**：根据友方 ECM 等级，对敌舰追加额外压制（**15%–30%**，按难度浮动），优先作用于：
  - 护盾效率（变差）
  - 武器射程（下降）
  - 造成伤害（下降）

## 4. 设计总结
紫线独特舰强调 **操作复杂度**。它们自身缺乏直接的一击必杀能力，但能把战场变成敌人的噩梦。玩家需要学会利用干扰、诱饵和信息差来肢解比自己强大的多的舰队。
