# 紫线（LENS）：原型与独特舰

> **设计哲学**：视点即真相。阿斯忒里亚的“透镜”计划是一场关于认知的博弈。如果现实可以被重构，那么战争只不过是改变观测者参数的过程。

## 1. 旗舰：决明级（ZW-001）

- **级别**：巡洋舰（Cruiser）[半航母半巡洋平台]
- **定位**：锚点控场型指挥舰 / 电子战核心 / 4 甲板母舰 / 机制型 Boss
- **获取**：唯一（Unique），赏金关键目标

### 机制描述
决明级不是传统意义上的武库，而是一座漂浮在深空中的逻辑陷阱：其巨大的非对称阵列面向战场广播虚假感知，向周围所有传感器灌输虚假的威胁评估与目标信息。

### 战斗节奏定位
**指挥舰**：使用电子战和战机优势控制战场。

### 舰船系统：引力投射器
“决明”超载奇点核心，向指定区域投放一片临时性的圆形引力场。
投射范围 1500su，引力场基础半径 500su，投射范围和场半径可被军官/AI 核心的技能所增强。
处于引力场内的所有单位（射弹/导弹/舰船）都会被吸向引力场中心，质量越低的目标吸力更强。
其中射弹和导弹影响最大，舰船其次，如果舰船本身推力较强则仍然可以脱离范围。
友军不会受到此影响。

### 内置 Hullmod：双模式切换器
### 内置 Hullmod：透镜核心
- **敌方难度倍率缩放（仅敌对单位）**：数值受敌人难度 / 威胁倍率影响，按系数 $m\in[1.0,2.0]$ 缩放。
- **无人模式**：
  - **蜂群思维**：提升本舰所有舰载机非导弹武器射程 20%，提升导弹飞行速度和机动性 20%，提升最大航速 20%。
  - **幽灵信号**：周围 ~2000su 内的导弹有 25% 概率失去制导（进范围 500su 后随机触发，而不是进范围马上触发）。
- **载人模式**：
  - **情报中枢**：全舰队 ECM 等级提升。
    - 每个友方舰船根据等级，额外提供 2% / 1.5% / 1% / 0.5（越小贡献越大）ECM 等级。
- 需要常驻状态显示（位于左侧的状态栏）。

### 内置 Hullmod：相位引力甲板
- **相位部署**：机群出库 2s 后，获得 2s 的相位状态和 200% 时流加成。
- **回收重构**：舰船战机指令为整备，且位于舰船 1000su 周围时，获得 50% 伤害减免。
- 需要美术表现：部署后的相位状态为战机施加紫色 jitter 特效和紫色 afterimage(0.25s 一帧)。

## 2. 幕僚：密蒙级（ZW-002）

> **状态：全重做已定（D27）**——定位/数值/机制全部重做，本节原案内容不追认、仅作考古留存。
> 重做前提：相位巡洋舰·**独特档**；主要依靠**进攻性舰船系统 + 大量机制**取胜；舰船系统以原版**量子干扰**为基线做增强处理并挂难度系数（轨一三锚点）；保留飞行甲板（1 甲板）但非主要战术目的。

- **级别**：巡洋舰（Cruiser）
- **定位**：虚无代理人 / 视觉剥夺
- **获取**：唯一（Unique）

### 文案描述（原案）
密蒙级游离在战线边缘，如同乌云般笼罩着战场。它搭载的多组相干干扰发射器并不造成物理损伤，它们剥夺的是目标的“认知权力”。在它的阴影下，即使是威力巨大的主炮，也只能对着空无一物的虚空徒劳开火。

### 内置 Hullmod：暗潮干扰器（Dark Tide Jammer）（原案）
*“我允许你怀疑，但我禁止你确信。”*
- **效果**：被该舰攻击的敌人（即使被护盾阻挡），武器射程暂时降低 100su（不可叠加，持续 3s）。

### 舰船系统：电磁烟幕（EM Smoke）（原案）
- **效果**：向前方喷吐一团阻断视线和锁定的带电烟雾。
- **作用**：穿越烟雾的导弹会失去目标；而在烟雾内的船只无法被锁定。

### 数值规格（v0，原案）
- **基础属性**：
  - 船体：7000
  - 装甲：700
  - 最大航速：70
  - 幅能散耗：600
  - 幅能容量：9000
  - 部署点：22 DP
- **槽位**：
  - 1x 飞行甲板（支援用），2x 中型能量（光束），2x 中型导弹。

## 3. 设计总结
紫线独特舰强调 **操作复杂度**。它们自身缺乏直接的一击必杀能力，但能把战场变成敌人的噩梦。玩家需要学会利用干扰、诱饵和信息差来肢解比自己强大的多的舰队。
