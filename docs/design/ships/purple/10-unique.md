# 紫线（LENS）：原型与独特舰

> **设计哲学**：视点即真相。阿斯忒里亚的“透镜”计划是一场关于认知的博弈。如果现实可以被重构，那么战争只不过是改变观测者参数的过程。

## 1. 旗舰：引力透镜级（Gravitational Lens Class）

- **级别**：巡洋舰（Cruiser）[半航母半巡洋平台]
- **定位**：锚点控场型指挥舰 / 电子战核心 / 4 甲板母舰 / 机制型 Boss
- **获取**：唯一（Unique），赏金关键目标

### 机制描述
引力透镜级不是传统意义上的武库，而是一座漂浮在深空中的逻辑陷阱：其巨大的非对称阵列面向战场广播虚假感知，向周围所有传感器灌输虚假的威胁评估与目标信息。

### 战斗节奏定位
**指挥舰**：使用电子战和战机优势控制战场。

### 舰船系统：引力投射器
“引力透镜”超载奇点核心，向指定区域投放一片临时性的圆形引力场。
投射范围 1500su，引力场基础半径 500su，投射范围和场半径可被军官/AI 核心的技能所增强。
处于引力场内的所有单位（射弹/导弹/舰船）都会被吸向引力场中心，质量越低的目标吸力更强。
其中射弹和导弹影响最大，舰船其次，如果舰船本身推力较强则仍然可以脱离范围。
友军不会受到此影响。

### 内置 Hullmod：透镜核心
- **敌方难度倍率缩放（仅敌对单位）**：数值受敌人难度 / 威胁倍率影响，按系数 $m\in[1.0,2.0]$ 缩放。
- **无人模式**：
  - **蜂群思维**：提升本舰所有舰载机非导弹武器射程 20%，提升导弹飞行速度和机动性 20%，提升最大航速 20%。
  - **幽灵信号**：周围 ~2000su 内的导弹有 25% 概率失去制导（进范围 500su 后随机触发，而不是进范围马上触发）。
- **载人模式**：
  - **情报中枢**：全舰队 ECM 等级提升。
    - 每个友方舰船根据等级，额外提供 2% / 1.5% / 1% / 0.5（越小贡献越大）ECM 等级。
- 需要常驻状态显示（位于左侧的状态栏）。

### 内置 Hullmod：相位引力甲板
- **相位部署**：机群出库 2s 后，获得 2s 的相位状态和 200% 时流加成。
- **回收重构**：舰船战机指令为整备，且位于舰船 1000su 周围时，获得 50% 伤害减免。
- 需要美术表现：部署后的相位状态为战机施加紫色 jitter 特效和紫色 afterimage(0.25s 一帧)。

## 2. 尖兵：星云回声级（Nebula Echo Class）

- **级别**：驱逐舰（Destroyer）
- **定位**：侦察 / 标记 / 生存
- **获取**：唯一（Unique）

### 机制描述
星云回声级是雷达上的幽灵、通讯链路中的噪音。它体现了透镜计划的作战取向：不以击毁为目的，而是持续破坏目标对战场信息的信任——让敌人在自我怀疑中丧失判断与协同。

### 内置 Hullmod：回声发生器（Echo Emitter）
- **纳米重构协议**：紫线特化（装甲修复优先）。
- **动态信号**（核心：以传感器信号塑形自身威胁度）：
  - 高速时：传感器信号（Sensor Profile）显著放大（模拟更大吨位单位），更容易吸引火力与锁定。
  - 低速/漂移时：传感器信号急剧降低（进入近似“空白回波”状态），更容易断锁与脱离接触。
- **相位潜航**：具备相位能力（Phase Field）。该舰的相位用于“位置信息战”而非纯输出：进相位后切换存在位置，出相位后重新建立接触。

### 特殊船插（内置 Hullmod）：回声回落缓冲（Echo Reentry Buffer）
- **效果**：退出相位后的 3s 内，获得 **全伤害减免**，从 **95%** 线性衰减到 **0%**（即：刚出相位几乎打不动，但很快恢复为正常）。
- **设计意图**：避免“刚出相位被秒”导致的体验崩坏，同时通过线性衰减保留追击与预判的反制面。

### 特殊船插（内置 Hullmod）：相位谐振干扰（Phase Resonance Jamming）
- **效果**：当星云回声处于相位状态时，会干扰 1000su 内的其他相位舰船：
  - 提高其峰值时间（PPT）与 CR 消耗速度（更快烧尽）。
  - 削弱其武器精度与机动性（更难命中、更难贴脸）。
- **用途**：在“相位内”打相位战，专门克制对方的相位突击与拖时。

### 舰船系统：信标投放（Targeting Beacon）
- **效果**：在当前位置留下一枚隐形信标，随后立即进入相位状态并向鼠标方向短距离瞬移。
- **信标作用**：信标持续发出强烈的“诱导信号”，强制吸引周围敌方导弹的锁定，并降低周围敌舰的护盾效率（干扰波）。

### 数值规格（v0）
- **基础属性**：
  - 船体：2000
  - 装甲：300
  - 最大航速：160（极快）
  - 相位：标准相位消耗
  - 部署点：12 DP
- **槽位**：
  - 1x 中型通用（用于安装功能性压制武器），2x 小型导弹。

## 3. 设计总结
紫线独特舰强调 **操作复杂度**。它们自身缺乏直接的一击必杀能力，但能把战场变成敌人的噩梦。玩家需要学会利用干扰、诱饵和信息差来肢解比自己强大的多的舰队。
