# 紫线（LENS）：战机联队

> 状态：三支联队已实装（hull/联队/战机武器/描述全链路，美术贴图暂用原版占位，需求见 `docs/design/art/15-战机美术需求.md`）。
> LENS 的载机哲学：母舰与联队是"投送平台"，把压制与终结弹药送进战场纵深——联队本身是透镜协议的延伸臂，而非独立火力线。

## 双子座 轰炸机联队

- 状态：**已定案 v1.0（2026-07-28 裁定）**——跨线武备维持（LENS 投送平台 × ARC 制式弹药）；护盾 120° 前盾；耗散 75；战机版 DEM 发射不产生辐能；文案经用户优化后裁定。
- 归属：LENS 线**量产**战机联队（蓝图制造，00-common §3）。
- 一句话：双机编组的无人轰炸机——把"双子星"DEM 的双色死光投送到 4000su 交战圈内的任何目标脸上。

### 面板（v1 定案）

| 项目 | 数值 |
|---|---|
| 联队编制 | 2 机 |
| 类型 | 无人战机（轰炸机） |
| 交战范围 | 4000 |
| OP | 22 |
| 更换时间 | 25s |
| 船体结构 | 500 |
| 装甲 | 100 |
| 辐能容量 / 耗散 | 500 / 75 |
| 护盾 | 前向 120°，效率 0.6 |
| 最大航速 | 150 |

### 武备

| 武器 | 数量 | 口径 |
|---|---|---|
| "双子星" DEM（战机） | 1 | 备弹 **2**，**无法恢复备弹**，**发射不产生辐能**；其余属性与机制与原版武器一致（备弹打空后按原版轰炸机逻辑返航母舰重新武装） |

- **齐射口径解读**：备弹 2 = **2 次齐射**，每次齐射仍为双弹（动能+EMP 一枚、高爆一枚）；全联队理论一波投送 = 2 机 × 2 齐射 × 2 弹 = 8 枚 DEM。
- **同步冲击机制沿用**：双弹同时命中窗口（≤1s）的额外能量伤害照原武器结算；难度缩放射程/伤害随原武器三锚点（玩家联队固定 v2，敌方母舰放出的联队按轨一 $k_s$）。

### 文案（描述文本，2026-07-28 用户优化后裁定）

搭载 “双子星” DEM 导弹的无人重型轰炸机，能够在友方战机的掩护下投射毁灭性的间接突破火力。但容易在密集火力面前避之不及。

### 设计要点

- **定位**：LENS 量产轰炸联队——与 ARC 的双子星 DEM 发射器/舱（舰装中/大槽）互补：舰装版吃槽位与备弹经济，联队版把同等弹药搬到航母体系上，用 OP22 + 25s 更换时间买"可再生的远程爆发"。
- **克制面**：无自卫武备、航速 150——脱离母舰掩护即点防靶子；备弹 2 不可恢复，投送窗口结束后联队进入长真空（返航 + 25s 更换）；0.6 盾效率虽硬但容量仅 500，吃不住持续火力。
- **EVP 威胁**：敌方航母放出双子座时，双机一波 8 枚 DEM（含 EMP 引擎打击）对玩家舰船引擎面威胁极大；反制面明确——点防拦截慢速 DEM、优先点掉投送途中的轰炸机本体。
- **难度缩放**：联队本体数值不缩放（与舰船口径一致）；缩放全部继承自 DEM 武器本体（同步冲击伤害三锚点）。

### 实装落点（已实装）

- 战机版武器：`astd_gemini_dem_fighter`（备弹 2、无恢复、辐能 0，弹体复用舰装版 dummy spec，机制沿用 GeminiDemSalvoOnFireEffect）。
- 联队数据：hull `astd_gemini_bomber` + 联队 `astd_gemini_bomber_wing`（wing size 2 / OP 22 / replacement 25s / 交战范围 4000）；返航重新武装走原版战机原生逻辑，零插件。
- 归属航母：LENS 线飞行甲板舰（飞蓬级 3 甲板、密蒙级 1 甲板，均在重构排期内）为本联队的天然载台。

## 电涌 战斗机联队

- 状态：**已定案 v1.0（2026-07-28 裁定）**——战机版电针射程 600 / 辐能 35 / 连发 15；护盾前向 270°；文案经用户优化后裁定。
- 归属：LENS 线**量产**战机联队（蓝图制造，00-common §3）。
- 一句话：三机编组的高机动无人战斗机——借等离子推进器抢占有利阵位，用电荷针刺把目标的护盾维持与武器系统一并烧进瘫痪。

### 面板（v1 定案）

| 项目 | 数值 |
|---|---|
| 联队编制 | 3 机 |
| 类型 | 无人战机（战斗机） |
| 交战范围 | 4000 |
| OP | 16 |
| 更换时间 | 12s |
| 船体结构 | 400 |
| 装甲 | 75 |
| 辐能容量 / 耗散 | 700 / 100 |
| 护盾 | 270°，效率 0.6 |
| 最大航速 | 200 |
| 战术系统 | 等离子推进器（原版） |

### 武备

| 武器 | 数量 | 口径 |
|---|---|---|
| 电荷针刺（战机） | 1 | 连发数量 / 射速从 20 / 20发/s 降为 **15 / 15发/s**；射程降为 **600**；辐能产出降为 **35**；其余数值与机制与原武器一致 |

- **机制沿用**：电荷淤积（命中护盾叠层抬维持辐能，200 层上限）+ 电荷泄放（命中船体概率 EMP 电弧）照原武器结算；玩家联队固定 v2（淤积 2%/层、泄放 40%/175%），敌方母舰放出的联队按轨一 $k_s$。
- **弹匣口径解读**：原武器弹匣 30 不变——15 发/轮即 **2 轮连发**，回充列沿用（30, 2.5, 15）；一轮连发 15×35 = 525 辐能，700 容量留有富余，两轮节奏自洽。
- **护盾朝向**：前向 270°（2026-07-28 裁定）。

### 文案（描述文本，2026-07-28 用户优化后裁定）

透镜协议前线最常见的无人格斗单元，搭载电荷针刺。比起击毁目标，电涌级更擅长利用机动能力骚扰敌方，待到敌方炮组成片熄灭时，真正负责终结的火力已经在路上了。

### 设计要点

- **定位**：LENS 量产战斗联队——与双子座（远程爆发投送）互补：电涌是前线缠斗/软瘫痪，为母舰与轰炸联队创造无反击窗口；3 机 12s 更换保证前线密度。
- **克制面**：结构 400、装甲 75 属轻量级，脱离 270° 盾面方向即裸奔；战机版电针射程 600 要求贴脸缠斗，点防密集区生存堪忧；单发 50 能量伤害对重型单位硬杀伤有限，瘫痪依赖叠层与概率电弧的时间积累。
- **EVP 威胁**：敌方电涌编队贴脸时，玩家舰船的护盾维持被持续抬升、武器组吃泄放电弧——反制面是机动脱离 600 射程圈或优先点掉本体（结构仅 400）。
- **难度缩放**：联队本体数值不缩放；缩放全部继承自电荷针刺武器本体（淤积/泄放三锚点）。

### 实装落点（已实装）

- 战机版武器：`astd_charge_needle_fighter`（burst 10 / 射速 10 / 射程 600 / 辐能 40、弹匣 20 / 回充 10 发每 4s，弹体复用 astd_charge_needle_shot，机制沿用 ChargeNeedleOnHitEffect）。
- 联队数据：hull `astd_surge_fighter` + 联队 `astd_surge_fighter_wing`（wing size 3 / OP 16 / replacement 12s / 交战范围 4000 / 最大航速 200）；战术系统挂原版等离子推进器（plasmajets），零自定义代码。

## 引力井 支援战斗机联队

- 状态：**已定案 v1.1（2026-09-26 裁定）**——wing role=SUPPORT、支援范围 2000（标签显示「最大支援范围」）；战术系统原版「闪现」；战机版 GCP 数据全量复用舰装版。
- 归属：LENS 线**量产**战机联队（蓝图制造，00-common §3）。
- 一句话：三机编组的重型护卫支援战斗机——借闪现抢位，引力坍缩炮的范围打击在母舰周围 2000su 织成一张净空网，来犯的战机与导弹一并坠进井底。

### 面板（v1 定案）

| 项目 | 数值 |
|---|---|
| 联队编制 | 3 机 |
| 类型 | 无人战机（支援战斗机） |
| 支援范围 | 2000 |
| OP | 15 |
| 更换时间 | 12s |
| 船体结构 | 500 |
| 装甲 | 50 |
| 辐能容量 / 耗散 | 600 / 80 |
| 护盾 | **全向** 180°，效率 0.6 |
| 最大航速 | 150 |
| 战术系统 | 闪现（原版） |

### 武备

| 武器 | 数量 | 口径 |
|---|---|---|
| 小型引力坍缩炮 PD（战机） | 1 | 数据全量复用舰装版 `astd_gcp2`（射程 600 / 辐能 300/s / 周期一致），唯一差异是不渲染武器贴图 |

- **机制沿用**：引力坍缩炮的范围坍缩打击照原武器结算（对区域内战机/导弹的净空能力即 GCP 本体机制），玩家联队固定 v2，敌方母舰放出的联队按轨一 $k_s$。
- **支援范围 2000 解读**：贴身护卫圈——wing role=SUPPORT，支援战斗机不离舰远征，仅在母舰周边迎战来犯目标，与原版护卫战斗机（希腊矛/希腊剑）行为一致（原生 wing 行为，零插件）；「闪现」用于护卫圈内快速抢位补防。

### 文案（描述文本，2026-07-28 裁定）

引力井级从不远离它所护卫的母舰。它像一颗贴身卫星般悬在舰侧，等不知好歹的战机群撞进坍缩炮的作用范围——然后那里就会多出一团短暂存在的、由残骸构成的星云。

### 设计要点

- **定位**：LENS 量产护卫截击联队——与电涌（前线缠斗）/ 双子座（远程投送）构成三段式载机体系：引力井守内圈净空，电涌抢中圈瘫痪，双子座打外圈爆发。
- **克制面**：支援范围 2000 意味着它几乎不参与进攻——把战场主动权让给对手；装甲 50 是纸糊水平，被实弹命中即重创；航速 150 追不上高机动战机，净空依赖 GCP 的范围机制与闪现抢位而非咬尾。
- **EVP 威胁**：敌方母舰带引力井时，玩家的战机/导弹饱和战术在 2000 内圈被高效清理——反制面是用舰船直射火力越过护卫圈直接压母舰，或用远程导弹在圈外消耗。
- **难度缩放**：联队本体数值不缩放；缩放全部继承自 GCP 武器本体（GCP 系列为 D8 保留案，缩放射程/伤害随其三锚点）。

### 实装落点（已实装）

- 战机版武器：`astd_gcp_fighter`（数据全量复用舰装版 astd_gcp2，仅 .wpn 为全隐资源；光束渲染与坍缩机制复用舰装版 GCP 接线，特效 spec 与 astd_gcp2 共用同一配置）。
- 联队数据：hull `astd_gravwell_interceptor` + 联队 `astd_gravwell_interceptor_wing`（wing size 3 / OP 15 / replacement 12s / role=SUPPORT、支援范围 2000 / 全向盾 180°）；战术系统挂原版闪现（displacer），零自定义代码；护卫行为走原版支援战斗机原生 AI，零插件。
