## 1. 重构背景与设计目标

在 D30 移除旧版剧情核心后，当前游戏内仅保留了 `StandardCores.kt` 中的制式 G / B / A / O 四级量产核心（共用单一固有技能 `astd_combat_intel`）。现行体系存在两处明显的设计空白：

1. **缺乏分局路线辨识度**：菀星设计总局的核心叙事是“星坠（ARC，武备与重工）+ 紫菀（LENS，传感、相位与力场）”双轨分立与“联制（LH）”协同，但制式 AI 核心目前只按“相位 vs 非相位”二分，未与双局设计流派及双模式（载人/无人）舰船深度耦合。
2. **闲置美术资产与高阶奖励空缺**：`contents/graphics/portraits/` 下已具備 4 张高品质特殊核心立绘（`astd_portrait_core_sp_blue / copper / violet / yellow.png`），亟需一套符合总局“签发、裁决、测试、审计”衙门气质的高价值特务核心体系来承接高难赏金、遗迹探索与 `SecondInCommand`（SiC）副官联动。

本提案将模组 AI 核心体系重构为 **“第一层：制式核心（双局协议自适应） + 第二层：四席特务核心（唯一具名人格）”** 的双层结构。

---

## 2. 第一层：总局制式核心（G / B / A / O）——双局协议自适应

### 2.1 世界观设定
菀星设计总局的制式自动智能核心采用“统一硬件基底 + 双局固件烧录”架构：
- **硬件基底**由紫菀理事会铸造，封装高维奇点演算阵列；
- **战术协处理层**由星坠理事会与紫菀理事会联合写入。当核心接入不同设计流派（Design Type）的座舰时，底层 `菀星战斗智能` 会自动识别座舰母线规格，激活对应的分局子协议。

### 2.2 分档定位与获取口径（沿用现行框架）

| 档位 | 物品 ID | 军官等级 | 自动分数倍率 | 获取与定位 |
|---|---|---:|---:|---|
| **制式 Gamma** | `astd_ai_core_g` | 4 | 2x | 量产列装型；外围测试群（T1~T3）常见打捞品 |
| **制式 Beta** | `astd_ai_core_b` | 6 | 3x | 中坚列装型；中高阶封存特遣群（T3~T6）主力打捞品 |
| **制式 Alpha** | `astd_ai_core_a` | 8 | 4x | 高阶统筹型；高阶赏金打捞，可兼任舰队军官与殖民地行政官 |
| **制式 Omega** | `astd_ai_core_o` | 11 | 5x | 封存孤品；仅作为四大唯一原型舰赏金（`XC-001 / XC-002 / ZW-001 / ZW-002`）的敌方主控标尺，不可打捞 |

### 2.3 固有技能 `菀星战斗智能 (astd_combat_intel)` 扩展方向
在保留现行“相位舰通用加成 / 非相位舰护盾与装甲固定减伤 / 精英能量武器射程补足与辐耗减免”的基础上，后续可追加 **【座舰流派自适应子协议】**（仅对带有 ASTD 对应流派特征的座舰生效）：

- **【星坠火力协处理】（座舰为 `菀星设计局-星坠`）**：
  - 实弹与射弹类能量武器的弹丸飞行速度额外提升 `10% / 15% / 25%`（随难度系数）；
  - 舰船从过载或强制排辐状态恢复后的 `3 秒` 内，非导弹武器射速提升 `10% / 15% / 25%`。
- **【紫菀透镜协处理】（座舰为 `菀星设计局-紫菀`）**：
  - 舰船战术系统充能与冷却速率额外加快 `5% / 10% / 20%`（随难度系数）；
  - 本舰所属战机或引力类武器造成的移动减速/EMP 压制持续时间延长 `15% / 25% / 40%`。
- **【联制双生校准】（座舰为 `菀星设计局-联制`）**：
  - 同时获得上述两项子协议 `50%` 幅度的混合加成。

## 3. 第二层：四席特务核心（Special Named Cores）

启用 4 张特殊立绘，设计 4 枚**唯一性/准孤品级特务核心（军官等级 9~10 级，介于 Alpha 与 Omega 之间）**。它们不走常规随机打捞池，而是对应总局第七分局编制内的**四个核心职能席位**，作为里程碑赏金、遗址深层解密或特定工程项目的固定终局奖励。

| 席位代号与名称 | 建议物品 ID | 绑定立绘 | 归属流派与色系 | 军官等级 | 核心职能与玩法定位 |

| **特务核心：[司衡]**<br>*(Ballistics Arbiter)* | `astd_ai_core_sp_blue` | `astd_portrait_core_sp_blue.png` | 星坠理事会（电容蓝） | 9 | **重炮裁定 / 强袭突破**：主力舰与重巡洋舰极致正面火力特化；强化大型直射武器与幅能对换。 |
| **特务核心：[司炉]**<br>*(Crucible Warden)* | `astd_ai_core_sp_copper` | `astd_portrait_core_sp_copper.png` | 星坠理事会（熔炉铜） | 9 | **高压抗线 / 工业监理**：战斗内强化装甲承压、反冲电弧与极限排辐；战役侧可作为**超级工业行政官/重工插槽核心**。 |

### 3.2 逐枚详细设定与机制草案

#### ① 特务核心：[司衡]（`astd_ai_core_sp_blue`）
- **背景档案**：原驻“锻原”星坠工程部第 01 号实弹靶场的首席弹道裁定核。它的逻辑阵列不设任何防御保守权重，曾在大崩塌前的上万次主炮齐射测试中，以毫秒级精度校准过每一门 `[坠星残响]` 与 `[贯星之矛]` 的谐振膛压。
- **专属技能草案 `[司衡·弹道极值裁定]`**：
  - 座舰的大型（Large）非导弹武器射程提升 `15%`，弹丸速度提升 `25%`，后坐力与散布降低 `50%`；
  - 当座舰硬辐能水平高于 `50%` 时，所有武器的辐能产出降低 `15%~25%`（随难度系数），鼓励高压顶盾对轰；
  - **特殊许可**：允许直接安装在处于“载人模式”的星坠系主力舰/巡洋舰上作为混合指挥官（无需强制切换为无人模式，或免除无人模式的部分部署点惩罚）。

#### ② 特务核心：[司炉]（`astd_ai_core_sp_copper`）
- **背景档案**：原驻主星系“洪炉”与“淬池”轨道冶炼阵列的总监理核心。它把整艘战舰的反应堆与装甲板视作一座移动的高温锻炉，擅长在舰体濒临融毁的边缘维持结构稳定，并将承受的动能冲击尽数奉还。
- **专属技能草案 `[司炉·热力学逆向锻压]`**：
  - **战斗效果**：座舰最大装甲值提升 `15%`，纳米重构协议/战斗内结构与装甲修复效率提升 `50%`；强制排辐期间受到的伤害降低 `35%`，且排辐结束瞬间向周围释放一道基于排散辐能量的大范围过载电弧；
  - **战役/殖民地效果（Admin / Industry）**：若指派为殖民地行政官（尤其驻守拥有 `星坠工程部遗址` 的锻原），除基础 `工业规划 + 超凡认知` 外，额外为所在殖民地提供 **舰船品质 +25%、重工业全产出 +1** 的特殊增益。

#### ③ 特务核心：[司瞑]（`astd_ai_core_sp_violet`）
- **背景档案**：原驻紫菀黑洞星系“拾光”站的视界观测核。它常年凝视黑洞事件视界的引力畸变，其思维结构已半处于实空间与 P 空间的叠加态。“瞑”取自闭目内视——当它接管舰桥时，敌方传感器看到的只是一团不断坍缩的虚假星云。
- **专属技能草案 `[司瞑·视界盲区投影]`**：
  - 座舰处于相位状态或激活战术系统期间，时间流速上限额外提升 `25%`，相位硬辐能失速阈值提升至 `95%`；
  - 座舰搭载的引力类武器（`GCP-*` 系列、`湮灭涡旋`）与裂隙系统的坍缩伤害提升 `15%~30%`；
  - 座舰在场时，无条件为我方舰队提供 `+10%` 电子战优势，并使受本舰锁定的目标护盾效率降低 `10%`。

#### ④ 特务核心：[司契]（`astd_ai_core_sp_yellow`）
- **背景档案**：原驻“兰台”第七分局行政中枢的联席审计与合同核销总核。它是两局唯一共享最高签章权限的特务智能，熟悉星坠与紫菀每一份封存图纸的底层接口。
- **专属技能草案 `[司契·双局联席裁决]`**：
  - **作为舰船军官时**：座舰可随时在战斗前零损耗切换载人/无人双模式且双向保留一半正面增益；单挑（周围 1000su 内仅有一艘敌舰）时全伤害与耗散提升 `20%`（极度契合 `衔星-级` 与 `决明-级`）；
  - **作为 `SecondInCommand`（SiC）联动钥匙**：
    - 当玩家安装有 `SecondInCommand` 模组时，可在第七分局空间站或通过物品交互，将 `[司契]` 核心授权接入舰队指挥链，直接解锁并招募专属副官 **【菀星技术督导·司契】（天赋：引力相位工程院 `astd_sc_grav_phase`）**。
