# 模组总 UI：交互与特效设计

> 定稿日期：2026-09-04。需求来源：`docs/story/05-第一章-积压工单.md`「模组总 UI 入口」节。
> 定位：玩家与分局空间站交互后，对话选项进入的**模组全屏总 UI**，
> 统一承载工单终端 / 档案室 / 承包商账户三大模块。
> 视觉第一原则：**尽可能贴合原版 UI**——用原版组件语言做，总局特色只通过文案、
> 文书图形元素与动效渗出，不自造控件风格。

## 视觉基调（参照原版）

参照物：原版战役（任务）界面与生涯情报界面。

- **底色**：深蓝黑星域底（近原版面板 #0A0F14~#101820 区间），面板带细描边与斜切角；
- **主高亮色**：原版青/teal（选中态、tab 下划线、按钮主色，约 #1FB6C9 观感）；
- **辅强调色**：原版橙黄（关键数值、高亮字段，约 #FFC35A 观感）；
- **字体观感**：等宽终端感，标题白、正文浅灰白、数值橙、稀有信息青；
- **布局语法**：左列表 + 右详情的双栏结构（同原版战役界面），顶部 tab 栏（同情报界面），
  底部操作按钮条（同原版"开始战役/返回菜单"位置）。

总局差异化（克制使用）：

- 文书详情以"纸质文书"卡片呈现：米白底、铅封角标、编号骑缝——在满屏深色终端里，
  纸是唯一的发光体；
- 所有系统文案保持公文语体（见 story 文档基调守则）。

## 布局

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：菀星设计总局 · 英仙座第七分局    [工单][档案室][账户] │  tab 栏（同情报界面顶部）
├───────────────┬──────────────────────────────────────────┤
│ 左列表栏        │ 右详情栏                                  │
│ （工单/档案/流水）│ （文书卡片/档案阅读器/账户明细）            │
├───────────────┴──────────────────────────────────────────┤
│ 底部操作条：[接取/核销]              [关闭终端]              │
└──────────────────────────────────────────────────────────┘
```

### Tab 1：工单终端

- 左栏：工单列表。行元素：编号、危险等级（罗马数字徽记）、目标摘要、状态章
  （待接取/执行中/已核销）。按批次分组，组头显示批次名与结清进度（2/3）。
- 右栏：选中工单的**文书卡片**——全文书排版：签发抬头、编号骑缝、委托事项、
  条款、报酬、备注、铅封角标。
- 底部：「接取工单」/「前往核销」（按状态切换）。

### Tab 2：档案室

- 左栏：档案列表（按"层"分组，未解锁项显示为灰色存目条目："依保密条令不予展示"）。
- 右栏：阅读器——档案以旧打印件观感呈现（等宽字、轻微扫描线）。
- 无底部操作（纯阅读），保留「关闭终端」。

### Tab 3：承包商账户

- 顶部：承包商编号、等级徽记（一级/二级…）、注册日期（"本审计周期"纪年）。
- 主体：**履约流水账**——每单一行：编号、交割日期、金额、批注。
  格式仿老账本，借贷分列。
- 角落常驻一行小字："本账户由分局行政系统托管。"

## 动效与特效清单

| 动效 | 触发 | 描述 |
|---|---|---|
| 终端开机 | 打开 UI | 黑屏 → 扫描线自上而下点亮 → 总局徽记淡入 → tab 栏逐字打出。约 1.2s，可跳过 |
| 逐行打印 | 切换 tab / 打开文书 | 正文逐行打出（打字机），按键音/打印音 |
| 盖章 | 接取 / 核销成功 | 一枚红色印章（"已受理"/"已核销"）砸在文书角上，带轻微屏幕震动与墨渍扩散 |
| 回执打印 | 核销结算 | 底部吐出明细单，逐行打印，金额数字滚动到位 |
| **闪现（加分效果）** | 特定剧情节点 | 界面短暂 glitch：某一状态栏/某行文字闪现异常内容（如「目标状态：现役？」），
伴随噪点与扫描线撕裂，<0.5s 后自愈，系统不解释。**不考虑防读档** |
| 待机呼吸 | 空闲 | 极低频的扫描线明暗波动，保持"机器活着"的体感 |

## 交互细则

- 打开：分局空间站对话选项「接入分局终端」；关闭：底部「关闭终端」或 Esc（本 UI 允许退出，
  与代办对话的不可退出相反——终端是玩家的地盘）。
- tab 切换有打印音 + 逐行打印；列表选中行青色高亮，hover 行微亮。
- 所有数字字段（金额、FP、日期）用原版橙黄色。
- 闪现效果由剧情系统发事件驱动，UI 层只做呈现。

## Web 预览原型

- 单页 HTML/CSS/JS，置于 `tools/mod-ui-preview/`（与 tools/ 下既有预览工具同惯例）；
- 用模拟数据完整呈现三个 tab 与全部动效；不要求响应式，按 1920×1080 定尺寸；
- 目的是确认观感与动效节奏，不追求代码复用——实装时以原版 UI 组件重写。
