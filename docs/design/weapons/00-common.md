# 武器设计：通用规则

> 目标：为赏金扩展包提供“舰系特色武器 + 独特舰签名内置 + 稀有/Ω 掉落”，在强度跨度很大的模组环境下依然**强但可控、可读、可调**。

## 1. 设计原则（跨模组适配）

- **强但可控**：避免纯面板常驻乘法；优先用窗口、条件触发、代价与软上限。
- **可读性优先**：武器机制能用一句话解释；玩家上手成本低。
- **体系化**：武器与舰体/模式（无人/载人）互相咬合，形成“装什么、为什么装”的决策。
- **掉落与强度绑定**：越强的稀有武器越应绑定更高风险、更严格掉率、更明显代价。

线路手感差异（约定）：
- **蓝线（直接火力投射）**：直射主炮/火力墙为主（A / C），强调压制与窗口爆发。
- **紫线（间接投射与压制）**：制导、延迟、区域拒止、僚机协同为主（B），强调“逼走位/逼开盾/逼幅能”。

## 2. 命名规范（硬科幻取向）

- 目标：武器名更像“军工产品/研究所项目编号”。
- 结构建议：
  - 中文：功能/机理 + 类型 + 型号（可选小名）
  - 英文：Mechanism/Function + Type + Model (optional callsign)

### 2.1 系列名与缩写（同作用域跨稀有度共用）

- 目标：避免每把枪一个新缩写导致理解成本飙升。
- 结构：**系列缩写 + 变体编号/稀有度标记**。
  - 示例：驱动炮系列 `DRV`：`DRV-9`（量产）/ `DRV-11`（稀有）/ `DRV-Ω`（Omega）
  - 示例：干扰束系列 `JMB`：`JMB-2` / `JMB-9` / `JMB-Ω`
  - 示例：压制阵列系列 `SLT`：`SLT-4` / `SLT-3` / `SLT-Ω`

> 约定：本套设计文档仅使用当前系列代号与命名口径。

## 3. 供给层级与约束

- **签名内置武器（Signature Built-ins）**：定义独特舰玩法。默认按 OP=0/不参与装配经济；强度靠窗口/冷却/自惩罚/反制/模式门槛约束。
- **量产武器（Production）**：略高于原版同类（通常 +5%~+15%“有效战斗价值”），通过命中可靠性/封顶软控/目标偏好获得稳定价值。
- **稀有武器（Rare）**：提供“我赚到了”的直观收益，但必须带代价并保留反制面。
- **Omega（Ω）**：在某个维度极端强，但必须有明确代价与“不会越叠越强”的安全闸。

## 4. 双模式（无人/载人）联动口径

- 无人模式：偏“稳定输出/体系维持”，可对部分武器提供小幅稳定性加成（封顶），但通常需要更高门槛（无人点数/核心等级）。
- 载人模式：偏“改装自由度与后勤”，通过更多 OP 与维护优势支撑不同配置。

## 5. 火力投射范式（A / B / C）

- **A：直射主炮（Direct Lance/Driver）**
  - 特征：高速弹/光束、强命中与手感。
  - 典型代价：高幅能/高 OP、需要持续对线、对盾/甲偏科。

- **B：间接压制（Indirect Pressure / Area Denial）**
  - 特征：制导/弧线/延迟引爆/子母弹/布雷/僚机引导；逼走位与逼幅能。
  - 典型代价：可被点防/机动/ECM 克制；命中更依赖体系。

- **C：直射火力墙（Direct Barrage / Suppression Line）**
  - 特征：高射速/高抑制，为队友创造击杀窗口；强调节奏与热管理。
  - 典型代价：散布/后坐/热堆积明显；需要系统窗口或阵线保护。

## 6. 数值落地与难度缩放

### 6.1 对标法

- 每件签名武器至少选 2 个原版对标：
  - 一个对标同槽位/同射程/同手感（玩家直觉）
  - 一个对标极端上限/代价窗口（防超模）
- 价值拆分目标：
  - 蓝线直射：命中率、压制持续、爆发窗口、冷却惩罚
  - 紫线间接：可被拦截性、区域覆盖率、软控封顶、体系前置条件

### 6.2 参数旋钮（建议统一可配置）

- 通用：射程档位、投射体速度、散布/后坐、每秒幅耗、爆发倍率、超频后惩罚时长
- B：投射体 HP（点防拦截门槛）、引信延迟、AOE 半径、EMP 强度/次数（封顶）、制导转向率
- A/C：基础 ROF、窗口倍率、窗口期间幅耗增幅、窗口后冷却/机动惩罚

### 6.3 难度系数 $k$：机制随威胁缩放（建议）

- 定义：$k\in[0,1]$ 为赏金/事件难度系数（可由 Threat Tier、敌方 DP、词缀等合成）。
- 默认：**仅对敌方版本启用缩放**；玩家持有版本默认固定（可做配置开关）。

缩放优先级（推荐）：
1) 可靠性：投射体耐久、抗点防、终端段减伤、触发距离（更难反应）
2) 频率：装填/冷却（缩短，但有下限）
3) 软控质量：持续时间/层数上限（小幅提升，仍封顶）
4) 伤害：只允许小幅提升，且必须配合更强代价/更显著反制

关于“层数上限”：
- 量产/稀有软控：最多 +1 层（$k=1$）
- Omega 软控：最多 +1（极少数场景可 +2），并必须配合更长内部冷却/更强衰减

推荐取值公式（占位，可替换）：
- 线性：$x=\mathrm{lerp}(x_{min},\ x_{max},\ k)$
- 凹函数：$x=\mathrm{lerp}(x_{min},\ x_{max},\ k^{1.6})$
- 强封顶：所有软控相关参数必须 clamp 到上限
