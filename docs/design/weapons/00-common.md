# 武器设计：通用规则

> 目标：为赏金扩展包提供“舰系特色武器 + 独特舰签名内置 + 稀有/Ω 掉落”，在强度跨度很大的模组环境下依然**强但可控、可读、可调**。

## 1. 设计原则（跨模组适配）

- **强但可控**：避免纯面板常驻乘法；优先用窗口、条件触发、代价与软上限。
- **可读性优先**：武器机制能用一句话解释；玩家上手成本低。
- **体系化**：武器与舰体/模式（无人/载人）互相咬合，形成“装什么、为什么装”的决策。
- **掉落与强度绑定**：越强的武器越应绑定更高的获取门槛（风险 / 掉率 / 唯一事件）与更明显的代价。

线路手感差异（约定）：
- **蓝线（直接火力投射）**：直射主炮/火力墙为主（A / C），强调压制与窗口爆发。
- **紫线（间接投射与压制）**：制导、延迟、区域拒止、僚机协同为主（B），强调“逼走位/逼开盾/逼幅能”。

## 2. 命名规范（硬科幻取向）

- 总原则：**直接写明武器名称，不使用缩写代号前缀与编号**。
- 目标：武器名更像"军工产品/研究所项目"的正式称呼，玩家看一眼就知道它是什么。

### 2.1 三类命名模式

- **体系规格武器**：功能名 + 规格前缀，成体系的大小规格共用一个功能名。
  - 规格梯度：`小型 X PD` / `小型 X` / `X`（中规格为基准名）/ `大型 X`。
  - 示例：小型引力坍缩炮 PD / 小型引力坍缩炮 / 引力坍缩炮 / 大型引力坍缩炮。
  - 文案：直截了当的描述，适当给出科学层面上的理解文案；不同规格只在文案细节上有一些变化。
- **杂项武器**：独立命名，没有成体系的大小规格；设计自由度与体系武器无异。
  - 可以是原版武器的加强延展——吃 ASTD 难度系数加成 + 独特美术表现。示例：重型离子脉冲（原版"离子脉冲"的大能量槽位加强版）、电荷针刺（原版"针刺"系列实弹武器的能量版本）。
  - 也可以是独立机制武器。示例：辉星投射仓（追踪导弹武器）。
- **超规格武器**（类 Omega 级别）：以夸张名称起手（示例：雷暴发射器）或以超现实现象名称起手（示例：源生冰晶 / 裂隙产生器），玩家一眼就能认出该武器的强度。
  - 文案不必使用常规描述：可以是某项文录、某项研究记录/档案，又或者是玩家舰队对其的评价。总体而言更多的是变幻莫测。

## 3. 供给层级与约束

- **签名内置武器（Signature Built-ins）**：定义独特舰玩法。默认按 OP=0/不参与装配经济；强度靠窗口/冷却/自惩罚/反制/模式门槛约束。
- **可获取武器不做显式稀有度分档**：稀缺性通过**获取来源**隐性告知玩家——
  - **蓝图制造**：常规强度，可以量产；
  - **赏金掉落**：更强或更特殊，获取看运气；
  - **特定赏金 / 主线限定**：超规格武器（类 Omega），绑定唯一获取事件。
- 强度锚点（设计自律，非玩家可见分档）：
  - 蓝图级：略高于原版同类（通常 +5%~+15%"有效战斗价值"），通过命中可靠性/封顶软控/目标偏好获得稳定价值。
  - 掉落级：提供"我赚到了"的直观收益，但必须带代价并保留反制面。
  - 超规格：在某个维度极端强，但必须有明确代价与"不会越叠越强"的安全闸，且只走特定赏金/主线获取。

## 4. 双模式（无人/载人）联动口径

- 无人模式：偏“稳定输出/体系维持”，可对部分武器提供小幅稳定性加成（封顶），但通常需要更高门槛（无人点数/核心等级）。
- 载人模式：偏“改装自由度与后勤”，通过更多 OP 与维护优势支撑不同配置。

## 5. 火力投射范式（A / B / C）

- **A：直射主炮（Direct Lance/Driver）**
  - 特征：高速弹/光束、强命中与手感。
  - 典型代价：高幅能/高 OP、需要持续对线、对盾/甲偏科。

- **B：间接压制（Indirect Pressure / Area Denial）**
  - 特征：制导/弧线/延迟引爆/子母弹/布雷/僚机引导；逼走位与逼幅能。
  - 典型代价：可被点防/机动/ECM 克制；命中更依赖体系。

- **C：直射火力墙（Direct Barrage / Suppression Line）**
  - 特征：高射速/高抑制，为队友创造击杀窗口；强调节奏与热管理。
  - 典型代价：散布/后坐/热堆积明显；需要系统窗口或阵线保护。

## 6. 数值落地与难度缩放

### 6.1 对标法

- 每件签名武器至少选 2 个原版对标：
  - 一个对标同槽位/同射程/同手感（玩家直觉）
  - 一个对标极端上限/代价窗口（防超模）
- 价值拆分目标：
  - 蓝线直射：命中率、压制持续、爆发窗口、冷却惩罚
  - 紫线间接：可被拦截性、区域覆盖率、软控封顶、体系前置条件

### 6.2 参数旋钮（建议统一可配置）

- 通用：射程档位、投射体速度、散布/后坐、每秒幅耗、爆发倍率、超频后惩罚时长
- B：投射体 HP（点防拦截门槛）、引信延迟、AOE 半径、EMP 强度/次数（封顶）、制导转向率
- A/C：基础 ROF、窗口倍率、窗口期间幅耗增幅、窗口后冷却/机动惩罚
