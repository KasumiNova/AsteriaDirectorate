# 武器设计总纲（P2）

> 状态：**已定案 v1.1（2026-07-28 定稿 v1.0；同日修订排产：AOD-7 载体重设计移入 P3 船设阶段）**。本文件是武器线重设计的总纲：两条线路武器哲学、美术识别原则、难度缩放落点、与引力坍缩炮系列的档位关系、设计方向 roster。
> 工作原则：**P2 周期预计较长，各项武备的原型与机制设计逐项确认后再实装**，确保后期不返工或少返工。
> 落地顺序：本总纲 → 两线量产武器逐批设计 → PSI-Ω 载体重设计。
> 通用规则（命名 / 供给层级 / 投射范式）沿用 `00-common.md`；本文件与旧文冲突处以本文件为准。

## 1. 两条线路武器哲学

### 1.1 ARC 线：直接火力投射（A / C 范式）

- **核心手感**：实弹武器与射弹类能量武器，直接火力投射打击目标，短期爆发力强。
- **数值性格**：辐伤比低（越低越有性价比，辐能交换中占优势）；面板数值朴实无华地高——"底大一级压死人"。纯粹的数值设计使其在任意难度系数下都不可小觑，但机制直白，容易被针对性战术破解。
- **机制复杂度**：简单暴力。机制一句话能讲清，玩家上手通常不会有理解障碍；**美术表现不做减法**——机制简单不等于观感朴素。
- **舰船装配倾向**：夸张的直接火力投射武备 + 进攻类舰船系统；个别舰船可具有极为出众的抗线能力（防御力/韧性）。
- **编队哲学**：推崇单舰精英 / 主 C 位。

### 1.2 LENS 线：间接火力投射（B 范式）

- **核心手感**：战机/无人战机、光束武器、导弹武器，以及独特的**引力武器**（GCP-* 系列及其延展）。
- **引力武器三要律**（LENS 主线设计方向）：
  1. 对船体有极度出众的出伤能力，能在敌方弱势窗口期快速冲破敌方战线；
  2. 通常都带 AOE 效果；
  3. 对护盾效果很差，需要配合其他武器先"开壳"。
- **数值性格**：单件数值通常不出众，机制较为复杂；在多类机制的配合下做到 1+1>2。倾向于打配合、靠战术与阴招取胜。
- **EVP 性格**：是玩家赏金体验中 EVP 元素较强的设计，在高难度系数（如"破晓"）下尤其明显——敌方 LENS 舰队的配合链会随难度变得更完整。
- **舰船装配倾向**：导弹槽位与能量槽位较多，航母/战航居多，带部分相位类舰船；舰船系统倾向于控制战线、压制敌人，而非强化自己。
- **编队哲学**：推崇集群作战。玩家需要对舰船组合有一定理解；**开发者需要对舰船 AI 做适配设计**，避免 AI 开不出组合效果造成体验问题。

### 1.3 美术识别原则（配色口径）

- 两线武器的区分首先从**配色**读出：玩家看到设计主色就能分辨武器属于哪条线。
- **ARC 线**：蓝色 / 白色灯点缀为特征色——配合"简单暴力"的机制性格，观感直白、冷冽、高亮。
- **LENS 线**：紫色 / 红色灯点缀为特征色——配合"配合与阴招"的机制性格，观感更深邃、更具压迫感。
- 机制简单不等于观感朴素：ARC 武器的美术表现不做减法；超规格武器的文案与美术均可跳出常规（00-common §2.1）。

## 2. 难度缩放落点（衔接 D13 / 80-数值缩放体系设计）

### 2.1 武器：主要承载点，但描述必须短

- 武器机制数值是难度缩放的主要承载点位之一；技术口径为**轨一 $k_s$ 三锚点（v1/v2/v5），仅敌方版本生效，玩家持有版本固定 v2**（取代 00-common §6.3 的旧 $k\in[0,1]$ 动态系数口径）。
- 受限于原版武器描述（tip 写死在 CSV，无变量替换），**武器 tip 保持简短，不写具体数值**，缩放存在性用一句话交代。句式范式：
  - "射弹至少能够弹射 3 个目标，额外弹射数量受到难度系数影响。"
  - "多次击中目标会不断叠加辐能抑制效果，效果受到难度系数影响。"
  - "使用引力坍缩打击目标，造成较高的高爆伤害并穿透部分护甲，效果受到难度系数影响。"
- 舰船系统描述同理。

### 2.2 船插：可展示细节的承载点

- 船插 Tooltip API 开放，**可以逐档展示具体数值**（以当前生效档呈现）。示例：
  - 迟暮：提升本舰战机 10% 最大航速、10% 伤害抗性、10% 非导弹武器射程。
  - 远征：提升 30% 最大航速、30% 伤害抗性、30% 非导弹武器射程、10% 非导弹武器射速。
  - 破晓：提升 50% 最大航速、50% 伤害抗性、50% 非导弹武器射程、25% 导弹最大航速、30% 非导弹武器射速；战机从甲板整备出舰后获得 2 秒 200% 时流加成。
- 上例同时展示了**逐项映射**的用法：高档位解锁新的加成项（射速、导弹航速、时流），而非全线性放大同一组数值。

### 2.3 EVP 视角的缩放意图

- ARC 敌人：缩放主要放大"朴实数值"（伤害/耐久/射速的克制提升），机制层不变——保证任何难度下 ARC 都是硬目标，但破解方式不变。
- LENS 敌人：缩放主要放大"配合链完整度"（开壳效率、AOE 覆盖、软控层数、战机联队质量），单件数值提升克制——高难度下 LENS 舰队打得更"像一个体系"。

## 3. 与 GCP-* 的档位关系

- **引力坍缩炮系列是 LENS 引力武器的基线**（设计案冻结，D8）：四个规格完成"坍缩脉冲 + 引力撕裂"的核心循环——持续命中施压、低装甲点破线。命名按体系规格法（00-common §2.1）落地：**小型引力坍缩炮 PD / 小型引力坍缩炮 / 引力坍缩炮 / 大型引力坍缩炮**（游戏内 id `astd_gcp2/4/8/12` 不变）。
- 后续引力武器设计以该系列为锚向上延伸：
  - **掉落级**：在核心循环上叠加一个新维度（如位移牵引、护盾联动开壳、弹药化瞬发坍缩），保留"对盾弱"的反制面；
  - **超规格**：某一维度极端化（如大范围引力井、对主力舰特化撕裂），必须有安全闸（不会越叠越强），命名与文案走超规格模式（00-common §2.1）。
- 该系列的数值档（射程/DPS/幅耗/OP 四档阶梯）是后续 LENS 能量武器的对标基准，新武器不重复其已覆盖的"持续光束压制"定位。
- ARC 线不设引力武器；ARC 武器与该系列无档位对应关系，其数值锚为原版同级实弹/能量武器上浮一档（见 00-common §3 蓝图级 +5%~+15%）。

## 4. 设计方向 roster（v0，按舰船池需求排产）

> 原则：命名走 00-common §2.1 三类模式（体系规格 / 杂项 / 超规格），正式名称随各自设计案确定；稀缺性靠获取来源隐性表达（00-common §3），不设显式稀有度。先补舰船槽位真空，再做锦上添花。保持开放——本表是需求方向而非立项清单，避免为了设计而设计。
> 舰船池现状：ARC 六舰（弧光耀斑/等离子拱冻结，电弧闪/断熵弧刃/弧光喷流/辐射带待收尾），槽位以 HYBRID/ENERGY 直射为主；LENS 七舰，引力透镜带双机库 + 导弹/能量槽，其余舰槽位在 P3/P4 重构时定案。

### 4.1 ARC 线（实弹 / 射弹能量，低辐伤比，简单暴力）

| 方向 | 定位 | 命名模式 | 需求来源 |
|---|---|---|---|
| 中/大槽动能直射主炮 | 高单发低射速，正面破甲 | 体系规格 | 弧光喷流 2L+4M HYBRID |
| 小/中槽实弹速射 | 火力墙压制逼幅能，含 PD 变体 | 体系规格 | 辐射带 2S HYBRID、各舰小槽 |
| 射弹类能量武器 | AOE 轻度溅射，能量槽填充 | 体系规格或杂项 | 弧光喷流/辐射带 ENERGY 槽、电弧闪 2S ENERGY |
| 原版实弹的能量化延展 | 吃 ASTD 难度加成 + 独特美术 | 杂项（示例方向：电荷针刺） | 全 ARC 舰船池 |

### 4.2 LENS 线（引力主线 + 光束/导弹/战机配合件）

| 方向 | 定位 | 命名模式 | 需求来源 |
|---|---|---|---|
| 引力武器向上延展 | 核心循环叠加新维度 / 单维极端化 | 掉落级走体系或杂项；超规格走超规格命名 | T4/T5 赏金掉落池 |
| 对盾特化光束 | 为引力武器开壳的配合件 | 体系规格 | 引力透镜 2M SYNERGY + 2M ENERGY、各舰能量槽 |
| 引力弹头导弹 | 导弹化坍缩载荷，AOE 破线 | 杂项（示例方向：辉星投射仓） | 引力透镜 1L MISSILE、LENS 舰导弹槽 |
| 无人战机联队 | 航母/战航用联队，配合压制链 | 杂项 | 引力透镜双机库、后续航母舰 |
