### 数据生成链路

新增一件武器需要动的文件：

1. **`ss-csv/src/main/kotlin/cn/kasuminova/astd/sscsv/entries/catalog/weapondata/arc/Catalog_WeaponData_ARC.kt`（ARC 线）或 `lens/Catalog_WeaponData_LENS.kt`（LENS 线）**
   - 新增 `WeaponDataEntry` 的 Kotlin `object`。
   - 投射体武器实现 `SsProjProjectileOutputs`；导弹武器实现 `SsProjMissileOutputs`。
2. **`ss-csv/src/main/kotlin/cn/kasuminova/astd/sscsv/entries/catalog/strings/Catalog_Descriptions.kt`**
   - 新增 `LocalizedDescription` 对象（`WEAPON` 类型）。
3. **`ss-csv/src/main/resources/i18n/zh-cn.properties`**
   - `weapon.<id>.name`
   - `weapon.<id>.tooltip.customPrimary`、`weapon.<id>.tooltip.customPrimaryHL`
   - `weapon.<id>.primaryRoleStr`
   - `desc.<id>.text1~text5`、`desc.<id>.notes`
4. **`contents/data/weapons/<id>.wpn`**（手写 JSON，不生成）
   - 挂载 `everyFrameEffect`、`beamEffect`、`projectileSpecId` 等插件入口。
5. **`contents/data/campaign/special_items.csv`**（仅量产件与单件蓝图）
   - 量产武器新增 `weapon_bp` / `single_bp` 蓝图条目。
   - 超规格/稀有掉落 P6 前用 `no_drop` 测试，P6 后接入赏金/掉落事件。
6. **`src/main/kotlin/cn/kasuminova/astd/combat/effect/arc/`（ARC）或 `lens/`（LENS）**
   - 实现机制代码。
7. **`src/main/kotlin/cn/kasuminova/astd/renderer/...`**
   - 弹体：在 `ProjectileVfxSpecs.kt` 登记构建函数，并在 `contents/data/config/smd_projectile_vfx.json` 加映射。
   - 光束：在 `BeamVfxSpecs.kt` 登记构建函数。
8. 编译后执行 `./gradlew :ss-csv:generateSsCsv` → 输出到 `build/generated/ss-csv/`；`copyContents` 叠加到 `contents`，最终 `deployMod` 到 `mods/ASTD`。

### 难度缩放统一口径

- 所有浮动机制数值使用 `ScalingEntry(v1, v2, v5, ScalingMap.LINEAR)`。
- 非玩家来源生效：调用 `DifficultyTuning.value(entry)`（由 LunaLib 设置决定 `k_s`）。敌方与友军 AI 版本均按此口径（`01-武器设计总纲.md` v1.3）。
- 玩家固定 v2：来源 `owner == 0` 时，强制取 `entry.v2`。
- 文案中写死数值的展示面以 v2 为准（详见 `01-武器设计总纲.md` v1.3 §2.1）。

### 1.2 代码面

| 类名 | 职责 | 挂载点 |
|---|---|---|
| `ChargeNeedleOnHitEffect` | 命中回调：护盾命中叠加淤积层；船体/装甲命中按概率触发 EMP 电弧。 | `.proj` 的 `onHitEffect` |

说明：

- `shieldUpkeepMult.modifyMult(modifierId, 1 + stacks * perStack)` 每帧幂等刷新。
- 上限安全闸：追加总量不超过目标当前耗散终值的 50%。读取 `ship.mutableStats.fluxDissipation.modifiedValue` 计算允许层数并 clamp。

### 3.1 数据面

| 字段 | 数值 |
|---|---|
| `id` | `astd_electric_drive_accelerator` |
| `size` / `type` | `MEDIUM` / `BALLISTIC` |
| `range` | 800 |
| `damage/shot` | 80 动能 |
| `energy/shot` | 88 |
| `burst size` / `burst delay` | 4 / 0.15s |
| `projectileCount`（散射） | 2 |
| `chargedown` | 1s |
| `ammo` / `ammo/sec` / `reload size` | 30 / 2 / 8 |
| `OPs` | 15 |
| `tags` | `astd_production` |

`.wpn` / `.proj` 生成要点：

- 主武器 `.wpn` 挂载 `everyFrameEffect = cn.kasuminova.astd.combat.effect.arc.ElectricDriveAcceleratorWeaponEffect`。
- `.proj`：`spawnType = BALLISTIC`，`onFireEffect = ProjectileSpecOnFireDispatcher`，`onHitEffect = cn.kasuminova.astd.combat.effect.arc.ElectricDriveAcceleratorOnHitEffect`。
- 弹体视觉隐藏，由 `ProjectileVfxSpecs` 接管。

i18n 键：

- `weapon.astd_electric_drive_accelerator.name` 等。

### 3.2 代码面

| 类名 | 职责 | 挂载点 |
|---|---|---|
| `ElectricDriveAcceleratorOnHitEffect` | 命中回调：按三锚点随机百分比追加动能伤害。 | `.proj` 的 `onHitEffect` |
| `ElectricDriveAcceleratorWeaponEffect` | 每帧读取本舰辐能水平，折算并应用净空加速射程加成。 | `.wpn` 的 `everyFrameEffect` |
| `ElectricDriveAcceleratorDifficulty` | 提供不稳定装药上限与净空加速射程三锚点。 | 被 `OnHitEffect` / `WeaponEffect` 使用 |
| `ElectricDriveAcceleratorVfx` | 白色弹体与长拖尾。 | 由 `ProjectileVfxSpecs` 调用 |

说明：

- 不稳定装药：命中时生成 `[0, maxPct]` 均匀随机值（以面板 80 为基准），追加一次 `DamageType.KINETIC` 的 `applyDamage`；随机数优先使用战斗种子，若 API 不可达则使用 `Misc.random` 并留下 TODO/INFO 标记。
- 净空加速：
  - 基础加成 = `DifficultyTuning.value(entry)`，玩家固定 v2。
  - 辐能水平 `level = ship.fluxLevel`（软 + 硬）。
  - 衰减系数：level ≤ 0.2 为 1.0；level ≥ 0.4 为 0.0；中间线性插值。
  - 最终加成 = 基础加成 × 衰减系数。
- 射程应用：当前 Starsector API 没有 `WeaponAPI.setRange`；先通过 `ship.mutableStats.ballisticWeaponRangeBonus.modifyFlat(weapon-instance-id, bonus)` 注入，但该方式会作用于全舰实弹武器。实装时优先寻找更精确的入口（如 `weapon.getCurrMaxRange()` 的可写字段或 `WeaponSpec` 的运行时覆盖）；若仍不存在，以该方式实现并记录为已知副作用。

### 3.3 难度缩放

| 机制 | v1 | v2 | v5 |
|---|---|---|---|
| 不稳定装药上限（面板百分比） | 25% | 56.25% | 150% |
| 净空加速射程加成（su） | 100 | 200 | 400 |

远征（k=3）射程加成按线性插值为 300su。

### 3.4 特效面

- 弹体：`simpleProjectileVfx` 白色；粗细为电荷针刺箭弹的 1.5×，长 trail 拖尾 500su。
- 命中：少量白色 hitParticle，不抢视觉。

### 3.5 测试

- 单元测试：
  - 不稳定装药随机值落在 `[0, maxPct]`，均值近似 `maxPct/2`；玩家固定 v2。
  - 净空加速：level=0 满额、level=0.3 半额、level=0.4 零额；敌版三档可观测。
- 烟测：`deployMod` + `launchSmokeTestGame`，检查散射连发弹数、射程随辐能变化、随机附加伤害数字。

### 3.6 依赖与风险

- 依赖：`ProjectileVfxSpecs` 已就绪；`DifficultyTuning` 已落地。
- 风险：
  - 没有可靠的每武器射程修改 API，可能需要以舰体实弹射程加成近似，带来同舰其他实弹武器射程同步变化的副作用。
  - 战斗种子来源待确认；若使用 `Misc.random`，存档重载/回放时结果可能不同。
  - `burstSize=4 × projectileCount=2` 的实际弹数、散射角度与动画需目检确认符合"每触发 8 弹"预期。
- 验证手段：先实现无随机附加、仅射程加成的最小原型跑烟测；再叠加随机伤害与 VFX。

## 10. 建议实现顺序

1. **电荷针刺 / 重型电荷针刺**：建立 OnHitEffect + 目标舰状态表 + shieldUpkeepMult 链路。
2. **重型离子脉冲**：复用 OnHit 模式，新增 EMP 贯穿补伤。
3. **电驱加速炮**：验证 everyFrameWeaponEffect 修改射程、OnHit 随机附加伤害、白色弹体 VFX。
4. **湮灭涡旋**：验证光束 everyFrame 插件与 RenderEntity 管线在 LENS 侧的承载。
5. **"七星" 折跃发射器**：建立自定义投射体瞬移/连锁/对舰终结样板；沉淀十字闪光爆炸 VFX。
6. **辉星 MRM 发射器 / 发射舱**：复用十字爆炸 VFX，验证自定义导弹 AI 与碰撞钩子。
7. **贯星之矛**：复用/沉淀锥状冲击结算与 VFX；验证 HYBRID 槽与能量结算、大光柱 VFX。
8. **双子星 DEM 发射器 / 发射舱**：复杂度最高（双弹同步窗口 + 自定义导弹 AI），最后攻坚。

**顺序说明**：贯星之矛机制为单次命中的锥状冲击，比辉星的自定义导弹 AI 简单，但比双子星简单得多；把它放在辉星之后、双子星之前，可在“导弹 AI 验证完成”后立刻沉淀锥状冲击公共组件，并为后续摧锋复用，同时让双子星作为首批压轴攻坚项不变。

## 11. 关键事实与风险汇总

### 已查证 API 可行性

- `MissileAPI.setMissileAI(...)`、`giveCommand(...)`、`CombatEngineAPI.spawnProjectile(...)` 可用于双子星/辉星自定义导弹。
- `MutableShipStatsAPI.getShieldUpkeepMult()` / `getEmpDamageTakenMult()` 支持 `modifyMult`。
- `CombatEngineAPI.getProjectiles()` / `getMissiles()` 可用于湮灭涡旋吸收遍历。
- `BeamAPI.getTo()` / `getBrightness()` / `getDamageTarget()` 与 `WeaponAPI.getBeams()` / `getChargeLevel()` 已在 `GravityCollapseBeamEveryFrameEffect` 验证。
- `engine.addPlugin(BaseEveryFrameCombatPlugin)` 可用于七星弹体连跳状态机。
- `ShipAPI.getFluxLevel()` 可用于电驱加速炮读取本舰辐能水平。

### 主要风险

1. **双子星自定义导弹 AI**：`MissileAIPlugin.advance(float)` 只给 `amount`，需自持 `MissileAPI`/`CombatEngineAPI`；先写最小原型验证 `setMissileAI` 不被覆盖。
2. **七星射弹瞬移与连跳**：射弹引用可能在连跳中失效，需每帧 `isEntityInPlay` 检查；多段终结沿舰体取点算法需验证。
3. **辉星对战机全部武器 EMP**：需确认 `WeaponAPI` 位置获取与 EMP 施加 API；若不可行，fallback 为对战机整体 EMP。
4. **隐藏武器进入 codex/掉落**：`no_drop, no_drop_salvage` 通常足够，但需在烟测中确认。
5. **湮灭涡旋性能**：300su 涡旋每帧遍历全图射弹/导弹，需空间过滤。
6. **EMP 贯穿补伤**：需防止二次 onHit 或异常伤害数字。
7. **电驱加速炮射程修正**：无 `WeaponAPI.setRange`，需以舰体 `ballisticWeaponRangeBonus` 近似，副作用为同舰所有实弹武器共享加成；实装时优先寻找更精确入口。
8. **电驱加速炮随机数种子**：战斗种子 API 待确认；若不可达，使用 `Misc.random` 并标记为非确定性来源。
9. **贯星之矛 HYBRID 槽结算**：需确认 `HYBRID` 类型武器在技能和船插中按能量还是实弹结算；设计意图按能量结算，若原版不符需额外处理。
10. **贯星之矛锥状冲击性能**：600su/80° 范围需预过滤，避免每帧遍历全图目标。
