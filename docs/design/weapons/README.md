## 侧线剧情武器（MIND / PSI）

为复用本目录的“线路 → 稀有度”落地框架，部分**侧线剧情**武器也会收录在蓝/紫线文档中；为了避免与主线两线武器池混淆，侧线条目必须满足：

- 条目标题前添加 `【侧线：MIND】` / `【侧线：PSI】`。
- 条目元信息中写明 `归属：侧线剧情…；不计入主线两线武器池基线`。
- 侧线系列代号前缀（仅用于侧线）：`MND`、`PSI`、`PSB`。
