## 电荷针刺 / 重型电荷针刺

- 状态：**已定案 v1.0（2026-07-28）**
- 归属：ARC 线**杂项武器**——原版「针刺」系列实弹武器的能量化延展（00-common §2.1 杂项命名）；吃 ASTD 难度系数加成 + 独特美术表现（密集淡蓝色箭弹，ARC 蓝白主色，总纲 §1.3）。
- 范式：C（直射火力墙 / 压制逼幅能）
- 获取来源（提案）：蓝图制造
- 一句话：弹匣供弹的电荷箭弹速射武器——命中护盾淤积电荷、持续抬高其维持开销；命中船体泄放电弧、打击武器与引擎。

### 面板（v1 提案）

| 项目 | 电荷针刺（小型能量） | 重型电荷针刺（中型能量） |
|---|---|---|
| 射程 | 700 | 700 |
| 伤害 | 50×20 能量 + 100×20 EMP | 同左 |
| 单发辐能 | 50 | 50 |
| 弹匣 | 30 | 60 |
| 回充 | 每 6s 一次性 +15 | 每 6s 一次性 +30 |
| 射速（爆发） | 20 发/s（与原版针刺系列同步：burst delay 0.05s） | 20 发/s（同左） |
| OP | 9（原版 +1） | 17（原版 +2） |

- 持续射速折合 2.5 / 5 发/s → 持续约 125 / 250 能量 DPS + 250 / 500 EMP DPS；满弹匣可连续倾泻 1.5s / 3s，随后进入约 12s 的满充周期。
- 原版对标：轻型针刺（700 射程 / 50 动能×15 / OP 8 / 辐伤比 0.8）、重型针刺（OP 15）。动能→能量的类型转换使其更加泛用，代价是辐伤比升至 1.0（EMP 不计入）。

### 机制

**电荷淤积（命中护盾）**

- 每次命中护盾为目标叠加 1 层：目标护盾维持幅能 **+x%/层**（乘算护盾维持乘区），最多 **200 层**。
- 安全闸：淤积追加的维持总量不超过目标**当前耗散终值的 50%**（动态读取，避免无上限破坏平衡）。
- 衰减：每秒减少 **10 层**（即上限层数的 5%/s），不随难度系数变化。
- 难度缩放（每层加成，层数恒定 200）：迟暮 **1%** / 砺刃 **2%** / 破晓 **5%**——对应总上限 200% / 400% / 1000%。

**电荷泄放（命中船体 / 装甲）**

- 每次命中船体或装甲有概率触发：向目标**武器与引擎**释放电弧，额外造成 **100 EMP × 倍率**。
- 难度缩放：触发概率 迟暮 **25%** / 砺刃 **40%** / 破晓 **100%**；EMP 倍率 迟暮 **100%** / 砺刃 **175%** / 破晓 **400%**。

> 缩放口径：敌方版本按轨一 $k_s$ 三锚点取值；玩家持有版本固定砺刃档（D13）。机制数值隐性缩放，不在 tip 展示（总纲 §2.1）。中槽变体机制完全复用，无差异化。

### 设计要点

- **双面对价**：能量伤害对盾中性，淤积提供反盾价值；EMP 对盾无效（原版特性），泄放电弧提供拆船价值。一件武器两头都有事做，但两头都不顶尖——符合 ARC「数值朴实、机制直白」的性格。
- **弹匣节奏**：倾泻窗口短、回充周期长，鼓励压窗口爆发而非常驻对线；这是相对原版针刺的核心手感差异。
- **克制面**：高耗散舰船几乎免疫淤积（50% 耗散封顶天然限值）；高装甲/重甲目标使 EMP 与泄放失去意义；射程 700 中距无制导，被远距离风筝与高速机动克制。

### 文案（tip 提案，静态无数值）

- 电荷针刺：以弹匣供弹的电荷箭弹速射武器，短时间内可倾泻密集火力。命中护盾会使电荷在目标护盾矩阵中淤积，持续抬高其维持开销；命中船体则可能将电荷泄放为电弧，打击武器与引擎。效果受到难度系数影响。
- 重型电荷针刺：电荷针刺的中型规格，更沉稳的供弹机构带来加倍的持续火力。命中护盾会使电荷在目标护盾矩阵中淤积，持续抬高其维持开销；命中船体则可能将电荷泄放为电弧，打击武器与引擎。效果受到难度系数影响。

### 实装落点（确认后执行）

- 弹匣：`weapon_data.csv` 原生三列直接表达（ammo / ammo/sec / reload size = 30, 2.5, 15 与 60, 5, 30），无需插件。
- 命中效果：`OnHitEffectPlugin` 挂 `.proj` 的 `onHitEffect`（参照 `HighFluxShieldPressureOnHitEffect` 模式）。
- 淤积层数：以目标舰为键的战斗内状态表 + EveryFrame 衰减；护盾维持修改走 `MutableShipStatsAPI.shieldUpkeepMult`，封顶按目标 `fluxDissipation` 终值动态折算允许追加量。
- 泄放电弧：`CombatEngineAPI.spawnEmpArc`，落点选目标武器槽 / 引擎挂载点。
- 难度取值：机制数值经 `DifficultyTuning` 三锚点（v1/v2/v5），敌方生效、玩家固定 v2。
- 美术：密集淡蓝色箭弹（ARC 蓝白主色）；小/中槽共用贴图族，中槽弹体更粗。

## 重型离子脉冲

- 状态：**已定案 v1.0（2026-07-28，含补充裁定：射速 1.5×、OP 26、v2 锚点线性默认）**
- 归属：ARC 线**杂项武器**——原版「离子脉冲」的大型能量槽位加强版（00-common §2.1 杂项命名示例方向）；吃 ASTD 难度系数加成 + 独特美术表现（标准弹头附加 EMP 电弧特效，ARC 蓝白主色）。
- 范式：C（直射压制 / 爆发瘫痪）
- 获取来源（提案）：蓝图制造（量产）
- 一句话：离子脉冲的大型化——射程更远、单发更重、连发+1、弹匣更深，瘫痪火力全面加码。

### 面板（v1 提案）

| 项目 | 重型离子脉冲（大型能量） | 原版离子脉冲（中型，对照） |
|---|---|---|
| 射程 | 700 | 500 |
| 伤害 | 135×4 能量 + 600×4 EMP | 90×3 能量 + 600×3 EMP |
| 单发辐能 | 150 | 100 |
| 弹匣 | 40 | 20 |
| 回充 | 每 3s 一次性 +8 | 每 1.5s 一次性 +3 |
| 连发 | 4（射速为原版 1.5×：burst delay ≈0.067s；双炮管交替射击） | 3（burst delay 0.1s） |
| OP | 26（自动脉冲 20 + 强力 EMP +5 + ASTD 加成 +1，与 25 OP 的速子长矛平级） | 11 |

- 持续射速 ≈2.67 发/s → 持续约 360 能量 DPS + 1600 EMP DPS（原版中型：180 + 1200）；满弹匣可连续倾泻约 2.7s。
- 辐伤比 1.11，与原版一致；EMP 总量提升依靠弹匣与射速，单发 EMP 维持 600 不变。

### 机制

**瘫痪电弧（命中船体 / 装甲，沿用原版机制并接入缩放）**

- 每次命中船体或装甲有概率向目标**武器与引擎**释放电弧，额外造成 **600 EMP × 倍率**（单发等值）。
- 难度缩放：触发概率 迟暮 **25%** / 砺刃 **31.25%**（线性默认）/ 破晓 **50%**；EMP 倍率 迟暮 **100%** / 砺刃 **125%**（线性默认）/ 破晓 **200%**。
- 设计注：EMP 倍率刻意低于电荷针刺（破晓 400%）——离子脉冲本身瘫痪能力已足够强，过高的电弧 EMP 会直接把敌舰电成板砖，丧失交战过程。

**EMP 贯穿（隐性特效，破晓限定）**

- 破晓档下，目标对本武器 EMP 伤害的减免**最多生效 90%**，超出部分被无视（等效 `empDamageTakenMult` 下限 0.1）。
- 逐项映射式解锁：仅 v5 锚点新增该项，v1/v2 无此效果；玩家持有版本固定砺刃档（D13），永远不会获得此特效。
- 实现口径（待验证）：以补伤形式实现——命中与电弧结算时读取目标 `empDamageTakenMult`，若低于 0.1 则追加被超额减免部分的等额 EMP，不改动目标 stat。

> 缩放口径：同电荷针刺——敌方按轨一 $k_s$ 三锚点，玩家固定 v2，机制数值不在 tip 展示。

### 设计要点

- **与电荷针刺的分工**：电针是"压制 + 淤积耗盾"的小/中槽速射件；重离子是大槽爆发瘫痪重锤。两者 EMP 缩放一高一低，避免同场叠加把敌舰直接电停。
- **原版性格延续**：离子脉冲以 OP 效率与瘫痪力著称，大型化保留手感（同连发节奏、同辐伤比），加码在射程、单发与弹匣深度。
- **克制面**：能量伤害对盾中性，EMP 对盾无效——开壳前瘫痪力无处发挥；弹匣节奏惩罚无脑常驻对线；无制导，被高速机动与长射程风筝克制。

### 文案（tip 提案，静态无数值）

- 重型离子脉冲：离子脉冲炮的大型化改进型，拥有足以在交战时迅速瘫痪敌舰系统与引擎的巨量 EMP 损害，并产生严重损伤着弹点附近模块的电弧。效果受到难度系数影响。

### 实装落点（确认后执行）

- 弹匣：`weapon_data.csv` 原生三列（ammo / ammo/sec / reload size = 40, 2.67, 8）。
- 命中电弧：`OnHitEffectPlugin` 挂 `.proj`（同电荷针刺路径）。
- EMP 贯穿：补伤实现，读取目标 `MutableShipStatsAPI.empDamageTakenMult` 结算差额。
- 难度取值：机制数值经 `DifficultyTuning` 三锚点；EMP 贯穿为 v5 逐项解锁项。
- 美术：标准弹头 + 命中 EMP 电弧特效（ARC 蓝白主色）；**双炮管交替射击**（对应 1.5× 射速，区别于原版单管）。

## 双子星 DEM 发射器 / 双子星 DEM 发射舱

- 状态：**已定案 v1.0（2026-07-28）**
- 归属：ARC 线**杂项武器**——原版「龙炎 DEM 鱼雷」的强化延展（00-common §2.1 杂项命名）。命名按槽位区分后缀：**中型 = 发射器，大型 = 发射舱**（2026-07-28 裁定）。归入 ARC 线量产（蓝图制造）；导弹虽属 B 范式，但本武器定位**终结打击、爆发收益极高**，故按 ARC 系列设计（2026-07-28 裁定）。
- 一句话：一次发射两枚异色 DEM 光束导弹，动能弹头剥盾附带瘫痪电弧、高爆弹头专职拆甲；双弹同步锁定并命中同一目标时引发额外能量冲击。

- 大槽提升在**备弹经济**：持续投射节奏翻倍（20s/轮 vs 40s/轮）且储量翻倍；单轮投射量与中槽相同（同为 2 发齐射，2026-07-28 确认）。

### 机制

**双子齐射（原型机制强化）**

- 一次发射**两枚异色 DEM 导弹**（特殊光束导弹：追踪飞行 → 锁定目标 → 短暂充能 → 光束打击）：
  - **动能弹头**：1000 动能伤害 + 打击武器与引擎的 **500×4 EMP** 电弧；
  - **高爆弹头**：1500 高爆伤害。
- **同步冲击**：两枚导弹**同时锁定并击中**同一目标时，额外造成双弹面板总和（2500）**x%** 的能量伤害。x：迟暮 **25%**（625）/ 砺刃 **43.75%**（约 1094，线性默认）/ 破晓 **100%**（2500）。
- **同步窗口**：放宽至 **1s**——两弹对同一目标的命中时间差 ≤1s 即触发（2026-07-28 裁定）。

> 缩放口径：同其他件——敌方按轨一 $k_s$ 三锚点，玩家固定 v2；机制数值隐性缩放，tip 不展示数值。

### 设计要点

- **双弹头分账**：动能剥盾（200% vs 盾）、EMP 瘫痪、高爆拆甲（200% vs 甲）——一轮齐射覆盖全部防御面相，同步冲击奖励"两弹都活着到达"，符合 ARC 数值朴实、配合直白的性格。
- **克制面**：弹体结构 600、航速仅为龙炎 1.5 倍——点防御与干扰弹可拆解双弹头队形，只要击落一枚，同步冲击即告落空；备弹经济决定它是窗口武器而非常驻火力。
- **EVP 威胁**：破晓档同步冲击 100%（+2500 能量）时，一轮双弹全中理论爆发 5000+——反制面仍是点防御拆队形。

### 文案（描述文本，提案）

龙炎 DEM 鱼雷的深化改进型。两枚弹头共用同一套推进与导引舱段，却装着截然不同的战斗部——一枚以动能冲击剥开护盾并释放瘫痪电弧，一枚以高爆装药撕开装甲。只有当双弹在近乎同一瞬间命中时，两股能量才会在目标体内交汇，引发远超单装药总和的终结爆发。

*试射记录（深灰斜体）：靶舰日志显示，两枚弹头命中时间相差 0.8 秒时，终结爆发如约而至；相差 1.1 秒时，什么都没有发生。火控组据此把同步窗口正式写进了验收标准——"让双子学会握手，容许一秒的迟到。"*

### 文案（tip 提案，静态无数值）

一次发射两枚异色 DEM 导弹：动能弹头附带瘫痪电弧，高爆弹头专职拆甲；两弹同时锁定并命中同一目标时将引发额外能量冲击。效果受到难度系数影响。

### 实装落点（确认后执行）

- 弹体行为：自定义导弹 AI（追踪 → 锁定 → 充能 → 光束打击，参照龙炎 DEM 行为）；单次开火生成双弹（异色贴图/光束色）。
- 同步判定：双弹共享齐射批次号，同批次两弹对同一目标的命中时间差 **≤1s** → 追加能量伤害事件；难度倍率经 `DifficultyTuning` 三锚点。
- 备弹：`weapon_data.csv` 原生三列（中：2, 0.05, 2；大：4, 0.1, 2），开火间隔 12s。
- 美术：动能/EMP 弹头冷蓝白、高爆弹头暖橙白（ARC 主色族内的双色区分）；光束与爆炸特效对应双色。

### 机制

**不稳定装药（随机附加伤害）**

- 射弹击中目标时，额外造成**完全随机**的动能伤害，取值区间 [0, 面板 ×x%]（均匀随机解读，见待裁定）。x：迟暮 **25%** / 砺刃 **56.25%**（线性默认）/ 破晓 **150%**。

**净空加速（低辐射程加成）**

- 舰船处于低辐能状态时获得额外武器基础射程，至多：迟暮 **+100** / 砺刃 **+200** / 远征 **+300** / 破晓 **+400**（v1/v2/v5 锚点；远征值与 v2→v5 线性一致）。
- 衰退区间：辐能水平（软硬合计）超过 **20%** 开始线性减少，抵达 **40%** 时加成完全消失。

> 缩放口径：敌方与友军按轨一 $k_s$，玩家固定 v2。机制数值隐性缩放，tip 不展示数值。

### 文案（武器描述）

弹链供弹的加速实弹炮，以散射连发倾泻动能弹雨。武器使用不稳定装药，命中能够额外释放冲击。

### 玩家可见机制描述（tip 提案，静态无数值）

射弹命中目标造成额外动能伤害；舰船辐能状态处于较低状态时获得额外基础射程。效果受到难度系数影响。

### 设计要点

- **定位**：ARC 实弹线开篇 + 中槽反护盾答案——与电荷针刺（能量压制、淤积耗盾）形成"硬砸盾 / 软耗盾"的中槽双选；800 射程也是 ARC 直射件目前的射程上限，净空加速把它推到 1000+。
- **数值性格**：随机附加伤是 ARC"朴实数值"的噪声变体——期望值稳定（v2 均值约 28%）、单次不可预测，机制一句话讲清；净空加速奖励辐能纪律，是玩家侧主要收益点（v2 +200）。
- **克制面**：纯动能对装甲刮痧（50%）；中等精确度 + 散射决定它对小型高速目标命中惨淡；备弹经济惩罚常驻对线；自身辐伤比 1.1 不低，与净空加速构成"想打得远就得忍着少开炮"的内生张力。
- **EVP 威胁**：破晓档 +400 射程（合计 1200）的反护盾压制超出玩家对中槽实弹的射程直觉，随机附加 150% 上限让每一发都可能爆出高伤——但动能对盾被"落盾"直接化解，反制面清晰。

### 实装落点（确认后执行）

- 射击模式：`weapon_data.csv` burst size 4 + 每发散射 2（spec `projectileCount`/散射参数）+ burst delay 0.15s + refire 1s；备弹三列 `30, 2, 8`。
- 不稳定装药：`OnHitEffectPlugin` 追加 `applyDamage`（动能，随机量），随机数走战斗种子（避免回档重掷争议）。
- 净空加速：`EveryFrameWeaponEffectPlugin` 读取本舰辐能水平，按 [0,20%] 满额 / [20%,40%] 线性至 0 折算射程修正（`weapon.getRange()` 基础值 + 加成，经 MutableShipStats 射程乘区或直接改 weapon range——实装时按可写入口定）。
- 难度倍率经 `DifficultyTuning` 三锚点（射程锚 v1=100/v2=200/v5=400 为原案显式给定，非线性默认）。
- 美术（2026-07-28 裁定）：**白色射弹**，粗细度为电荷针刺箭弹的 **1.5×**，长 trail 拖尾（**500su**）。

## "穷距"相位轨道炮

- 状态：**已定案 v1.0（2026-07-29 裁定）**——定名"穷距"相位轨道炮；叠层每层 5%/6.25%/10%，上限 10 层；OP 27；文案经用户换稿后裁定（灰字段移除）。
- 归属：ARC 线**量产武器**（蓝图制造，00-common §3）——原型为其他模组（兽耳助手！）的「稳信测流」（**特效与描述风格参考，设定不参考**；原型的电子战双机制不采用，机制按 2026-07-29 裁定重做）。
- 一句话：高斯级射程的站桩演算主炮——相位弹头持续干扰护盾稳定性，命中后校准自身相位谐波：对同一目标越打越准、越打越快；切换目标，演算作废。

| 射程 | **1200**（固定，同高斯炮） |

| 精度 | 完美 |

| OP | 27 |

### 机制

**持续演算（同目标叠层）**

- 连续命中**同一目标**（护盾或船体均计）：每层使本武器伤害与射速提高 **+x%**。x：迟暮 **5%** / 砺刃 **6.25%**（线性默认）/ 破晓 **10%**。
- 层数上限：**10**（无难度系数影响）——满层增益：迟暮 **+50%** / 砺刃 **+62.5%** / 破晓 **+100%**。
- **切换目标**（命中了不同的舰船）：当前层数大幅削减，仅保留 **y%**（向下取整）。y：迟暮 **25%** / 砺刃 **31.25%**（线性默认）/ 破晓 **50%**。
- **衰减**：连续 **3s** 未命中任何目标后（固定窗口），层数以 **z 层/s** 逐步流失。z：迟暮 **2** / 砺刃 **1.75**（线性默认）/ 破晓 **1**。

> 缩放口径：敌方与友军按轨一 $k_s$ 三锚点，玩家固定 v2。叠层幅度与增益削减（切换保留/衰减速率）为缩放点（2026-07-29 裁定）；层数上限、衰减窗口、射程、面板不缩放。

### 玩家可见机制文本（tip 提案，静态无数值）

连续命中同一目标会逐步提高本武器的伤害与射速；切换目标会损失大部分加成，长时间未命中也会逐渐衰减。效果受到难度系数影响。

### 文案（武器描述，2026-07-29 用户换稿）

弧光科研部的长程动能主炮。使用独特的相位弹头来干扰敌方护盾稳定性，持续施加动能压力，并在击中后持续校准武器自身的相位谐波。

### 特效

- **射弹**：长轨贯穿光矛——高亮度白色细长射弹 + 长距离明亮拖尾（原型表现参考，2026-07-29 截图），走 texTrail 管线；
- **命中**：小型白闪，克制处理（伤害在持续压制而非单发爆发）。

### 设计要点

- **定位**：ARC 量产大实弹主炮——补实弹线最大缺口（中/大动能直射，弧光喷流 2L+4M HYBRID 刚需）。与贯星之矛（2s 充能单发爆发）严格错位：贯星买"一击定音"，穷距买"越打越痛"；1200 射程也是 ARC 直射件的新上限（电驱 800/贯星 1000）。
- **数值性格**：基准 300 DPS 平庸、满层 v2 约 790 DPS（600→975 伤、2s→1.23s）——收益全部藏在"咬住一个目标不放"里；辐伤比 1.5 的压制税 + 完美精度 + 非常慢转向 = 站桩预瞄炮，被近身绕侧即废。
- **克制面**：叠层依赖连续命中——相位船、高机动护卫舰、烟雾/干扰都能打断演算；切换目标的 75% 削减（v1）惩罚雨露均沾打法；非常慢转向决定它打不了贴身目标。
- **EVP 威胁**：破晓档满层 +100% 伤害与射速（1200 伤 / 1s 间隔）的 1200 射程动能压制极具压迫感；反制面是机动打断命中链、用小型高速单位骗转火触发削减、或压进内圈逼它转不过头。

### 实装落点（确认后执行）

- 叠层跟踪：`OnHitEffectPlugin` 记录（武器 → 当前目标 + 层数 + 最后命中时间）；命中同目标 +1 层（上限 10），命中异目标按保留比例折算，超时未命中按速率衰减（EveryFrame 检查）。
- 增益生效：伤害倍率经 `WeaponAPI.getDamage().getModifier()` 实时调整（已查证可用）；射速无可靠 per-weapon API（2026-07-29 实装计划 v5 风险登记），实装时以舰体实弹 RoF 加成或冷却扣减近似，目检验证手感。
- 难度倍率经 `DifficultyTuning` 三锚点；特效走 RenderEntity + texTrail 管线。
