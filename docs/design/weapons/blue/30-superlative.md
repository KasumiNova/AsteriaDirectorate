> 状态：**重构中**（P2 逐件确认中）。本文件收录 ARC 线超规格武器（00-common §2.1 超规格命名、§3 特定赏金/主线限定）与**稀有掉落**武器（赏金掉落获取）设计案；每件按"原型与机制设计 → 确认 → 实装"推进，确认前不动数据与代码。

## “七星”折跃发射器

- 状态：**已定案 v1.0（2026-07-28）**——命名用直角引号"七星"（「」会被原版字体认成无效符号）；机制微调：对舰多段终结为破晓限定。
- 归属：ARC 线**超规格武器**（00-common §2.1 超规格命名；§3 特定赏金 / 主线限定获取）。
- 原型：其他模组 Polaris Prime 的「追迹 AD」（中型通用点防御，800 射程 / 300 伤害 / 闪光十字爆炸 + 隐藏折线追踪机制）。本案将其极端化为大型能量点防御超规格件。
- 一句话：射弹不做正常飞行——发射即折跃至最近的导弹/战机脸上自爆，摧毁目标后连锁折跃下一目标，最多七星连闪；无处可去时把剩余段数倾泻到最近的敌舰上。

### 面板（v1 提案）

| 项目 | 数值 |
|---|---|
| 槽位 | 大型能量（点防御） |
| 射程 | 800 |
| 伤害 | 250 能量（单发面板） |
| 单发辐能 | 750 |
| 射速 | 2s/发 |
| OP | 28 |

### 机制

**① 折跃打击（首发）**

- 发射后射弹**立即折跃**至最近的可打击点防御目标（导弹 / 战机）位置，**不会锁定舰船**，不做正常飞行。
- 到达即产生**闪光十字爆炸**：直击目标吃面板伤害，区域内其他所有目标造成面板 **x%** 的范围伤害。
- 难度缩放（hit，爆炸面板倍率）：迟暮 **100%** / 砺刃 **125%**（线性默认）/ 破晓 **200%**。
- 若首发时附近不存在点防御目标，直接进入 ③ 对舰终结判定。

**② 七星连锁（连跳）**

- 若直击或闪光爆炸**至少摧毁一个目标**：射弹不消失，冷却 **0.33s** 后折跃至下一个可打击目标并再次闪光爆炸；若未摧毁任何目标，射弹直接消散（不触发对舰终结）。
- 折跃范围：**最终武器射程的 50%**（基准 400，吃射程修正）。
- 最大折跃次数：**7**（无难度系数影响）。
- 每折跃一次，闪光爆炸伤害提升：迟暮 **+50%** / 砺刃 **+62.5%**（线性默认）/ 破晓 **+100%**；累计提升上限：迟暮 **+100%** / 砺刃 **+175%**（线性默认）/ 破晓 **+400%**。
- 目标选择优先**本轮可摧毁**的目标（预估剩余耐久 ≤ 本轮爆炸伤害），最大化防御效率；无可摧毁判定时取最近目标。

**③ 对舰终结（落幕闪爆）**

- 触发条件：附近不存在点防御目标，或折跃次数已达 7 次。
- 射弹寻找**最近的敌方舰船**，对其造成十字辉星爆炸；若连舰船目标也不存在，射弹直接消散。
- **破晓限定（v5 逐项解锁）**：根据已发生的折跃次数造成**多段闪光十字爆炸**，爆炸点沿舰体分布（产生机制参考原版「裂隙洪流发射极」）。每段 AOE 伤害逐段递增 **+25%**：50% → 75% → … → 200%（七段拉满），每段附带 **100% EMP**（250 EMP）。
- **其余难度**：只对舰船造成**一次且仅一次**十字辉星爆炸，造成 **50%** 面板伤害（按字面解读：单段不附带 EMP——如仍保留 EMP 请指出）。
- 玩家持有版本固定砺刃档（D13），永远只有单段终结。

> 缩放口径：同量产件——敌方按轨一 $k_s$ 三锚点，玩家固定 v2。机制数值隐性缩放，tip 不展示数值。

### 文案（描述文本，提案）

定向折跃拦截系统。它将整枚射弹作为可投掷的闪光弹头使用——发射瞬间即完成空间跃迁，在目标坐标引爆一团十字形强光。每一次成功摧毁都会为弹头重新充能，让它跃向下一处火光，直至七次跃迁耗尽，或天空再无可燃之物。若半途再无小型目标可供追猎，弹头会把剩余的跃迁次数尽数倾泻到最近的敌舰上——多段十字闪光沿舰体次第绽开，直至最后一道熄灭。

*观测档案摘录（深灰斜体）：首次遭遇它的舰长坚称记录仪出了故障——弹道摄像里没有任何飞行物，只有七道十字闪光几乎同时亮起，宛如北斗横陈于战场之上。七道闪光之后，整波导弹群在同一秒内熄灭。这个名字由此流传开来。*

### 玩家可见文本（tip，原案给定）

发射时立即折跃射弹至目标位置并产生一次闪光十字爆炸，造成等额面板伤害，如果成功摧毁目标会在短暂延迟后立即折跃至下一个可打击目标。
折跃后的射弹如果无法找到点防御目标，或者折跃次数已达 7 次，则选择最近的舰船单位引发一次闪光十字爆炸。（2026-07-28 微调：多段终结为破晓敌版限定，玩家版 tip 按单段描述）

### 特效（纯代码实现）

- **闪光十字爆炸**：十字星爆炸，使用本模组渲染组件 API + BoxUtil 绘制，附带星云烟雾特效（ARC 蓝白主色）。
- **折跃**：起点与终点产生 EMP 电弧特效；路径上产生多个小星云烟雾特效与少量 flare。

### 设计要点

- **定位**：超规格点防御——单件封锁导弹/战机饱和打击，连跳机制让它在面对集群小型目标时越打越值；对舰终结保证任何情况下开火都不落空。
- **EVP 威胁**：敌方持有（尤其破晓档 200% 爆炸 + 每跳 +100%/上限 +400%）时，玩家的导弹/战机体系会被单件武器成片清除——这正是超规格应有的压迫感，且反制面明确（用舰船直接压线、分散投放、或先用廉价弹药骗掉 2s/发的射击窗口）。
- **安全闸**：连跳必须击杀才能续段、7 次硬上限、对舰终结多段为破晓敌版限定（玩家版恒为单段 50%）——不会越叠越强（00-common §3 超规格自律）。
- **命名**：「七星」保留（2026-07-28 裁定）——暗合 7 次折跃上限，意象成立；描述文本走观测档案体（00-common §2.1 超规格文案口径）。

### 实装落点（确认后执行）

- 射弹行为：自定义弹体插件（发射即折跃，不做飞行）——发射挂钩走 `ProjectileSpecOnFireDispatcher`，折跃/连跳/终结状态机挂在弹体 EveryFrame 逻辑上。
- 目标筛选：导弹/战机集合按距离与可摧毁性排序；对舰终结取最近敌方舰船。
- 多段爆炸：参考原版裂隙洪流发射极的爆炸点生成（沿舰体取点 + 延迟依次引爆）。
- 伤害结算：`CombatEngineAPI.applyDamage` 区域结算；难度倍率经 `DifficultyTuning` 三锚点。
- 特效：RenderEntity 渲染组件 API + BoxUtil 绘制十字星与星云烟雾；EMP 电弧走 `spawnEmpArc`。

## 摧锋鱼雷 / 摧锋鱼雷发射器

- 状态：**设计案 v1（2026-07-28 提案，待确认）**
- 归属：ARC 线**稀有掉落**（赏金掉落获取，00-common §3）——其他模组（布塔赫联盟）后期野怪势力"格式塔"的「齐欧鱼雷」思路强化延展：极端反舰、终结打击、高伤害适应性。命名按槽位：**小型 = 摧锋鱼雷，中型 = 摧锋鱼雷发射器**；"鱼雷"在原版设定中指对舰船构成较大威胁的武器，与是否追踪无关（本案保留优秀追踪，不冲突）。
- 范式：B（制导投射 / 终结打击）——以杂项身份入 ARC 册，性格为单发重锤 + 辐能压制。
- 一句话：自适应反舰重锤——目标辐能越高吃得越痛，命中护盾还会把对方的硬辐能一寸寸顶向过载。

- 原型对标：齐欧鱼雷（格式塔 / 射程 1700 / 1500 能量 / OP 17 / 弹体结构 300）。
- 辐伤比 0.25（500 辐能换 2000 基础伤害），符合 ARC 低辐伤比性格。
- **命中即 AOE**：打中造成的伤害本身就是范围伤害，**全额面板**（2000 能量）作用于爆炸范围内所有目标（2026-07-28 裁定）；爆炸半径待定（提案 150su，目检调整）。

### 机制

> 命中结算基准：打中造成的伤害本身即为范围伤害（AOE），**全额面板**作用于爆炸范围内所有目标；以下各项在此之上叠加。

**辐能自适应（对高辐能目标增伤）**

- 目标辐能水平 **40% 起算、90% 为满值**，按该区间线性最多额外造成面板 **x%** 的能量伤害。x：迟暮 **25%** / 砺刃 **50%**（线性默认）/ 破晓 **125%**。

**硬辐推进（命中护盾）**

- 击中护盾时强制抬升目标 **y%** 最大辐能值的**硬辐能**。y：迟暮 **2%** / 砺刃 **4%**（线性默认）/ 破晓 **10%**。
- 抬升的辐能值在战斗 UI 中**显示为紫色值**。
- 与辐能自适应构成自增益链：命中护盾抬硬辐 → 目标辐能水平上升 → 后续命中增伤更满 → 逼近过载后终结。

**锥状冲击（远征起解锁，隐性机制）**

- **远征（k≥3）解锁**：击中目标时按命中矢量产生锥状冲击，对锥角范围内所有目标额外造成面板破片伤害。
- 锚点：远征 **30° / 250su / 100%** → 破晓 **90° / 500su / 200%**（k∈[3,5] 线性；k=4 时约 60°/375su/150%）。
- 锚点表达说明：该机制的三锚点 v1/v2 为"禁用态"（玩家版固定 v2 永远没有此机制），实现层用"解锁阈值 + k∈[3,5] 插值"的自定义映射，勿硬套 ScalingEntry 的 v1→v2→v5 全段插值。

**二段式打击（玩家不可见）**

- 发射时仅有 **50%** 最大航速；航程超过最大射程 **25%** 后开始加速，至 **75%** 航程时达到最大航速。

> 缩放口径：敌方与友军按轨一 $k_s$，玩家固定 v2。锥状冲击与二段式为隐性机制，不进玩家可见文案。

### 玩家可见机制文本（2026-07-28 裁定）

根据目标辐能水平造成额外**自适应**伤害。命中护盾会强制抬升目标 **4%** 的硬辐能。

> 数值口径：4% 为 v2 基准值（写死数值文案以 v2 为准，80 文档 §2.3）；玩家版固定 v2，故对玩家恒准确。

### 文案（描述文本，提案）

对"格式塔"主力反舰鱼雷的逆向重构。它不做多余的制导表演——命中即全额范围能量冲击，并用每一次护盾撞击把目标的硬辐能顶向过载红线。目标辐能越高，这一锤落得越重。

*战场回收分析（深灰斜体）：被摧锋命中的舰船，辐能记录呈现出同一种死法：硬辐能阶梯式不可逆地爬升，舰长被迫在开盾与散幅之间反复权衡——而每一次犹豫，都让下一枚鱼雷更加致命。打捞组在残骸上找不到弹片，只有一层均匀烧结的痕迹，"像被一柄锤头整个吻过"。*

### 特效

- 命中时的**大光柱** + 爆炸烟雾（ARC 蓝白主色）；
- **锥状冲击特效**：代码库有现成 VFX 直接复用（实装时盘点确认出处）。

### 设计要点

- **定位**：ARC 稀有反舰终结件——与双子星（点防拆解窗口、中远程爆发）错位：摧锋是近距离（1600）单发重锤，主打辐能战自增益链，"高伤害适应性"体现在目标越强撑（高辐硬抗）吃得越痛。
- **克制面**：弹体结构 500、航速前段仅 50%——点防御有充足的拦截窗口（尤其二段加速前的慢速段）；备弹稀少（小 2 / 中 6 + 长装填），打空即长真空；低辐能目标（相位、纪律性落幅的舰船）使自适应增伤无从发挥。
- **EVP 威胁**：破晓档硬辐 10%/发——敌方两三艘带摧锋的舰船集火，玩家主力舰的硬辐能被快速顶满；远征起锥状冲击让抱团护航阵型吃连带破片。反制面仍是点防与辐能纪律。

### 实装落点（确认后执行）

- 弹体：优秀追踪 AI + 二段式速度曲线（自定义 MissileAIPlugin 推力调度）；爆炸 AoE 走 `applyDamage`。
- 辐能自适应：伤害结算钩子读取目标 `currFlux/maxFlux`，按 [40%,90%] 区间线性折算增伤。
- 硬辐推进：命中护盾判定 → 目标 `fluxTracker.increaseFlux(hard=true)`；紫色浮字走战斗 UI 浮文本。
- 锥状冲击：k≥3 判定 + 命中矢量锥形范围结算（自定义映射，不用 ScalingEntry 全段插值）。
- 备弹：`weapon_data.csv` 原生三列（小：2, 1/60, 1；中：6, 1/40, 1），冷却 3s/12s。
- 难度倍率经 `DifficultyTuning`；特效大光柱走 RenderEntity + bloom 管线。
