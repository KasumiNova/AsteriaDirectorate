# 紫线（B）：超规格与稀有掉落武器

> 状态：**重构中**（P2 逐件确认中）。本文件收录 LENS 线超规格武器（00-common §2.1 超规格命名、§3 特定赏金/主线限定）与**准超规格稀有掉落**（高阶支线赏金获取、强度逼近超规格）设计案；每件按"原型与机制设计 → 确认 → 实装"推进，确认前不动数据与代码。

## 湮灭涡旋

- 状态：**已定案 v1.0（2026-07-28）**
- 归属：LENS 线**准超规格**（稀有规格接近超规格），**T3~T4 支线赏金**获取。原型：原版渊暮原种（超空间生物威胁）的「深渊耀光」。
- 范式：B（区域拒止 / 弹药反制）
- 一句话：爆发光束的终点展开引力涡旋，吞噬途经的射弹与导弹；光束熄灭时涡旋坍缩，把吞下的火力一次性还给战场。

### 面板（v1 提案）

| 项目 | 数值 |
|---|---|
| 槽位 | 大型协同（爆发光束） |
| 射程 | 900 |
| 爆发伤害 | 1600 能量（2s 爆发，800 DPS） |
| 爆发辐能 | 3200（约合 291/s 全程均摊） |
| 爆发时间 / 冷却 | 2s / 9s |
| OP | 30 |

### 机制

**湮灭涡旋（引力强化，光束持续期间）**

- 光束终点展开**红色涡旋**，半径：迟暮 **150su** / 砺刃 **187.5su**（线性默认）/ 破晓 **300su**。
- 涡旋附近的射弹与导弹被**逐渐吸入**光束位置；抵达涡旋附近即被**吸收**——弹体移除、不计伤害，其面板伤害按伤害类型折算后计入"吞噬池"。
- **伤害效率转换比**（按被吸收弹体的伤害类型）：能量 **100%**（基准默认）/ 高爆 **50%** / 动能 **50%** / 破片 **25%**。

**坍缩爆炸（光束结束时）**

- 涡旋快速坍缩并引发深红色爆炸：对**涡旋半径 150%** 范围内的目标造成 **吞噬池 × x%** 的 AOE 能量伤害。
- 难度缩放（aoe_damage，x）：迟暮 **50%** / 砺刃 **100%**（线性默认）/ 破晓 **250%**；范围倍率 150% 不缩放（跟随涡旋半径本身）。

**吞噬池强度控制（2026-07-28 补充裁定）**

- **曲线增长（软上限）**：以光束爆发伤害（1600）的 100% 为基准设定吸收阈值，超过阈值的伤害**快速衰减**（超出部分按 25% 折算计入，提案值，待目检调整）。阈值：迟暮 **200%**（3200）/ 砺刃 **550%**（8800，线性默认）/ 破晓 **1000%**（16000）。
- **空爆保底**：吞噬池下限 **500**（无缩放系数）——不足 500 按 500 计入后续转化。
- **吸收阵营**：仅敌方射弹/导弹（裁定确认）。
- **幅能特性**：继承原型软幅能（裁定确认）。

**原型电弧**：不保留（2026-07-28 裁定）；后续如需增强表现再议。

> 缩放口径：敌方按轨一 $k_s$ 三锚点，玩家固定 v2。机制数值隐性缩放，tip 不展示数值。

### 文案（tip 提案，玩家可见机制描述，静态无数值）

光束终点会展开引力涡旋，将附近的敌方射弹与导弹牵引并吞噬；光束结束时涡旋坍缩爆炸，把吞噬的火力转化为范围能量伤害——吞噬得越多，爆炸越强。效果受到难度系数影响。

### 文案（误区描述文本，提案）

渊暮原种光束武器的逆向工程产物。它将光束终点作为引力锚点展开吞噬涡旋——任何途经的敌方射弹与导弹都会被没收，成为下一次爆炸的燃料。

*研究档案（深灰斜体）：关于涡旋的成因，学术界至今维持着三种互不兼容的理论：引力透镜效应的亚稳态残留、伪粒子流的自聚集临界，以及"光束只是诱饵，真正开火的是别的东西"。第三种理论的支持者在最近一次实地观测中失去了一整艘探测船和船上全部记录设备——除了最后三秒的弹道摄像：十六枚已发射的反舰导弹调转方向，排着队飞进了那团红光里。*

### 设计要点

- **定位**：区域拒止 + 弹药反制 + 转化反打。光束本体（800 DPS×2s）只是入场券，真正的价值在心理压制——涡旋覆盖区内对方不敢释放导弹/射弹武器。
- **配合链**：与 GCP 开壳链互补——光束压盾逼走位、涡旋断弹药、坍缩爆炸补 AOE 收尾；9s 冷却给对面留出反扑窗口，节奏符合 LENS"打配合"而非"站桩压制"。
- **克制面**：冷却窗口长，爆发期外毫无作为；对方不依赖射弹/导弹时吞噬价值归零；光束固定终点，被高速机动目标脱离终点位置后涡旋空转。
- **EVP 威胁**：破晓档 300su 涡旋 + 250% 转化——玩家的导弹海战术被单件武器没收并反打，符合 LENS 高难度"体系更完整"的缩放意图。

### 实装落点（确认后执行）

- 爆发光束：`weapon_data.csv` 光束参数（2s 爆发 / 9s 冷却）+ 光束武器 EveryFrame 插件驱动涡旋逻辑。
- 牵引/吸收：遍历涡旋半径内（敌方）射弹与导弹，施加指向光束终点的加速度；进入吸收阈值后移除弹体并累计其面板伤害入吞噬池。
- 坍缩爆炸：光束结束事件 → `CombatEngineAPI.applyDamage` 按半径结算；难度倍率经 `DifficultyTuning` 三锚点。
- 特效：红色涡旋与深红坍缩爆炸走 RenderEntity 渲染组件 + BoxUtil；LENS 紫/红主色。

## 辉星 MRM 发射器 / 辉星 MRM 发射舱

- 状态：**设计案 v1（2026-07-28 提案，待确认）**
- 归属：LENS 线**稀有规格**（赏金掉落获取，00-common §3）——原版「反物质 SRM」的**逆向工程产物**（原物为不可分析的上古遗产，无法下放复刻）：高效反战机 PD 导弹，但不及反物质 SRM 的超规格强度。命名按槽位后缀：**小型 = 发射器，中型 = 发射舱**（沿用双子星判例）；**MRM** 为中程分级标识，对应原版射程分级（SRM/MRM/LRM）口径（2026-07-28 裁定）。
- 范式：B（制导投射 / 区域防空）
- 一句话：优先追猎战机的高速导弹——命中机体即瘫痪其全部武器，撞击处绽放十字辉星；它从不主动拦截导弹，但撞上它的导弹没有好下场。

### 面板（v1 提案）

| 项目 | 辉星发射器（小型导弹） | 辉星发射舱（中型导弹） |
|---|---|---|
| 射程 | 2500 | 2500 |
| 直击伤害 | 100 能量 | 同左 |
| 弹体结构值 | 200 | 200 |
| 碰撞体积 | 常规导弹的 1.5× | 同左 |
| 单次发射量 | 1 | 2 |
| 最大备弹量 | 8 | 20 |
| 重装时间 / 单次装填 | 5s / +1 | 4s / +2 |
| 发射冷却 | 1s | 1s |
| 发射辐能 | 60 | 60 |
| 追踪 / 航速 | 优秀 / 反物质 SRM 的 75% | 同左 |
| OP | 4 | 10 |

- 原版对标：反物质 SRM（小型 / 射程 1200 / 1000 能量 / OP 7 / 备弹 3、20s 回 1）。辉星射程翻倍、备弹经济大幅放宽，单发面板仅其 1/10——"高频次小拳头"对"一锤定音"。

### 机制

**猎机本能（对战机特化）**

- **优先打击战机**；反舰效果一般但不至于无用。
- 对战机造成额外 **x%** 伤害：迟暮 **50%** / 砺刃 **100%**（线性默认）/ 破晓 **250%**。
- 命中战机机体时，对该战机上**所有武器**造成面板伤害 **y%** 的 EMP 伤害：迟暮 **200%** / 砺刃 **400%**（线性默认）/ 破晓 **1000%**。

**辉星爆炸（任意撞击触发）**

- 无论以何种方式撞击（战机 / 舰船 / 导弹 / 残骸），都在撞击点引发**十字辉星爆炸**（半径 **50su**，无缩放），造成面板 **z%** 的范围能量伤害：迟暮 **50%** / 砺刃 **100%**（线性默认）/ 破晓 **250%**。

**撞线者死（隐性机制）**

- 通常**不会主动追踪导弹**；但与导弹发生碰撞时，若该导弹当前结构值低于辉星自身结构值的 **h%**（200 × h%），则**必定摧毁该导弹**，自身同归于尽。h：迟暮 **150%**（阈值 300）/ 砺刃 **300%**（600，线性默认）/ 破晓 **750%**（1500）。
- 1.5× 碰撞体积在此身兼两职：既增加被敌方点防击落的风险，也提高与导弹相撞的概率。

> 缩放口径：敌方按轨一 $k_s$ 三锚点，玩家固定 v2。机制数值隐性缩放，tip 不展示数值；撞线者死为隐性机制，不进任何文案。

### 设计要点

- **定位**：LENS 防空拼图——战机是 LENS 的核心输出手段，这件武器就是发给敌方航母流的"对等答案"；EVP 视角下，破晓档敌方 LENS 舰队带着它，玩家的航母/导弹海同时被克（猎机 + 撞线者死阈值 1500 已能吞掉重型鱼雷）。
- **数值性格**：单发面板刻意平庸（100 能量），价值全在特化倍率与备弹经济上——符合稀有掉落"我赚到了但有边界"的自律。
- **克制面**：反舰刮痧（能量直击 + 小 AoE）；1.5× 碰撞体积使它比常规导弹更容易被点防击落；战机脱离 2500 射程后即无价值。

### 特效

- **弹体**：固定大小的紫色十字辉星 + 很长的 twin trail 双拖尾（LENS 紫主色；texTrail 双带栈直接承载）。
- **撞击**：十字辉星爆炸——与「七星」同族渲染（十字星 + 星云烟雾），特效尺寸为其 **60%**。

### 文案（描述文本，提案）

上古遗产「反物质 SRM」的逆向工程产物。原物的装药原理至今无法解析，工程组转而复现它的飞行性能与猎杀逻辑，以常规能量装药补上最后一块拼图——紫色辉星掠过之处，战机联队的武器系统将集体沉默。

*逆向工程记录（深灰斜体）："拆解报告第 41 版，结论与第 1 版相同：不可分析。我们甚至无法确定装药舱里是不是反物质。"工程组最终放弃了理解原物，转而复现它的飞行——三十二架无人靶机在三秒内接连熄火，像被同一根手指依次捻灭的蜡烛。评审委员会沉默了很久，然后在量产许可上签了字。*

### 文案（tip 提案，静态无数值）

优先追猎战机的高速导弹。命中战机机体时对其全部武器释放 EMP；无论撞上什么，撞击处都会绽放十字辉星。效果受到难度系数影响。

### 实装落点（确认后执行）

- 弹体：追踪 AI 优先战机（目标权重：战机 > 舰船；不主动锁定导弹）；碰撞体积 ×1.5。
- 猎机判定：命中目标为战机且命中机体 → 对其全部武器 `applyEmpDamage`；战机增伤走伤害结算钩子。
- 撞线者死：碰撞回调中判断对方为导弹且当前结构值 < 自身 ×h% → 双方移除（辉星侧照常触发辉星爆炸）。
- 备弹：`weapon_data.csv` 原生三列（小：8, 0.2, 1；中：20, 0.5, 2），冷却 1s。
- 难度倍率经 `DifficultyTuning` 三锚点；爆炸范围固定 50su 不缩放。
