## 1. 设计总览（最终选案）

| 类别 | 选案 | 支柱 / 定位 |
|---|---|---|
| 舰船系统（选 1） | **回声定影（Echo Fixation）** | 延迟结算的区域威慑 |
| 内置插件 · 基座（必带） | **① 透镜阵列核心（Lens Array Core）** | 全局指挥 / 双模式中枢 |
| 内置插件 · 选案 | **② 视差甲板（Parallax Decks）** | 4 甲板支柱 |
| 内置插件 · 选案 | **③ 渗透潮汐（Permeating Tide）** | 高级电战支柱 |

> 编号说明：`purple/10-unique.md` §1 中插件按 ①②③ 顺序列出
> （① 核心 / ② 视差甲板 / ③ 渗透潮汐），本稿沿用该编号。

### 1.1 统一咬合约束：标记闭环（Mark Loop）

本舰所有机制围绕一套**「标记 → 全队增伤」闭环**协同：

```
铺点（系统 / 机群） → 沉淀（插件标记） → 收割（核心·载人模式 战术链路 全队增伤）
```

两种标记共性：**均可叠加 10 层；每层持续 5s，叠加时重置持续时间；需要美术表现 +
常驻状态显示（位于战斗 UI 左侧状态栏）**。

- **误差标记（Drift Mark）**：通用增伤标记。由舰船系统、视差甲板机群铺设。
  - 每层增加目标 **2.5%~7.5%** 受到的伤害（按难度系数缩放）。
- **深水标记（Deep Water Mark）**：电战压制标记。由渗透潮汐高潮位铺设，可与误差标记叠加。
  - 每层：**−2% 武器射程，−4% 武器精度，−1% 最大航速，−4% 对「引力透镜」造成的伤害**。

> 实现层：建议一个统一标记数据结构 `LensMarkState`（接口 + Impl），挂在目标 ship 的
> customData 上，记录两类标记的层数与各自剩余时间；由各机制读写，由核心收割时统一查询。
> 状态栏显示与美术表现是两类标记共同的交付项。

## 2. 舰船系统：回声定影（Echo Fixation）

*"我把这一刻拓下来。它会替你们，再死一次。"*

**定位**：延迟结算的区域威慑。逼迫场内敌舰移动（打乱输出 / 阵型），或承受站桩惩罚。
是「时间信息战」而非「引力物理场」。

### 2.1 机制（定影 → 回放 两阶段）

- **定影阶段（4s）**：在鼠标指定区域生成「观测快照场」，持续记录场内敌舰位置 / 状态。
  - 鼠标选择范围：~2000su。
  - 场半径：~700su。
  - **场半径与下方各范围均受舰船系统射程属性影响**。
- **回放阶段（场结束瞬间）**：每个被记录敌舰的「过去坐标」浮现残影；
  对**残影半径内的当前敌舰**施加「认知撕裂」，持续 ~4s：
  - **提升目标受到的伤害 50%~100%**（按难度系数缩放）。
  - 护盾受到的伤害**不再额外增加**——因为舰船承伤系数本身会应用在护盾上。
  - 原理叙事：其「现在」与本舰记录的「过去」对不上，相变重构（紫线·幻觉剥离）被干扰。
- **越站桩越痛**：站桩不动的敌舰（过去 ≈ 现在）残影与本体重合，效果最强；走位躲开线性衰减。
  - 重合时最高 **额外 +200%** 增伤；敌舰离「过去」越远效果越低，**最低 25%**。
  - 站桩判定基础范围 **500su**，**受舰船系统射程属性影响**。

### 2.2 与插件咬合

- 被「认知撕裂」命中的敌舰叠 **1 层误差标记**（接入标记闭环）。
- 设计上与深水标记可叠加（深水来自插件 ③）。

### 2.3 数值锚点（v0，待平衡）

| 参数 | 值 |
|---|---|
| 鼠标选择范围 | ~2000su |
| 场半径 | ~700su（受系统射程属性影响） |
| 定影时长 | 4s |
| 认知撕裂时长 | ~4s |
| 认知撕裂增伤 | +50%~100%（难度缩放） |
| 站桩额外增伤 | 重合 +200% → 最远 +25%（线性衰减） |
| 站桩判定范围 | 500su（受系统射程属性影响） |
| 误差标记 | 命中即叠 1 层 |

### 2.4 落地路径与风险

- **记录**：定影期间按固定间隔遍历 `engine.ships`，存场内敌舰位置历史快照。
  已有遍历框架（`ASTDProjectileVfxRuntimePlugin` 的扫描式插件范式）。
- **回放 debuff**：临时 HullMod + `AffixCausalityLagHullMod` / `AffixRecordedLoopHullMod`
  （名称即「因果延迟 / 记录回放」）思路复用；增伤走承伤系数（应用到护盾与船体）。
- **残影 VFX**：BoxUtil / sprite 叠绘敌舰残影。
- **风险**：
  - 需存敌舰位置历史快照——**必须设场内目标数与历史长度上限**，超限要 `log()` 丢弃，
    避免静默截断。
  - 站桩 / 偏移的线性衰减阈值需实测调参。

## 3. 内置插件 ①（基座）：透镜阵列核心（Lens Array Core）

*"真相只是一个可调节的变量，而我握着旋钮。"*

> 承载本舰的**双模式切换逻辑**（无人 / 载人），是 `00-common.md` §5 要求的主干插件。
> 紫线特化的纳米重构 = 装甲优先（幻觉剥离）。**必带基座，不参与选择。**
> 需要常驻状态显示（位于战斗 UI 左侧状态栏）。

### 3.1 双模式

- **[无人模式] 全域拓扑态**
  - **蜂群思维**：
    - 本舰所有舰载机非导弹武器射程 +20%；
    - 导弹飞行速度与机动性 +20%；
    - 最大航速 +20%。
  - **幽灵信号**：周围 ~2000su 内的敌方导弹有 **50% 概率失去制导**
    （进入 500su 后**随机触发**，而非进范围即触发）。
- **[载人模式] 宏观锚定态**
  - **情报中枢**：全舰队 ECM 等级提升。取决于友方舰队数量，鼓励集群作战——
    每个友方舰船按其等级额外提供 **2% / 1.5% / 1% / 0.5%** ECM 等级（吨位越小贡献越大）。
  - **战术链路（标记闭环·收割端）**：全队对**带误差标记**的目标造成额外伤害
    （数值 = 误差标记 §1.1 定义）。

### 3.2 共性

- **纳米重构协议**：紫线特化（装甲修复优先）。见 `ASTDNanoRestorationProtocolHullMod`。
- **敌方难度缩放**：作为 Boss / 敌对单位时，数值按 `m ∈ [1.0, 2.0]` 受难度系数放大
  （仅敌对单位，呼应 `BountyScalingHullMod`）。

### 3.3 落地路径与风险

- 双模式切换 ← `ASTDArcFlareDualModeSwitcherHullMod` 现成范式直接复用。
- 纳米重构 ← `ASTDNanoRestorationProtocolHullMod`。
- 全队增伤收割 ← 遍历友军 + 查询目标标记状态（统一标记数据结构）。
- 「蜂群思维」舰载机加成 ← hull stats / fighter wing 修饰。
- 「幽灵信号」导弹失制导 ← 范围内遍历 missiles，按概率 `flameOut`/解锁制导。
- ECM 按友军数量与等级累加 ← 遍历友军舰队，按吨位等级查表累加。
- **风险**：
  - 中。「全队对被标记目标 +X%」需走 on-hit 增伤修饰而非全局 buff，以正确限定「仅对被标记目标」。
  - 「按友军吨位等级提供差异化 ECM」需确认原版 ECM 叠加 API 的可写性。

## 4. 内置插件 ②（选案）：视差甲板（Parallax Decks）

*"它们从你看不到的角度出现。"*

> 强化「4 甲板」支柱。机群是「铺标记的载具」而非主体输出。**需要美术表现。**

### 4.1 机制

- **错位部署**：本舰机群出库时获得 **~2s 相位隐形 + 100% 时流加成**
  （降低甲板被压制时的机群损耗，呼应紫线「切频道」相位味）。
- **链路回响（标记闭环·铺点端）**：本舰机群命中敌人时叠 **1 层误差标记**。
  - **每秒最多叠加 1~2 层，冷却单位为敌舰**（即每艘敌舰独立计算叠加冷却，防刷）。
- **回收重构**：当战机意图为整备（返航）时，位于本舰 1000su 范围内获得 **50% 承伤减免**。

### 4.2 数值锚点（v0，待平衡）

| 参数 | 值 |
|---|---|
| 出库相位隐形 | ~2s |
| 出库时流加成 | +100% |
| 机群 on-hit 叠标记 | 1 层 / 命中 |
| 叠加上限 | 每敌舰每秒 1~2 层 |
| 整备承伤减免 | 50% |
| 整备生效范围 | 本舰 1000su |

### 4.3 落地路径与风险

- 出库相位隐形 + 时流 ← 改 fighter phase / collision + time mult（出库瞬间设短时窗口）。
- on-hit 叠标记 ← `onHitEffect`，范式 `ASTDPursuitVirtualParticleOnHitEffect`；
  **按敌舰维护每秒叠加冷却**（key = 目标 ship）。
- 整备承伤减免 ← 监测 fighter wing 意图（整备 / 返航）+ 与本舰距离。
- **风险**：
  - 中等。「出库相位隐形 / 时流」对 fighter 的相位 / collision / time-mult API 支持度需验证。
  - 「战机意图为整备」的判定需确认 fighter wing API 是否暴露该状态。

## 5. 内置插件 ③（选案）：渗透潮汐（Permeating Tide）

*"它不是一堵墙，是一片正在涨起来的水。"*

> 钉死「高级电战」支柱。会涨落、随交战时长加深的渗透式压制场。**需要美术表现。**

### 5.1 机制

- **涨潮（Rising Tide）—— 深水标记累积**：
  本舰周围 ~2500su 形成「电战潮汐场」。场内敌舰**不断累积深水标记**，
  每 **2.5s~5s** 叠加一层，**距离本舰越近叠加越快**：
  - 最大速度范围：1000su（最快叠加）。
  - 最小速度范围：2000su（最慢叠加）。
- **退潮反制（Ebb）—— 给敌方破局窗口**：
  当本舰**过载**时潮汐退去，**清空所有敌舰的误差标记与深水标记**。
- **敌方难度缩放**：潮汐上限与涨速按 `m ∈ [1.0, 2.0]`——相当于最快约 **1.25s / 层**。

### 5.2 数值锚点（v0，待平衡）

| 参数 | 值 |
|---|---|
| 潮汐场半径 | ~2500su |
| 叠加速率 | 2.5s~5s / 层（按距离插值） |
| 最快叠加范围 | ≤1000su |
| 最慢叠加范围 | ≤2000su（出 2500su 不叠） |
| 退潮触发 | 本舰过载 |
| 退潮效果 | 清空全场敌舰的误差 + 深水标记 |
| 敌方难度缩放 | m∈[1.0,2.0]，最快约 1.25s/层 |

### 5.3 落地路径与风险

- 潮位 / 叠加节奏 ← `AdvanceableListener` 每帧维护，按距离插值叠加间隔。
- 深水标记 ← 统一标记数据结构。
- 退潮触发 ← `fluxTracker.isOverloaded`；触发时遍历全场敌舰清空两类标记。
- **风险**：低。状态机 + 范围标记范式齐备。需确认深水标记「−ECM/射程/精度」对原版属性
  系统的作用方式（按层叠加 debuff）。
