# ARC Production Ships Redesign Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the redesigned `astd_arc_jet`, `astd_plasma_arch`, and `astd_radiation_belt` hullmods, ship systems, ship data, copy, and combat VFX described in `docs/design/ships/blue/20-production.md`.

**Architecture:** Keep data source-of-truth in `ss-csv` entries, generate to `build/generated/ss-csv`, then write back to `contents` only after validation. Runtime mechanics live in focused `combat/hullmods/arc` and `combat/shipsystems` classes, with shared ARC helpers for aura selection, range falloff, damage bookkeeping, and VFX emission. Visual effects use BoxUtil-first rendering and fail loudly when required rendering support is unavailable.

**Tech Stack:** Kotlin, Starsector combat API, ss-csv Gradle generator, project I18n API, `ASTDHullModTooltipRenderer`, BoxUtil combat VFX helpers, Gradle tests/smoke tests.
