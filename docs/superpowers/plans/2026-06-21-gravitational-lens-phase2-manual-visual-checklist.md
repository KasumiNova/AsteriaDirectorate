# 引力透镜级 · 阶段二 · 人工视觉复核清单

> **背景**：SSOptimizer 实机集成测试（`lens_phase2_mechanisms`）只能验证「shader 特效已向渲染管线提交」（提交计数 >0 = 视觉管线生效），**像素级外观仍需人眼复核**。本清单是阶段二交付的人工复核项，请在游戏内实际观察后逐项确认。

**复核入口**：部署 mod 后进战斗（任务/战役），用引力透镜级（载人 + 无人模式各一轮），对敌群施放系统/触发机制，观察以下视觉。

**阶段二配色基线（用户定）**：LENS 主题色**紫色**优先，辅色用**红色**或**淡紫色**。逐项确认配色符合该基线。

---

## 1. 回声定影（舰船系统 D）
- [ ] **定影场圆形边界**：施放后落点出现紫罗兰圆环边界，沿定影进度（~4s）脉动收束。
- [ ] **残影回放**：定影结束瞬间，场内敌舰的「过去位置」浮现半透明紫调舰体残影（~1.25s 淡出）。
- [ ] **被撕裂敌舰**：站桩不动（与过去位置重合）的敌舰承伤明显升高（结合伤害数字观察）。
- [ ] 场边界 / 残影配色为紫罗兰系，无残留青色。

## 2. 误差 / 深水标记高光
- [ ] **误差标记高光**：被误差标记的敌舰周身**紫罗兰**高光环。
- [ ] **深水标记高光**：被深水标记的敌舰周身**红色**高光环。
- [ ] **两类可区分**：紫 vs 红对比清晰，不混淆。
- [ ] **强度随层数**：层数越高（最高 10 层）环越亮/越宽。

## 3. 幽灵信号波（无人模式）
- [ ] **径向扩散波**：无人模式下，幽灵信号剥离敌方导弹制导时，以本舰为中心放出**紫色**径向干扰波（电子战脉冲质感）。
- [ ] 波扩散观感平滑（~0.6s 一道，每 tick 至多一道，不刷屏）。
- [ ] 被剥离的导弹失去制导、保持当前航向直飞（不熄火坠落）。

## 4. 渗透潮汐场
- [ ] **潮汐场涟漪**：本舰周围 ~2500su 紫罗兰 FBM 涟漪场，随交战时长涨潮加深。
- [ ] **越近越快**：靠近本舰的敌舰叠深水标记更快（1000su 内最快，2500su 外不叠）。
- [ ] **过载退潮**：本舰过载瞬间，潮汐场消散 + 全场敌舰标记被清空（敌方破局窗口）。
- [ ] 潮汐场配色紫罗兰，无残留青色。

## 5. 视差甲板（机群）
- [ ] **出库相位**：本舰机群出库 ~2s 内呈相位态（半透明/可穿透），表现「切频道」相位味。
- [ ] **机群叠标记**：机群命中敌舰时叠误差标记（敌舰出现误差高光）。
- [ ] **整备减伤**：返航/整备意图的机群在本舰 1000su 内承伤降低（不易被秒）。
  > 注：fighter on-hit 叠标记在自动化测试中降级为「插件挂载」断言（实机难确定性触发），此处需人工实战确认机群真的在叠标记。

## 6. 整体视觉一致性
- [ ] **紫线主题统一**：所有 lens 特效（定影场 / 标记高光 / 幽灵波 / 潮汐场 / 残影）与 ASTD_LENS 引擎尾焰、`grav_lens` 舰体贴图协调，整体紫罗兰基调一致。
- [ ] **辅色克制**：红色（深水标记）/ 淡紫（点缀）作为辅色出现，不喧宾夺主。
- [ ] **无视觉冲突**：多机制同时生效时（场 + 标记高光 + 残影叠加）画面不过曝、不糊成一团（Additive 叠加观察）。
- [ ] **性能**：大量敌舰带标记高光 + 潮汐场 + 残影同屏时帧率稳定。

## 阶段二修订轮（2026-06-21）· 人工复核增量

> 本轮针对阶段二实机验收暴露的 9 项问题做了调整（计划：`2026-06-21-gravitational-lens-phase2-revision.md`）。
> 以下为本轮**新增/变更**的人工复核项；上方原清单中被本轮覆盖的项以本节为准。
> 三场景自动化已全 PASS（lens_phase1_foundation / lens_phase2_mechanisms / arc_production_ships_vfx_tooltip）。

### R1. 切换器「拆即切」（通用双模式切换器）
- [ ] **可拆卸触发切换**：refit 改装界面拆下「双模式切换器」（`astd_dual_mode_switcher`）→ 舰船在载人 / 无人模式间轮换（切换器随即被加回，常驻）。
- [ ] **tooltip 动态文案**：切换器说明区显示「当前模式」+「拆下后切到的目标模式」，模式名随当前舰 variant 正确变化（紫蓝高亮）。
- [ ] **通用复用**：同一切换器在 arc_flare（弧光耀斑）与 gravitational_lens（引力透镜）上均可用，tooltip 各自显示对应舰的模式名（非硬编码单舰）。
- [ ] **无人模式可验收**：通过拆即切切到无人模式后，幽灵信号 / 蜂群思维等无人专属效果正常生效（修复前因切换器不可用而无法验收）。
- [ ] **载人模式自举**：全新部署的载人引力透镜（Standard 变体，无 permaMod 声明）应自动处于载人模式并带「透镜阵列核心 - 载人模式」船插。
  > 机制：切换器（lens .ship builtInMods 常驻）在 applyEffectsBeforeShipCreation 经 registry 反查 config → ensureASTDDualModeState 把无模式 variant 收敛到缺省载人模式。不依赖变体手写 permaMod（遵守 Standard 变体不用 permaMod 的项目约束，arc 例外）。

### R2. 渗透潮汐场降亮（≥50%）
- [ ] **大战场不抢眼**：潮汐场常驻涟漪亮度较旧版明显降低（alphaMult 0.55→0.26，约 −53%），多敌同屏时不再过曝抢眼，仍可辨涟漪形态。

### R3. 回声定影残影重做（常驻 + jitter + 红随距离）
- [ ] **残影常驻**：被「认知撕裂」的敌舰，其「过去位置」残影在 debuff 存活期内**持续显示**（非旧版一次性 ~1s），debuff 结束才消失。
- [ ] **越近越抖**：敌舰当前位置离「过去位置」越近，残影 jitter 抖动越剧烈（站桩重合者撕裂感最强）；远离时残影稳定无抖。
- [ ] **越近越红**：越接近「过去位置」残影颜色越偏红（紫罗兰→红插值），呼应「被拽回过去再死一次」语义；远处仍为紫罗兰。

### R4. 误差 / 深水标记高光改周期扩散波
- [ ] **周期脉冲扩散波**：被标记敌舰周身高光由旧版静态环改为「一波接一波」周期性向外扩散的轻波（周期 ~1.2s），带轻微扭曲。
- [ ] **颜色不变**：误差仍为**紫罗兰**、深水仍为**红色**（无青色），两类对比清晰。
- [ ] **轻度不刷屏**：波较旧静态环更轻（base alpha 下调），多敌带标记同屏不糊成一团。

### R5. 幽灵信号改导弹位置小特效 + 50% 熄火（无人模式）
- [ ] **导弹位置小脉冲**：无人模式幽灵信号剥离敌方导弹制导时，在**每枚被剥离导弹的位置**放一道小扰动波（~120su），不再是本舰中心的 ~2000su 大紫圈。
- [ ] **密集导弹不抢眼**：密集来袭时多个小脉冲分散在各导弹位置，画面不被单一大波占据。
- [ ] **50% 熄火坠落**：被幽灵信号影响的导弹有额外 50% 概率熄火（引擎失效、失速坠落），而非全部仅失制导直飞。

### R6. ASTD 系列引擎熄火修复时间
- [ ] **修复时间正常**：任意 ASTD 系列舰（arc / lens 等）引擎被打灭（熄火）后的修复时间与原版舰一致，不再异常漫长（修复前矢量尾焰管理器每帧 setFlameLevel 拖垮了原版修复计时）。
