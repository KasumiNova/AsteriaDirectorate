## 频闪锋线级批准设计

### 基本定位

- 驱逐舰
- 高机动弹幕突击 / 近距压制 / 精锐猎杀
- 当前资源与内部 id 可沿用 `astd_shockwave_striker`

### 战斗循环

1. 弹匣连射蓄能
2. 换弹期用副炮维持压力
3. 消耗充能执行自由方向位移
4. 位移后进入短时爆发窗口

### 光尘机制

- 全舰累计造成 800 点伤害生成 1 组光尘
- 主炮按双倍效率计入
- 每组光尘 = 1 防御光尘 + 2 攻击光尘
- 防御光尘上限 6~18，随难度系数缩放
- 超出上限时，新增防御光尘转化为攻击光尘
- 防御光尘：600 FRAGMENTATION，对导弹采用伤害池衰减逻辑
- 攻击光尘：150 ENERGY + 300 EMP

### 系统：过载位移（Overload Shift）

| 参数 | 值 |
|---|---|
| 类型 | DISPLACER |
| 弹药 | 2 |
| 回复速度 | 0.15 / s |
| 基础位移距离 | 400 |
| 满充位移距离 | 800 |
| 启动时间 | 0.1s |
| 位移过程 | 0.3s |
| 冷却 | 1s |

### 脉冲充能联动

- 主炮每次命中提供 +6% 充能
- 使用系统时消耗全部充能
- 位移距离 = 400 + 400 × 当前充能比例
- 位移期间获得 0.3s 无敌帧
- 位移后 4s 过载窗口：
  - 全武器射速 +30% × 当前充能比例
  - 全武器伤害 +20% × 当前充能比例
  - 光尘生成阈值减半

### 内置 Hullmod

**Light Dust Array**
- 负责光尘的生成、分类、数量控制与行为逻辑

**Pulse Capacitor Group**
- 中型 HYBRID OP 折扣 -3
- 武器转向速率 +20%
- 幅能散热常驻 +50
- 换弹期间额外散热 +150
- 脉冲充能自然衰减 -3% / s
- 充能上限 100%
- UI 为舰体下方弧形进度条

### 内置无人机：频闪护卫

- 数量：2
- 实现：MagicDrone
- 武装：1× 离子束、1× 离子炮、2× PD 激光
- 护盾效率：0.5
- 幅能容量 / 散耗：800 / 150
- 装甲 / 结构：75 / 600
- 非光束武器与 PD 武器射程 +100%
- 始终锁定在母舰轨道，可调整位置承担伤害
- 母舰激活系统时同步传送
- 近距贴身压制，持续施加 EMP 压力

## 结论

这份设计将原本偏“瞬时处决”的激波前锋重构成一艘节奏明确、主炮与系统强联动、兼具防御层与高机动爆发窗口的精锐驱逐舰。
